A-Grade Plan · 58 types

What algorithms are: flowcharts and pseudocode: What algorithms are and how we write them down · Spot selection and iteration, and pick the right loop · Write an algorithm on paper: flowcharts and pseudocode

Data types, variables, arrays and subprograms: Pick the right data type for a value · Variables, constants, arrays and records · Functions, procedures, parameters and libraries · Local and global variables

Trace tables: running, reading and fixing algorithms: Trace tables: run the algorithm by hand · Say what an algorithm (or one line) does · Find and fix errors in an algorithm

Sorting and searching: bubble sort, merge sort, binary search: Bubble sort, one pass at a time · Merge sort: split, then merge · Binary search step by step · Compare sorts and searches

Reading code: constructs, named items, errors and test data: Syntax, logic and runtime errors · Spot constructs, operators, keywords and comments · Find named items in a program · Normal, boundary and erroneous test data

Python: selection, fixing errors and short programs: Finish an if/elif/else so each input gives the right message · Fix the errors in a short program · Write a short number program from a list of requirements · Turn a flowchart or pseudocode into Python

Python: subprograms, files and the 20-mark program: Subprograms and strings: complete the function and its call · Read and write text files line by line · The final 20-mark program

Binary numbers and logic: Binary to denary and back (unsigned, 0 to 255) · Complete a truth table · How many patterns from n bits · Adding binary numbers and overflow · Sign and magnitude numbers · Two's complement numbers · Write a logic statement for a problem

File sizes, units and compression: Pixels, resolution and colour depth · Kilobytes and kibibytes · Sound sampling: analogue to digital · Expressions for file size and transfer time · Compression: lossy or lossless?

Computational models, the CPU and memory: Input, process, output and other computational models · RAM, ROM, virtual memory and flash memory · The stored program concept and the parts of the CPU · Buses and the fetch-decode-execute cycle · What makes a CPU faster: clock speed, cores and cache

Embedded systems, cloud storage, software and translators: Embedded systems: small computers inside devices · Cloud storage: what it is, pros, cons and security · What the operating system does, and system vs application software · High-level and low-level languages · Translators: assembler, compiler and interpreter

Networks, media, protocols and the internet: Network types: LAN, WAN, PAN and why we network · Network protocols: what they are and which one does what · Network topologies: bus, ring, star and mesh · The internet, the web, DNS and the parts of a URL · Wired or wireless? Media, pros and cons, and network speed units · The TCP/IP model: four layers and what each does

Encryption, network security, ethics and new technology: What encryption is and why we use it · Keeping a network secure: access rights, physical security and authentication · Finding and fixing weaknesses: penetration testing, ethical hacking, code reviews, audit trails · Ethics of technology: privacy, inclusion and professionalism · Emerging tech: quantum, DNA computing, AI and nanotechnology
