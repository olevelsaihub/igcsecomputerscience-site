Before you start: supporting skills

These starting skills support many types. Check them first, and come back to them whenever a type feels hard.

  • Reading a question and its figures: Read a Computer Science question, its command word, mark allocation and any table, code listing or diagram, and pick out what the answer needs
  • Flowchart symbols: Recognise and use the terminator, process, decision, input/output and arrow symbols, and follow a flowchart from start to stop
  • The pseudocode command set: Read the Pearson pseudocode command set: SET, SEND ... TO DISPLAY, RECEIVE, IF ... THEN ... ELSE, WHILE, REPEAT ... UNTIL, FOR, LENGTH, MOD and DIV, and arrays indexed from 0
  • Python 1: running a program, print, input and variables: Open the IDE, run and save a .py file; print text and values; read input with input(); store values in variables; convert with int() and float()
  • Python 2: making decisions with if, elif and else: Write conditions with comparison and logic operators and choose between paths with if/elif/else
  • Python 3: loops: Repeat with for ... in range() and while; count and total in a loop; stop on a sentinel value
  • Python 4: lists and strings: Store data in lists and 2D lists; index, slice and loop over lists and strings; len(); join and split
  • Python 5: functions: Define functions with parameters, return a value, call them; local and global variables
  • Python 6: text files: Open a text file to read or write, loop over lines, split on commas, write lines, close the file
  • Binary place values: Know bits, nibbles and bytes, powers of 2 up to 128 and the 128-64-32-16-8-4-2-1 place values
