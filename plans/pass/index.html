Why these types are in the plan
39selected question types
6learning days

The review covered 14 current component papers from 2019–2025.

Current-paper marks were assigned to each part’s sole primary type, and every selected type’s prerequisites were added.

Historical coverage check

7 of 7 current paper pairs cleared the target

The route covered at least 105/160 primary-owned marks on every complete 2019–2025 pair. Each pair stayed at least 10 marks above the higher of its own historical Grade 5 boundary and the matching June 2026 Grade 5 boundary.

This is 100% historical paper-pair coverage, not a 100% probability claim for a future student grade. Accuracy, timing, independent recall and unseen wording still matter.

Completion time

6 learning days plus 6 paper sessions

Study 6 to 7 types per day, then sit three complete Paper 1 + Paper 2 mock pairs as six separate paper sessions. That is 12 active days.

This keeps the olevels.com Pass Plan pace of about 6.6 types per learning day.

Readiness gate

Completion is practice. Fresh papers confirm readiness.

After completing the plan, attempt three fresh, unseen 160-mark Paper 1 + Paper 2 paper pairs under timed conditions. Have each pair independently marked with its official scheme. Grade 5 readiness is supported only when every score is at least 10 marks above that exact pair’s published Grade 5 boundary.

Supporting skills for Computer Science

Use these short bridges when a starting skill needs strengthening.

Reading a question and its figures

Read a Computer Science question, its command word, mark allocation and any table, code listing or diagram, and pick out what the answer needs

Flowchart symbols

Recognise and use the terminator, process, decision, input/output and arrow symbols, and follow a flowchart from start to stop

The pseudocode command set

Read the Pearson pseudocode command set: SET, SEND ... TO DISPLAY, RECEIVE, IF ... THEN ... ELSE, WHILE, REPEAT ... UNTIL, FOR, LENGTH, MOD and DIV, and arrays indexed from 0

Python 1: running a program, print, input and variables

Open the IDE, run and save a .py file; print text and values; read input with input(); store values in variables; convert with int() and float()

Python 2: making decisions with if, elif and else

Write conditions with comparison and logic operators and choose between paths with if/elif/else

Python 3: loops

Repeat with for ... in range() and while; count and total in a loop; stop on a sentinel value

Python 4: lists and strings

Store data in lists and 2D lists; index, slice and loop over lists and strings; len(); join and split

Python 5: functions

Define functions with parameters, return a value, call them; local and global variables

Python 6: text files

Open a text file to read or write, loop over lines, split on commas, write lines, close the file

Binary place values

Know bits, nibbles and bytes, powers of 2 up to 128 and the 128-64-32-16-8-4-2-1 place values
