    Read part (a) as text

    (a) Anna wants to program a guessing game for Beatrice to play on the computer. The program will generate a random number between 1 and 10. Beatrice has to guess the number. This pseudocode contains the logic required to create the game. # Initialise variables SET counter TO 1 # i.e. a random integer 1 to 10 inclusive SET answer TO RANDOM(9) + 1 SET guess TO 0 # Print prompt and take guess from user SEND “Enter a number from 1 to 10: ” TO DISPLAY RECEIVE guess FROM (INTEGER) KEYBOARD # Create while loop to check guess WHILE guess <> answer DO SET counter TO counter + 1 IF guess > answer THEN SEND (guess & “ was too high. Try again.”) TO DISPLAY ELSE SEND (guess & “ was too low. Try again.”) TO DISPLAY END IF SEND “Guess again: ” TO DISPLAY RECEIVE guess FROM (INTEGER) KEYBOARD END WHILE # Report the correct answer to the user and display the number of guesses SEND (“You guessed “ & guess & “ in “ & counter & “guesses.”) TO DISPLAY Write a program to implement the logic in the pseudocode. Open Q02a in the code editor. You must use the structure give in Q02a to write the program. Do not add any further functionality. Save your code as Q02aFINISHED with the correct file extension for the programming language. (10)

    Hint for part (a)

    Work through the design box by box or line by line, and wherever it loops back, write a while loop rather than an if. Plan the steps in order before writing, then test what you wrote with the example data.
