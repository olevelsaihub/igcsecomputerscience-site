    Read part (a) as text

    (a) The number of minutes a train is early or late are recorded each day for a week. • A value of 0 is recorded if the train is on time. A negative value is recorded if the train is early. • • A positive value is recorded if the train is late. The algorithm in Figure 2 has been created to calculate and output the total number of trains that were early, on time or late. SET arrival TO [-2, 1, 5, 0, -3, 4, 1] SET early TO 0 SET late TO 0 SET index TO 0 WHILE NOT (index > LENGTH(arrival)) DO IF arrival[index] >= 0 THEN SET late TO arrival[index] ELSE IF arrival[index] < 0 THEN SET early TO early + 1 END IF END IF SET index TO index + 1 END WHILE SEND "Trains early: " & early TO DISPLAY SEND "Trains on time: " & (late + early) TO DISPLAY SEND "Trains late: " & late TO DISPLAY Figure 2 Identify the type of iteration construct used in Figure 2. (1) A Post‑conditioned loop B Count controlled loop C Array loop D Pre‑conditioned loop

    Hint for part (a)

    Look for the shape or keyword: a decision with no loop-back is selection, while FOR, WHILE, REPEAT or an arrow going back means iteration. Cross out the options you know are wrong first, then check the one left against the method.
