Knowledge card

Logical and arithmetic binary shifts

Calculation
  • A binary shift moves every bit left or right by a given number of places.
  • Bits that move off the end are lost.
  • In a logical shift, the empty places are always filled with 0s.
  • In an arithmetic right shift, the empty places on the left are filled with copies of the sign bit (the leftmost bit), so a negative number stays negative.
  • An arithmetic left shift fills the empty places on the right with 0s, like a logical left shift.
  • Each shift of one place left multiplies an unsigned number by 2; each shift right divides it by 2 (any remainder is lost).
  • Shifting right by 2 divides by 4; shifting right by 3 divides by 8.
  • Pearson's papers describe an arithmetic shift as one that keeps the sign of the number: on a right shift the sign bit is copied into the empty places; answer in those terms.

Before you begin

  • Binary place value
  • The sign bit in signed numbers (CSC-T3-02, CSC-T3-03)
  • Powers of 2
1

The method

  1. Note the direction, the number of places and whether the shift is logical or arithmetic.

    Why: These three facts decide every bit of the result.

  2. Move every bit the given number of places, dropping the bits that fall off the end.

    Why: The register keeps the same number of bits.

  3. Fill the gaps: 0s for logical shifts and left shifts; copies of the original sign bit for an arithmetic right shift.

    Why: This is the only difference between logical and arithmetic shifts.

  4. Count the bits in your answer to make sure it is the same length as the original.

    Why: A wrong length shows a slip.

  5. For a 'describe' question, give the direction and the number of places (divide by 2 to the power n means right n places).

    Why: Each fact earns a mark.

Do not lose marks here

  • ✗
    Filling with 0s after an arithmetic right shift of a negative number.
  • ✗
    Shifting in the wrong direction.
  • ✗
    Changing the length of the pattern instead of dropping bits off the end.
  • ✗
    Shifting by one place too many or too few.
  • ✗
    Saying 'shift right' without the number of places in a describe question.

Worked explanation

  1. Pattern: 1100 0101. Shift: arithmetic, right, 3 places.
  2. The sign bit (leftmost) is 1.
  3. Move all bits 3 places right: the last three bits 101 fall off the end, leaving 11000 in the right-hand five places.
  4. Fill the three empty places on the left with copies of the sign bit: 111.
  5. Result: 111 then 11000, which is 1111 1000.
Model answer · written by olevels.com, not an official Pearson mark scheme

1111 1000

How the marks are earned

One mark for the exact pattern 1111 1000.

Calculation check

  • format(((0b11000101 - 256) >> 3) & 255, '08b') = 11111000
  • (0b11000101 - 256) >> 3 = -8
  • format(0b11000101 >> 3, '08b') = 00011000
