Knowledge card

Run-length encoding (RLE)

Written

Run-length encoding (RLE) is lossless. Each run of the same symbol becomes a count and the symbol: WWWW becomes 4W. It saves space only when there are long runs.

  • Run-length encoding is a lossless compression method.
  • A run is a group of the same symbol (or pixel colour) next to each other.
  • RLE replaces each run by a count and the symbol, for example WWWW becomes 4W.
  • Use the same order (count then symbol, or symbol then count) all the way through.
  • RLE works well when the data has long runs, such as simple images with large areas of one colour.
  • RLE works badly when values rarely repeat; it can even make the file bigger, because each single value gains a count.
  • Decoding RLE gives back exactly the original data.

The method

  1. Read in order

    Left to right, row by row.

  2. Count a run

    How many before it changes.

  3. Write the pair

    Count then symbol.

  4. Check the row

    Counts add up to the row width.

  5. Judge it

    Long runs save space.

Do not lose marks here

  • ✗
    Off by one

    Count carefully.

  • ✗
    Order swapped

    Count then symbol, every time.

  • ✗
    Totals not runs

    Count each separate run.

Worked explanation

  1. Read the 8-pixel rows of the icon from left to right.
  2. Line 1: white, white, white, black, then white x4. Runs: 3 white, 1 black, 4 white.
  3. Line 2: one white, six black, one white.
  4. Line 3: one black, two white, one black, one white, one black, two white.
  5. Line 4: three white, two black, three white.
  6. Check each line adds up to 8 pixels.
Model answer · written by olevels.com, not an official Pearson mark scheme

First line is 3W 1B 4W; the second line is 1W 6B 1W; the third line is 1B 2W 1B 1W 1B 2W; the fourth line is 3W 2B 3W.

How the marks are earned

All four lines correct earns 3 marks; three correct lines earn 2; two correct lines earn 1. One small slip in the sequence is allowed.

Calculation check

  • 'W' × 3 + 'B' × 1 + 'W' × 4 = WWWBWWWW
  • sum([3, 1, 4]) = 8
  • sum([1, 6, 1]) = 8
  • sum([1, 2, 1, 1, 1, 2]) = 8
  • sum([3, 2, 3]) = 8
