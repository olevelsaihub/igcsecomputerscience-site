Knowledge card

Write an algorithm on paper: flowcharts and pseudocode

Written

Every algorithm uses sequence, selection and iteration. In a flowchart: rounded Start/Stop, parallelogram input/output, rectangle process, diamond decision with Yes and No exits.

  • Every algorithm is built from three constructs: sequence (steps in order), selection (choosing a path with IF or a decision) and iteration (repeating with a loop).
  • Flowchart symbols: a rounded box (terminator) for Start and Stop, a parallelogram for input or output, a rectangle for a process, and a diamond for a decision.
  • Every decision diamond has exactly two exits, labelled Yes and No (or True and False).
  • Arrows show the order of steps; a loop is drawn as an arrow going back up to an earlier step.
  • In pseudocode, a counter is set to 0 before a loop (SET count TO 0) and increased inside it (SET count TO count + 1).
  • Text is joined to a value with & in Pearson pseudocode, e.g. SEND "There are " & count & " vowels" TO DISPLAY; in Python you can use + with str() or a comma in print().
  • A remainder of 0 shows divisibility: number MOD 3 = 0 means the number divides exactly by 3 (number % 3 == 0 in Python).

What a complete response includes

Separate marks for each required part: start and input, each correct decision with labelled branches, each output on the right path, counter set-up and increase, and the loop back. A final mark goes for a fully connected, working solution or consistent notation. Longer flowcharts may be marked in levels for how well they work and how accurate the notation is.

Worked explanation

  1. List the parts: input n; stop if n is 0; output 'Positive' if n > 0; output 'Negative' if n < 0; repeat.
  2. Draw Start (rounded box), then an input parallelogram 'Input n'.
  3. Draw a diamond 'Is n = 0?'. Yes goes to a Stop terminator.
  4. From No, draw a second diamond 'Is n > 0?'.
  5. Yes leads to an output parallelogram 'Output "Positive"'; No leads to 'Output "Negative"'.
  6. From both outputs, draw arrows back to 'Input n' so the user is asked again.
  7. Test: 5 gives Positive, then -3 gives Negative, then 0 reaches Stop.
Model answer · written by olevels.com, not an official Pearson mark scheme

Start -> [Input n] -> <Is n = 0?> Yes -> Stop. No -> <Is n > 0?> Yes -> [Output "Positive"] -> back to [Input n]; No -> [Output "Negative"] -> back to [Input n]. Terminators are rounded boxes, input and output are parallelograms, decisions are diamonds with Yes/No labels, and every line has an arrow.

How the marks are earned

1: Start followed by input of n. 2: a decision testing n = 0, with labelled branches, where Yes leads to Stop. 3: a second labelled decision testing n > 0 (or n < 0). 4: the two messages output from the correct branches. 5: everything connected with arrows and working, looping back for the next input. 6: the correct symbols used throughout.

Calculation check

  • ['Positive' if n > 0 else 'Negative' for n in [5, -3]] = ['Positive', 'Negative']
