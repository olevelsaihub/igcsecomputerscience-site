Knowledge card

Variables, constants, arrays and records

Written

A variable holds one value that can change. A constant is fixed, written in capitals. An array holds many values of one type, reached by index from 0. A record groups fields of mixed types.

  • A variable is a named memory location whose value can change while the program runs.
  • A constant is a named memory location whose value stays fixed while the program runs; in Python we show this by writing the name in capitals, like TAX = 0.05.
  • Using a constant means a value is typed in one place only, so updating it later means changing just one line.
  • In pseudocode a CONST can only be set once; Python does not enforce this, so capital letters are a convention that tells programmers not to change the value.
  • A constant with a clear name, like VAT_RATE, makes code easier to read than a bare number like 0.2.
  • An array holds many values of the same data type under one name; each value is reached by its index, starting at 0.
  • A one-dimensional array is like a single list or row; a two-dimensional array is like a table with rows and columns.
  • A record groups related fields about one item, and the fields can be different data types (for example a name, a year and a price).
  • A variable holds one value at a time, whereas an array holds a whole collection of values.

The method

  1. Underline the key word

    Variable, constant, array, record.

  2. Definition

    What is stored and can it change?

  3. Benefit of a constant

    One place to update; easier to read.

  4. Difference

    First item, whereas, second item.

  5. Record or array?

    Mixed types means record.

Do not lose marks here

  • ✗
    One side only

    Describe both items.

  • ✗
    Vague 'easier'

    Give a reason.

  • ✗
    Wrong structure

    Mixed data needs a record.

Worked explanation

  1. Write down what a variable stores: one value at a time, for example score = 12.
  2. Write down what an array stores: many values under one name, for example scores = [12, 7, 15].
  3. Join the two halves with 'whereas' so the comparison is clear.
Model answer · written by olevels.com, not an official Pearson mark scheme

A variable holds just one value at a time, whereas an array holds a collection of several values under a single name, each reached by an index.

How the marks are earned

First mark: a variable holds one value. Second mark: an array holds many values. Both halves are needed for two marks.
