Knowledge card

Write a logic statement for a problem

Written

Use AND when all conditions are needed, OR when one is enough and NOT when one must be false. Put brackets round an OR group: NOT first, then AND, then OR.

  • A logic statement (Boolean expression) uses letters for conditions and the operators AND, OR and NOT to show when something happens.
  • Use AND when all the conditions must be true together.
  • Use OR when any one of the alternatives is enough.
  • Use NOT when a condition must be false (for example, a lock removed or a code not entered).
  • The order of precedence is NOT first, then AND, then OR.
  • Put brackets around OR alternatives that must be joined to other conditions by AND, for example A AND (W OR D).
  • There can be more than one correct statement; equivalent versions earn full marks.
  • You can test your statement by building a quick truth table and checking a few rows against the story.

The calculation

Precedence: NOT, then AND, then OR

Brackets override this order.

  • A OR B AND C means A OR (B AND C).

The method

  1. List conditions

    Note each letter and whether it must be false.

  2. Group alternatives

    OR in brackets.

  3. Join with AND

    Everything that must hold together.

  4. Use given letters

    No circuits or other symbols.

  5. Test two rows

    One that gives 1, one that gives 0.

Do not lose marks here

  • ✗
    Missing brackets

    The meaning changes without them.

  • ✗
    Missing NOT

    A removed or not entered condition needs NOT.

What a complete response includes

Marks are given for each correct building block (for example an OR group, a NOT term, and the AND joining them), with a further mark for correct brackets or a fully correct statement. Equivalent statements and any order of terms are accepted.

Write a logic statement for a problem · June 2023 · Paper 1 · Question 5 · part (d)(ii) · 3 marks

(ii) A warehouse has an automated alarm system. When the alarm system is activated it will sound if: • a movement sensor (M) is activated • a pressure pad (P) is activated • a key code (C) to deactivate the alarm system has not been entered. Construct a logic statement, using AND, OR and NOT with the letters M, P and C, to show the conditions that will sound the alarm. (3)

Worked explanation

  1. List the conditions: M = movement sensor on, P = pressure pad on, C = key code entered.
  2. The alarm sounds if either sensor is triggered: M OR P. Put this in brackets.
  3. The key code must NOT have been entered: NOT C.
  4. Both parts are needed together, so join with AND: (M OR P) AND NOT C.
  5. Check with a truth table: rows M P C = 000,001,010,011,100,101,110,111 give the output column 00101010 from top to bottom. The alarm sounds only when a sensor is on and no code is entered. Correct.
Model answer · written by olevels.com, not an official Pearson mark scheme

(M OR P) AND NOT C

How the marks are earned

One mark for M OR P, one mark for NOT C, and one mark for joining the two parts with AND.

Calculation check

  • ''.join(str((int(r[0]) | int(r[1])) & (1 - int(r[2]))) for r in ('000','001','010','011','100','101','110','111')) = 00101010
