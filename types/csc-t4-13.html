Knowledge card

Utility software: anti-malware, defrag and file tools

Written

Utility software is system software that maintains, protects or tidies a computer. Match the problem to its standard utility, and name the type, never a brand.

  • Utility software is system software that helps maintain, protect or tidy up a computer.
  • Anti-malware protects against harmful software; types include antivirus, anti-spyware, anti-adware and a software firewall.
  • Anti-virus programs can detect viruses by scanning, quarantine infected files, remove them, scan in real time and update themselves.
  • Over time, a file's blocks can become scattered across a hard drive; this is called fragmentation.
  • A defragmentation utility moves each file's blocks next to each other in order and gathers the free space together.
  • Defragmenting a hard drive makes files quicker to read because the head moves less.
  • A file repair or recovery utility tries to fix corrupt files; a backup utility makes copies so files can be restored after damage.
  • A file conversion utility changes a file from one format to another, such as JPEG to PNG.

  1. Read the problem

    Slow disc, corrupt file, lost data, wrong format, malware.

  2. Name the type

    Not a brand.

  3. Skip given functions

    Do not repeat what the question gives.

  4. Defrag diagram

  5. Free space

    Gather it at one end.

Do not lose marks here

  • ✗
    Brand names

    Say 'file conversion', not a product.

  • ✗
    Blocks out of order

    Together is not enough: order matters.

  • ✗
    More space

    Defragmenting does not add space.

Worked explanation

  1. Row 1: a word processor cannot read a corrupt file. The tool that fixes damaged files is a file repair (recovery) utility.
  2. Row 2: a JPEG must become a PNG. Changing format needs a file conversion utility.
  3. Row 3: a flood damaged files on a server but the data is needed. A backup copy must be restored, so use a backup and restore utility.
  4. Row 4: the hard drive is slow when opening a file. Scattered blocks slow it down, so use a defragmentation utility.
Model answer · written by olevels.com, not an official Pearson mark scheme

Corrupt file: file repair (recovery) utility. JPEG to PNG: file conversion utility. Flood-damaged server files: backup and restore utility. Slow hard drive: defragmentation utility.

How the marks are earned

One mark for each correctly matched row, four in total.
