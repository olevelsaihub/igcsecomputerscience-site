Knowledge card

Finish an if/elif/else so each input gives the right message

Written

An if/elif/else chain runs only the first branch whose condition is True. Turn each boundary word into the exact operator, and use and for a range, or for two separate cases.

  • A condition is a test that is either True or False, such as aNum > 0.
  • Relational operators compare values: < less than, <= at most, > more than, >= at least, == equal to, != not equal to.
  • and is True only when both tests are True; use it for a range such as 31 to 39.
  • or is True when at least one test is True; use it when either of two separate cases is enough.
  • Python checks if, then each elif, in order, and runs only the first branch whose condition is True.
  • else catches every case that no earlier condition caught.
  • Boundary words matter: 'at least 10' is >= 10, 'more than 10' is > 10, 'under 5' is < 5.
  • input() always gives a string; int() turns it into a whole number before you compare it with numbers.

Worked explanation

  1. Line 4 needs the input: aString = input ("Enter a number: "). Input is kept as a string so an empty entry can be spotted.
  2. Line 7 is missing its keyword: if (aString != ""): means 'if something was typed'.
  3. Convert: aNum = int (aString), so the number can be compared with numbers.
  4. Acceptable is 1 to 20 or 60 or more. We are already inside aNum > 0, so test (aNum <= 20) or (aNum >= 60).
  5. Centre is 31 to 39, both limits at once: (aNum >= 31) and (aNum <= 39).
  6. Perfect is exactly 30: (aNum == 30). Everything else falls to 'No message'.
  7. Test: empty, -5, 0, 1, 20, 21, 29, 30, 31, 39, 40, 59, 60 and 100. Each gives the message in Figure 3.
Model answer · written by olevels.com, not an official Pearson mark scheme

aString = input ("Enter a number: ") if (aString != ""): aNum = int (aString) if (aNum > 0): if (aNum <= 20) or (aNum >= 60): print ("Acceptable") elif (aNum >= 31) and (aNum <= 39): print ("Centre") elif (aNum == 30): print ("Perfect") else: print ("No message") else: print ("The number must be greater than zero") else: print ("You must provide a number")

How the marks are earned

One mark for the string input line; one for adding the if keyword; one for int(); one for a correct pair of comparisons in one test; one for using or in the first test and and in the second; one for the == 30 test.

Calculation check

  • ','.join('A' if (n<=20 or n>=60) else 'C' if (n>=31 and n<=39) else 'P' if n==30 else 'N' for n in (1,20,21,30,31,39,40,59,60)) = A,A,N,P,C,C,N,N,A

Worked program

Written by olevels.com and tested against the paper’s examples.

# Worked example for CSC-CODE-02 (4CP0-2024-JUN-02-standard-Q03-c). Authored by olevels.com; not Pearson's code.
# Q03c

# Complete the line to take a string input
aString = input ("Enter a number: ")

# Complete the selection statement
if (aString != ""):

    # Convert the string to an integer
    aNum = int (aString)

    if (aNum > 0):

        # Complete the test
        # 1 to 20 OR 60 and above -> either end of the range is fine
        if (aNum <= 20) or (aNum >= 60):
            print ("Acceptable")
        # Complete the test
        # 31 to 39 -> the number must be inside both limits at once
        elif (aNum >= 31) and (aNum <= 39):
            print ("Centre")
        # Complete the test
        # exactly 30
        elif (aNum == 30):
            print ("Perfect")
        else:
            print ("No message")
    else:
        print ("The number must be greater than zero")
else:
    print ("You must provide a number")
