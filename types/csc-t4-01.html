Knowledge card

Input, process, output and other computational models

Written
  • A computational model is a simple picture of how a computer turns a problem into a result.
  • The input-process-output (IPO) model has three stages, always in this order: input, then process, then output.
  • Input is the data that goes into the program, such as numbers typed by a user or a reading from a sensor.
  • Process is the work done on the inputs, such as a calculation or a decision.
  • Output is the result the program produces, such as a value on screen, a printed slip or a movement.
  • In a sequential model, instructions are carried out one after another, in order.
  • In a parallel model, a task is split into parts that different processors (or cores) work on at the same time.
  • In a multi-agent model, several separate systems (agents) talk to each other and work together towards one goal.
  • Only independent pieces of work can run in parallel; a step that needs earlier results must wait for them.

The method

  1. Read the scenario and underline every value or action the program uses.

    Why: The inputs, the calculation and the results are all hidden in the scenario; you must use its own words to earn the marks.

  2. Pick an input: something the program is given and does not work out itself (for example a pay rate or a number of steps).

    Why: An input must enter the system from outside; a value the program calculates is an output, not an input.

  3. Write the process as a calculation or action using the input names (for example pay rate * hours).

    Why: A process mark needs the actual working, not just a word like 'calculate'.

  4. Pick an output: a value or effect the program produces at the end.

    Why: The output must be the result of processing, so it should be something shown, printed or done.

  5. For a parallel question, give each CPU a separate sub-calculation first, then combine the answers in a later row.

    Why: Parallel work only helps when parts do not depend on each other; the joining step must come after the parts are done.

  6. For a 'which model' question, match key words: one after another means sequential, at the same time on cores means parallel, separate systems cooperating means multi-agent.

    Why: Each model has one defining idea, and the wrong options usually describe a different model.

Do not lose marks here

  • ✗
    Writing the three IPO stages in the wrong order, or writing 'storage' instead of 'process'.
  • ✗
    Giving a calculated value (such as total pay) as an input.
  • ✗
    Writing only 'calculate' for the process instead of the actual calculation.
  • ✗
    In parallel tables, putting a step that needs earlier results in the same row as those results.
  • ✗
    Confusing parallel (cores sharing a job) with multi-agent (separate systems cooperating).

Now see it used on a real past-paper question

What a complete response includes

Usually one mark per correct box. IPO boxes must fit the scenario: any real input, any correct calculation and any produced result score. For the fixed IPO diagram, full marks need the right order. Parallel tables give a mark for each independent sub-result and a mark for the final combining step. Model-choice questions are single-mark multiple choice.

Worked explanation

  1. Look at the payslip: Pay Rate £18.75, Hours 19, Total Pay £356.25, Tax 20% = £71.25, Income £285.00.
  2. Ask: which values must be typed in? The pay rate and the hours. These are inputs.
  3. Ask: how is Total Pay made? Pay rate multiplied by hours: 18.75 * 19 = 356.25. That is a process.
  4. Check the other calculations too: tax = 356.25 * 0.2 = 71.25, and income = 356.25 - 71.25 = 285.00.
  5. Ask: what does the program produce? Total Pay, Tax and Income are all outputs. Pick one.
  6. Fill the table: Input = Hours (19); Process = Pay Rate * Hours; Output = Total Pay (£356.25).
Model answer · written by olevels.com, not an official Pearson mark scheme

Input: Hours worked (19). Process: Total pay = Pay Rate * Hours (18.75 * 19). Output: Total Pay (£356.25).

How the marks are earned

One mark for the input box (hours, or the pay rate), one mark for a correct calculation in the process box, and one mark for a produced value in the output box (total pay, tax or income).

Calculation check

  • 18.75 × 19 = 356.25
  • 356.25 × 0.2 = 71.25
  • 356.25-71.25 = 285.0
