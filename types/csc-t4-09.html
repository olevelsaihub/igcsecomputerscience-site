Knowledge card

Embedded systems: small computers inside devices

Written

An embedded system is a small computer built into a larger device to do one specific job. Most features, such as low power and small size, follow from that single task.

  • An embedded system is a small computer built into a larger device to do one specific job.
  • Examples include the controllers in washing machines, smartwatches, ticket machines and TV remote controls.
  • Embedded systems have both hardware and software, with the software usually set by the manufacturer and not changed by the user.
  • They are often small, cheap to mass produce, low power and robust.
  • They usually have built-in memory (often flash) and a simple or no user interface.
  • Many use sensors to measure the world (for example temperature, water level, heart rate) and actuators such as motors to act on it.
  • Because they do one job, their processor, memory and power use can be chosen to be just enough for that job.
  • Many embedded systems work in real time, responding straight away to inputs.

The method

  1. Recall the definition

    A computer inside a device for one task.

  2. List features

    Low power, small, cheap, built-in memory.

  3. Fit the device

    A water sensor for a washer, not GPS.

  4. Purpose beyond the name

    Say what the sensor lets the system do.

  5. Explain

    Link the feature to the single task.

Do not lose marks here

  • ✗
    Repeating the stem

    Do not reuse a feature already given.

  • ✗
    Name as purpose

    A heart rate sensor monitors heart rate scores nothing.

  • ✗
    Parts that do not fit

    No keyboard in a smartwatch.

Worked explanation

  1. The question gives 'uses sensors', so that cannot be used again.
  2. Think about a smartwatch: it is tiny and runs on a small battery.
  3. That suggests two characteristics: it is small, and it needs very little power.
  4. Write each one on its own line.
Model answer · written by olevels.com, not an official Pearson mark scheme

1. It has a low power requirement, so the small battery lasts a long time. 2. It is physically small, so it fits inside the watch.

How the marks are earned

One mark for each correct characteristic, up to two: low power use, and small size.
