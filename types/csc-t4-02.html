Knowledge card

Hardware devices: input, output and how they connect

Written

Hardware is the physical parts; software is the instructions that run on it. An input device sends data to the computer, an output device receives data from it, and some do both. Arrows show the way data travels.

  • Hardware is the physical parts of a computer that you can touch.
  • Software is the set of instructions (programs) that tells the hardware what to do.
  • A computer needs both: hardware cannot do anything useful without instructions, and software needs hardware to run on.
  • An input device sends data into the computer, for example a mouse, keyboard or microphone.
  • An output device receives data from the computer and presents it, for example a speaker, printer or screen.
  • Some devices do both jobs, for example a touch screen, a headset with a microphone, or a USB storage device.
  • On a diagram, an arrow shows the direction data travels: towards the CPU for input, away from the CPU for output, both ways for a device that does both.
  • A smartphone's built-in output devices include its screen, speaker and vibration motor.

Worked explanation

  1. The diagram has a CPU in the middle with a mouse, a speaker and a USB device around it.
  2. Mouse: it sends clicks and movements to the computer, so it is input. Draw a line from the mouse to the CPU with the arrow head at the CPU.
  3. Speaker: it receives sound data from the computer, so it is output. Draw a line from the CPU to the speaker with the arrow head at the speaker.
  4. USB device: data can be saved to it and read from it, so data goes both ways. Draw a line between the CPU and the USB device with arrow heads at both ends.
  5. Check there are three lines, one per device, each with correct arrow heads.
Model answer · written by olevels.com, not an official Pearson mark scheme

Mouse to CPU: one line with the arrow pointing to the CPU. CPU to Speaker: one line with the arrow pointing to the speaker. CPU and USB device: one line with arrows at both ends (or two separate arrows, one each way).

How the marks are earned

One mark for each correctly directed connection: mouse into the CPU, CPU out to the speaker, and two-way between the CPU and the USB device.
