Knowledge card

Buses and the fetch-decode-execute cycle

Written

A bus is a set of wires. The address bus carries addresses one way, CPU to memory. The data bus and control bus work both ways. Fetch: PC to MAR, address bus, read signal, instruction back on the data bus.

  • A bus is a set of wires that carries signals between the CPU, memory and other parts.
  • The address bus carries memory addresses from the CPU to memory, in one direction only (unidirectional).
  • The data bus carries data and instructions in both directions between the CPU and memory (bidirectional).
  • The control bus carries control signals, such as memory read, memory write and clock signals, in both directions.
  • Fetch: the address in the program counter is copied to the memory address register (MAR), which puts it on the address bus; a read signal goes on the control bus, and the instruction comes back on the data bus.
  • The program counter holds the address of the next instruction and is increased (incremented) during the fetch.
  • Decode: the control unit works out what the instruction means. Execute: the instruction is carried out, for example by the ALU.
  • A wider data bus moves more bits at once; a wider address bus can point to more memory locations.

Worked explanation

  1. Recall the fetch step: the CPU needs an instruction from memory.
  2. The CPU copies the address of that instruction (from the MAR) onto the address bus.
  3. The address travels one way, from the CPU to main memory.
  4. Memory uses the address to find the right location, so the CPU can read from it (or write to it).
  5. Join the two ideas into a linked description.
Model answer · written by olevels.com, not an official Pearson mark scheme

During the fetch, the CPU places the memory address of the next instruction (held in the MAR) onto the address bus. This address tells main memory which location to read the instruction from (or write data to).

How the marks are earned

One mark for the CPU putting an address onto the address bus, and a linked second mark for that address identifying the location in main memory that is read or written.
