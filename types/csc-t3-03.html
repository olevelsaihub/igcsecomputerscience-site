Knowledge card

Two's complement numbers

Written

In two's complement the leftmost bit is worth −128; the others are 64 to 1 as normal. To negate: flip every bit, then add 1. The 8-bit range is −128 to +127.

  • Two's complement is the usual way computers store signed (positive or negative) whole numbers.
  • In 8-bit two's complement the leftmost bit has a place value of -128; the others are 64, 32, 16, 8, 4, 2, 1 as normal.
  • If the leftmost bit is 1 the number is negative; if it is 0 the number is positive.
  • The 8-bit range is -128 (1000 0000) to +127 (0111 1111).
  • There is only one pattern for zero, 0000 0000.
  • To make a negative number: write the positive version in 8 bits, flip every bit (0 to 1, 1 to 0), then add 1.
  • Negating means changing the sign but keeping the size; flip-and-add-1 works in both directions.
  • A quick way to read a negative pattern: start at -128 and add the place values of the other 1s.

The method

  1. Write the headers

    −128 64 32 16 8 4 2 1.

  2. Pattern to denary

    Add the values above every 1; the first is −128.

  3. Negative to pattern

    Write the positive size in 8 bits.

  4. Flip, then add 1

    Carry where needed.

  5. Check

    Read your answer back with −128.

Do not lose marks here

  • ✗
    Sign and magnitude

    1100 0001 is −63 here, not −65.

  • ✗
    No +1

    Flipping alone is not enough.

  • ✗
    Dropped minus sign

    Write − in the denary answer.

Worked explanation

  1. Write the headers: -128 64 32 16 8 4 2 1.
  2. Place the bits 1 1 0 0 0 0 0 1 under them.
  3. There are 1s under -128, 64 and 1.
  4. Add: -128 + 64 + 1 = -63.
  5. Check with flip-and-add-1: flip 1100 0001 to get 0011 1110, add 1 to get 0011 1111, which is 63. So the original was -63.

How the marks are earned

One mark for the minus sign and one mark for the size 63.

Calculation check

  • int('11000001', 2) - 256 = -63
  • -128 + 64 + 1 = -63
  • format((~0b11000001 + 1) & 255, '08b') = 00111111
