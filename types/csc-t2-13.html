Pearson Edexcel · International GCSE Computer Science · 4CP0

Spot constructs, operators, keywords and comments

Reading opened Python code, printed pseudocode or a lettered list of algorithm steps and pointing to an element: a relational or logical operator, the selection keyword, comment text, the line where selection or iteration starts, a line that defines a subprogram, initialises a variable or takes input, including marking such a line with a comment in the editor; also recognising arithmetic, relational and logic operators and why brackets change the order of operations.

Type 6 2 Programming CSC-T2-13

★★★★★ · 7 of 14 exam papers (both papers), 2019–2025 (June 2021 not counted). Difficulty: Easy.

The question asks you to identify a line number, give the text of a line or comment, give a keyword or operator, give a step letter, or add a comment at the end of a line that contains a stated construct.

Knowledge card

Spot constructs, operators, keywords and comments

Written
  • A comment in Python starts with # and runs to the end of the line; the computer ignores it.
  • Logical operators in Python are and, or, not (AND, OR, NOT in pseudocode).
  • Relational operators compare values: ==, !=, <, >, <=, >= in Python; =, <>, <, >, <=, >= in pseudocode.
  • Selection starts at the line with if (IF in pseudocode).
  • Iteration starts at the line with for or while (FOR, WHILE, REPEAT in pseudocode).
  • A subprogram definition starts at the line with def (FUNCTION or PROCEDURE in pseudocode).
  • Initialising a variable means giving it its first value, e.g. count = 0.
  • User input in Python uses input(); in pseudocode it is RECEIVE ... FROM KEYBOARD.
  • A data structure is initialised where a list is first set up, e.g. vowels = ["a", "e", "i", "o", "u"].
  • Arithmetic operators do maths: + add, - subtract, * multiply, / divide, % modulus (remainder) and // integer division in Python.

The method

  1. Name the marker you are looking for: #, and/or/not, ==/</>, if, for/while, def, '= 0', input().

    Why: Each construct has a keyword or symbol that gives it away.

  2. Scan the code from the top and stop at the first match.

    Why: Any valid occurrence earns the mark, so the first one is enough.

  3. Answer in the form asked: the token itself, the full line text, the line number or the step letter.

    Why: The wrong form (e.g. a line number when the operator is asked for) can lose the mark.

  4. For an Amend task, type a # comment at the end of the correct line saying what it shows, then save with the given file name.

    Why: The comment must sit on the right line and name the construct.

Do not lose marks here

  • ✗
    Giving a relational operator such as > when a logical operator is asked for.
  • ✗
    Giving a line number when the question asks for the operator or text.
  • ✗
    Giving a variable name instead of the operator.
  • ✗
    Putting the Amend comment on the wrong line or not saving the file.
  • ✗
    Counting line numbers wrongly by skipping blank lines.
  • ✗
    Calling >= or = a logic operator; they are relational.

What a complete response includes

One mark for each correct token, text, line number, step letter or correctly placed comment. Any valid occurrence of the construct is accepted.

Worked explanation

  1. Look through the code for and, or or not.
  2. Line 11 is: if ((count > 10) and (count < 20)):
  3. > and < are relational operators, so they are not the answer.
  4. The word joining the two conditions is and. That is the logical operator.
