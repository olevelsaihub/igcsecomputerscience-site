Knowledge card

Normal, boundary and erroneous test data

Written

Test data checks a program works. Normal data is typical and valid. Boundary data is at the very edge of the valid range. Erroneous data is invalid and should be rejected. Give actual values, not descriptions.

  • Test data is input chosen to check that a program works properly.
  • Normal data is a typical valid value that the program should accept, well inside the allowed range.
  • Boundary data is a value at the very edge of the valid range, such as the smallest or largest value allowed.
  • Erroneous data is invalid data that the program should reject, such as a value outside the range or the wrong data type.
  • For a range of 1 to 12 inclusive: normal could be 6, boundary 1 or 12, erroneous 0, 13 or 'abc'.
  • For a text field allowed 2 to 8 letters: a 2-letter or 8-letter word is boundary; 1 letter or 9 letters is erroneous.
  • Some papers accept the value just outside the range as boundary data; always read the definition given in the question.
  • Each test example in a table should be different.

Worked explanation

  1. The valid range is 0 to 255, whole numbers only.
  2. Normal: pick a value in the middle, such as 125. It converts to hex 7D.
  3. Boundary: pick an end of the range. 255 is the largest; it converts to FF, the biggest two-digit hex number.
  4. Erroneous: pick a value outside the range, such as 256. In hex it would need three digits (100), so it is out of range.
  5. Check: three different integers, all fit the integer type.
Model answer · written by olevels.com, not an official Pearson mark scheme

Normal: 125. Boundary: 255. Erroneous: 256.

How the marks are earned

All three correct cells earn two marks; one correct cell earns one mark.

Calculation check

  • hex(125)[2:].upper() = 7D
  • hex(255)[2:].upper() = FF
  • len(hex(256)[2:]) = 3
