Knowledge card

Design validation checks for a code format

Written

Validation automatically checks that input follows set rules before it is accepted. It checks the data is sensible; it cannot prove it is correct. Good erroneous data breaks only one rule.

  • Validation is an automatic check that input data follows set rules before it is accepted.
  • Validation checks whether data is sensible and allowed; it cannot prove the data is actually correct.
  • A length check tests the number of characters, e.g. len(code) == 10 in Python.
  • A format (pattern) check tests the kind of character at each position, e.g. letters first, then digits.
  • A range check tests that a number lies between limits, e.g. 1 to 9.
  • A check-character test recalculates a character from the rest of the code and compares it.
  • Good erroneous data for a check breaks only that one rule and obeys all the other rules.

Before you begin

  • Characters, digits, upper and lower case
  • Even and odd numbers
  • Test data (erroneous)

Design validation checks for a code format · November 2020 · Paper 2 · Question 5 · part (a) · 4 marks

(a) Each item of stock will have a ten-character code. Each code consists of three parts. Part Description Characters 1 to 3 Uppercase letters Characters 4 to 9 Numbers between 1 and 9 inclusive Character 10 ‘e’ or ‘o’ indicating whether the sum of the numbers is even or odd WAS123456o, FDG232324e and VAC129222e are valid codes. All codes need to be validated. Complete the table to show two additional validation tests. For each test, give one example of erroneous data. The example that you give should fail only that test. (4) Validation test Erroneous data Is the last character ‘o’ or ‘e’? ABC654321v

Worked explanation

  1. List the rules: 10 characters; characters 1-3 upper-case letters; characters 4-9 digits 1 to 9; character 10 is 'e' if the digit sum is even, 'o' if odd.
  2. The last-character test is already given, so choose two others.
  3. Test 1: are characters 1 to 3 upper-case letters? Start from a valid code, WAS123456o (digits sum to 21, odd, so 'o').
  4. Make only the letters wrong: Was123456o. Length 10, digits 1-9, sum still 21, last character still 'o'. Only the case fails.
  5. Test 2: are characters 4 to 9 all digits from 1 to 9? Take WAS111111e (sum 6, even, so 'e').
  6. Change one digit to 0 and keep the parity: WAS101111o has sum 5, odd, so 'o' is still correct. Only the 'no zeros' rule fails.
Model answer · written by olevels.com, not an official Pearson mark scheme

Test: Are characters 1 to 3 upper-case letters? Erroneous data: Was123456o. Test: Are characters 4 to 9 all digits between 1 and 9? Erroneous data: WAS101111o.

How the marks are earned

One mark for each sensible new test (two tests) and one mark for each code that fails only its own test (two codes): four marks.

Calculation check

  • (1+2+3+4+5+6) % 2 = 1
  • len('Was123456o') = 10
  • (1+0+1+1+1+1) % 2 = 1
  • len('WAS101111o') = 10
