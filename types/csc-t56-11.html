Knowledge card

The internet, the web, DNS and the parts of a URL

Written
  • The internet is the worldwide network of networks: the cables, routers and connected devices.
  • The World Wide Web (WWW) is a service that runs on the internet: the collection of web pages and other resources, linked by hyperlinks and fetched using HTTP or HTTPS.
  • Every device on the internet has an IP address, a number that identifies it, for example 2.20.38.113.
  • A domain name is the human-friendly name of a website, for example pearson.com.
  • The DNS (domain name system) works like a phone book: you give a DNS server a domain name and it returns the matching IP address.
  • A URL (uniform resource locator) is the full address of one resource on the web, for example https://www.pearson.com/computing/specification.html.
  • Reading a URL from left to right: the protocol (https), the domain name (www.pearson.com), the folder path (computing) and the file name (specification.html).
  • An ISP (internet service provider) is the company that connects homes and businesses to the internet.

Before you begin

  • What a network is and what a web browser does.
  • What a protocol is (HTTP, HTTPS).
1

The method

  1. For a URL, split it at '://' and at each '/'.

    Why: This separates the protocol, domain, folders and file.

  2. Label each piece: before '://' = protocol; next piece = domain name; middle pieces = folders; last piece with a dot extension = file.

    Why: Each correct label earns one mark.

  3. For DNS, remember the direction: domain name in, IP address out.

    Why: Input and output are marked separately.

  4. For internet versus web, give both sides: internet = the network hardware; web = the pages that use it.

    Why: A description needs both sides to get two marks.

  5. In matching tables, tick one term per row.

    Why: Rows with two ticks score zero.

Do not lose marks here

  • ✗
    Saying the internet and the web are the same thing.
  • ✗
    Reversing DNS: saying it turns an IP address into a domain name.
  • ✗
    Calling 'www.cloudisfab.com' the URL; it is the domain name, and the URL is the whole address.
  • ✗
    Labelling a folder in the path as the file name.
  • ✗
    Ticking two terms in one row of a matching table.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. Split https://www.cloudisfab.com/re12/ru2.mp3 at '://' and each '/'.
  2. Piece 1: https, the protocol.
  3. Piece 2: www.cloudisfab.com, the domain name of the web server.
  4. Piece 3: re12, a folder on the server.
  5. Piece 4: ru2.mp3, the file being requested (an MP3 audio file).
Model answer · written by olevels.com, not an official Pearson mark scheme

https: the protocol (HyperText Transfer Protocol Secure) used to fetch the file securely. www.cloudisfab.com: the domain name of the website, identifying the web server. re12: a folder (directory) on the web server, part of the path to the file. ru2.mp3: the name of the file being requested, an MP3 music file.

How the marks are earned

One mark per row: protocol, domain name, folder, file name.
