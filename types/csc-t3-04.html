Knowledge card

Hexadecimal: why we use it and how to convert

Written
  • Hexadecimal (hex) is base 16.
  • Hex uses the digits 0 to 9 and then the letters A to F for the values 10 to 15.
  • A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
  • One hex digit stands for exactly one nibble (4 bits), because 4 bits give 16 patterns.
  • So one byte (8 bits) is always written as two hex digits.
  • Nibble place values are 8, 4, 2, 1.
  • Denary values from 0 to 15 become a single hex digit.
  • Hexadecimal is base 16; denary is base 10; binary is base 2.
  • Hex digits are 0-9 and A-F.
  • One hex digit matches one nibble (4 bits) because 2 to the power 4 is 16.

Before you begin

  • Unsigned binary to denary conversion (CSC-T3-01)
  • What a nibble is
  • Number bases: binary, denary, hexadecimal
1

The method

  1. Split the 8-bit pattern into two nibbles of 4 bits.

    Why: Each nibble becomes one hex digit.

  2. Convert each nibble to denary using 8 4 2 1.

    Why: This gives a value from 0 to 15 for each half.

  3. Replace any value from 10 to 15 with its letter A to F.

    Why: Hex needs a single symbol for each digit.

  4. Write the two digits in the same order as the nibbles: left nibble first.

    Why: The order matters; swapping digits gives a different number.

  5. For a small denary number (0-15), write its single hex digit directly.

    Why: No splitting is needed when the value fits in one nibble.

  6. Recall the base: hex is base 16.

    Why: Several options test whether you know the base.

  7. Remember that hex is only a way for humans to write binary.

    Why: This rules out any option that says hex is faster or smaller for the computer.

Do not lose marks here

  • ✗
    Writing 11 instead of B (a two-digit denary value instead of one hex digit).
  • ✗
    Swapping the order of the two hex digits.
  • ✗
    Converting the whole byte to denary (185) and stopping there.
  • ✗
    Mixing up the letters, for example C for 13.
  • ✗
    Choosing 'takes less memory', although hex values are stored as binary of the same length.
  • ✗
    Choosing 'processed faster', although the computer only ever works in binary.

Worked explanation

  1. Split 1011 1001 into 1011 and 1001.
  2. Left nibble 1011: 8 + 2 + 1 = 11, and 11 is B.
  3. Right nibble 1001: 8 + 1 = 9, and 9 stays as 9.
  4. Keep the order: B then 9.
Model answer · written by olevels.com, not an official Pearson mark scheme

B9

How the marks are earned

One mark for B in the first position and one mark for 9 in the second position.

Calculation check

  • hex(int('10111001', 2))[2:].upper() = B9
  • int('1011', 2) = 11
  • int('1001', 2) = 9
