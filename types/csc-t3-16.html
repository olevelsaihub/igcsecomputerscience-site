Kilobytes and kibibytes

Written

Decimal prefixes step by 1000 (kilobyte, megabyte). Binary prefixes step by 1024 (kibibyte, mebibyte). So a kibibyte is slightly bigger than a kilobyte. Convert through bytes.

  • Decimal (SI) prefixes go up in steps of 1000: 1 kilobyte (kB) = 1000 bytes, 1 megabyte (MB) = 1000 kB.
  • Binary (IEC) prefixes go up in steps of 1024: 1 kibibyte (KiB) = 1024 bytes, 1 mebibyte (MiB) = 1024 KiB.
  • 1000 is 10^3 (base 10); 1024 is 2^10 (base 2).
  • So a kibibyte is slightly bigger than a kilobyte.
  • To convert, change to bytes with one factor, then divide by the other factor.
  • Example: 500,000 bytes = 0.5 MB, but 500 KiB = 512,000 bytes.
  • SI is the International System of Units; IEC is the International Electrotechnical Commission.

The method

  1. Sort the units

    kB, MB decimal; KiB, MiB binary.

  2. To bytes

    Use the unit's own factor.

  3. Divide

    By the factor of the unit you want.

  4. Compare

    Contrast both sides with whereas.

Do not lose marks here

  • ✗
    Kilobyte as 1024

    Kilobyte is 1000.

  • ✗
    Multiplying

    Going to bigger units, divide.

  • ✗
    One unit only

    Describe both in a compare.

Worked explanation

  1. 13 kilobytes is decimal: 1 kB = 1000 bytes.
  2. So 13 kB = 13 x 1000 bytes = 13,000 bytes.
  3. A kibibyte is 1024 bytes, so divide by 1024.
  4. Expression: (13 x 1000) / 1024.
  5. Value if worked out: about 12.70 KiB (not required).
