Knowledge card

Kilobytes and kibibytes

Written
  • Decimal (SI) prefixes go up in steps of 1000: 1 kilobyte (kB) = 1000 bytes, 1 megabyte (MB) = 1000 kB.
  • Binary (IEC) prefixes go up in steps of 1024: 1 kibibyte (KiB) = 1024 bytes, 1 mebibyte (MiB) = 1024 KiB.
  • 1000 is 10^3 (base 10); 1024 is 2^10 (base 2).
  • So a kibibyte is slightly bigger than a kilobyte.
  • To convert, change to bytes with one factor, then divide by the other factor.
  • Example: 500,000 bytes = 0.5 MB, but 500 KiB = 512,000 bytes.
  • SI is the International System of Units; IEC is the International Electrotechnical Commission.

Before you begin

  • Powers of 10 and powers of 2
  • Bits and bytes
1

The method

  1. Work out which units are decimal (kB, MB, GB) and which are binary (KiB, MiB, GiB).

    Why: Each uses a different factor.

  2. Change the given amount into bytes using its own factor.

    Why: Bytes are the common unit both systems share.

  3. Divide by the factor for the unit you want.

    Why: This expresses the amount in the new unit.

  4. When comparing, give a contrast for each point: kilobyte is 1000 bytes whereas kibibyte is 1024 bytes.

    Why: A compare question needs both sides of each point.

Do not lose marks here

  • ✗
    Thinking a kilobyte is 1024 bytes.
  • ✗
    Multiplying by 1024 instead of dividing when going to kibibytes.
  • ✗
    Describing only one unit in a compare question.
  • ✗
    Mixing up SI and IEC.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. 13 kilobytes is decimal: 1 kB = 1000 bytes.
  2. So 13 kB = 13 x 1000 bytes = 13,000 bytes.
  3. A kibibyte is 1024 bytes, so divide by 1024.
  4. Expression: (13 x 1000) / 1024.
  5. Value if worked out: about 12.70 KiB (not required).
