Knowledge card

Functions, procedures, parameters and libraries

Written

A subprogram is a named block that does one job. A function always returns a value; a procedure need not. Both can use parameters. A library is a collection of pre-written, already tested subprograms.

  • A subprogram is a named block of code that does one job and can be called (run) from other parts of the program.
  • A function is a subprogram that always sends a value back to the code that called it, using return.
  • A procedure is a subprogram that carries out a task but does not have to return a value.
  • Functions and procedures can both take parameters, use local variables and be reused many times.
  • A parameter is a named input listed in the subprogram's header, e.g. def area(pLength, pWidth):
  • Parameters let the same subprogram work with different data each time it is called, so it is reusable.
  • A built-in subprogram comes ready-made with the language, such as print(), len(), int() and input() in Python.
  • A library is a collection of pre-written subprograms that can be imported, e.g. import random.
  • Library code has already been tested, so it saves the programmer time and is less likely to contain errors.

Worked explanation

  1. Think about what happens when each subprogram finishes.
  2. A function finishes with return and hands a value back, e.g. total = addUp(a, b).
  3. A procedure just does its job, e.g. printing a menu, and need not hand anything back.
  4. Write the function half, then 'whereas', then the procedure half.
Model answer · written by olevels.com, not an official Pearson mark scheme

A function always sends a value back to the code that called it, whereas a procedure carries out its task without needing to send back a value.

How the marks are earned

One mark for saying a function returns a value. One mark for the contrast that a procedure does not have to.
