Knowledge card

Caesar cipher

Written

A Caesar cipher shifts every letter the same number of places; the shift is the key. The alphabet wraps from Z to A. To decrypt, use the opposite shift. It is weak: only 25 shifts to try.

  • A Caesar cipher shifts every letter the same number of places along the alphabet.
  • The shift is the key; a positive shift moves forward (A to D for +3) and a negative shift moves back.
  • The alphabet wraps round: after Z comes A again, and before A comes Z.
  • To decrypt, apply the opposite shift.
  • Two shifts in a row add together: -6 then +8 is the same as +2.
  • There are only 25 useful shifts, so an attacker can try them all quickly (a brute-force attack).
  • Letter frequency (for example E is the most common English letter) can also reveal the shift.

The method

  1. Number the alphabet

    A = 0 to Z = 25, if it helps.

  2. Move each letter

    Wrap past Z or A.

  3. Find a shift

    Count the gap for one letter.

  4. Combine shifts

    Add them.

  5. Weakness

    Few keys, so easy to try them all.

Do not lose marks here

  • ✗
    No wrap

    After Z comes A.

  • ✗
    Wrong direction

    A negative shift moves back.

  • ✗
    Sign missing

    Write + or − with the shift.

Worked explanation

  1. Row 1: PIXEL with shift -4. Move each letter back 4 places.
  2. P back 4 is L. I back 4 is E. X back 4 is T. E back 4 is A. L back 4 is H.
  3. So PIXEL becomes LETAH.
  4. Row 2: CLOUD becomes FORXG. Compare C with F: C, D, E, F is 3 places forward.
  5. Check the others: L to O, O to R, U to X, D to G are all +3.
  6. So the shift is +3.
Model answer · written by olevels.com, not an official Pearson mark scheme

Row 1 ciphertext: LETAH. Row 2 shift: +3.

How the marks are earned

One mark for LETAH and one mark for +3.

Calculation check

  • ''.join(chr((ord(c) - 65 - 4) % 26 + 65) for c in 'PIXEL') = LETAH
  • ''.join(chr((ord(c) - 65 + 3) % 26 + 65) for c in 'CLOUD') = FORXG
  • (ord('F') - ord('C')) % 26 = 3
