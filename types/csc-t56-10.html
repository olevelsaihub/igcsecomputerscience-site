Knowledge card

Finding and fixing weaknesses: penetration testing, ethical hacking, code reviews, audit trails

Written

A vulnerability is a weakness. Methods such as penetration testing, code review and audit trails find or trace weaknesses before attackers use them. State what each is and what it achieves.

  • A vulnerability is a weakness in a system that an attacker could use to get in or cause harm.
  • Penetration testing is an authorised, simulated attack on your own system to find its weaknesses so they can be fixed.
  • Ethical hackers ('white hat' hackers) break in with the owner's permission, do not steal or change data, and report what they find.
  • Commercial analysis tools are programs that automatically scan a network or software for known weaknesses and produce a report.
  • Network and user policies are the rules for how devices and people use the network; they should be reviewed regularly to keep up with new threats and laws.
  • A code review is when other programmers check code to find bugs, security holes and poor programming practices before it is released.
  • An audit trail is an automatic record of what was done on a system and who did it, which helps spot suspicious activity and trace problems back to their source.
  • Modular testing means testing each subprogram on its own as it is written, so errors are found early and in a small piece of code.
  • Secure design also includes thinking about security from the start, keeping operating systems updated and writing secure code.

Worked explanation

  1. Say what penetration testing is: an authorised, pretend attack on the organisation's own network.
  2. Say its purpose: to find weaknesses before real attackers do.
  3. Say what happens next: weaknesses are reported and fixed, making the network safer.
Model answer · written by olevels.com, not an official Pearson mark scheme

Penetration testing is an authorised, simulated attack on the organisation's own network. Its purpose is to find weaknesses in the security before real criminals discover them, so that the IT team can report and fix them and the network becomes harder to break into.

How the marks are earned

One mark for finding weaknesses (vulnerabilities) in the system. One mark for the linked follow-up: fixing them, or the fact that it is an authorised test of the security measures.

June 2022 · Paper 1 · Q6(d)

Answer plan

  1. List the three methods named in the question: ethical hacking, commercial analysis tools, review of policies.
  2. Ethical hacking: who does it, what they try (with permission), what Santiago receives (a report of weaknesses), one drawback.
  3. Analysis tools: what a scanner checks automatically, the report it produces, why running it regularly helps, one limitation.
  4. Policy review: what the policies are (passwords, access rights, devices), why they go out of date, why reviews must be scheduled.
  5. Keep linking each method to finding AND fixing weaknesses in Santiago's network.
  6. Conclude: each method covers a different type of weakness, so use them together.
