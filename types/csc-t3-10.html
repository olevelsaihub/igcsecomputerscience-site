Knowledge card

Pixels, resolution and colour depth

Written
  • A bitmap image is made of a grid of tiny squares called pixels.
  • A pixel (picture element) is the smallest part of a bitmap image; each pixel has one colour.
  • Resolution describes how much detail there is: often given as width x height in pixels, or as pixels per inch (ppi), pixels per centimetre or dots per inch (dpi).
  • Colour depth is the number of bits used to store the colour of each pixel.
  • More colour depth means more possible colours (2^n) but more bits for every pixel.
  • File size grows with the number of pixels and with the colour depth.
  • Image file size in bits = width x height x colour depth (before any metadata or compression).

Before you begin

  • 2 to the power n (CSC-T3-08)
  • Bits and bytes
1

The method

  1. For definitions, give the short key phrase: a pixel is the smallest element of a bitmap image.

    Why: One clear phrase earns the mark.

  2. For resolution, give a unit such as pixels per inch or dots per inch.

    Why: The question asks for a measurement, not a description.

  3. For file size questions, start at a single pixel: more colour depth means more bits for it.

    Why: The reason works pixel by pixel.

  4. Then scale up: every pixel needs those extra bits, so the whole file is bigger.

    Why: The second mark needs the link from one pixel to the whole image.

Do not lose marks here

  • ✗
    Defining a pixel as 'a part of the screen' without saying it is the smallest element.
  • ✗
    Giving 'megabytes' or 'cm squared' as a measure of resolution.
  • ✗
    Writing only the file-size formula without explaining the extra bits per pixel.
  • ✗
    Saying more colour depth means 'more pixels'; the number of pixels does not change.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

How each command word is answered

Command wordTimes askedWhat to write
State2One word or short phrase, such as 'pixel'.

What a complete response includes

Recall questions give one mark for the term or unit. The describe question gives one mark for the idea of a single pixel needing more bits, and one for linking that to the size of the whole image.

Worked explanation

  1. Colour depth is the number of bits stored for each pixel.
  2. If colour depth goes up, every single pixel now needs more bits.
  3. The number of pixels stays the same, so the total number of bits for the image goes up.
  4. Example: a 100 x 100 image at 8 bits per pixel needs 80,000 bits; at 16 bits per pixel it needs 160,000 bits.
Model answer · written by olevels.com, not an official Pearson mark scheme

Increasing the colour depth means every pixel is stored using more bits, and since the image has the same number of pixels, the total number of bits needed for the whole image (and so the file size) increases.

How the marks are earned

One mark for referring to each pixel, and a linked second mark for explaining that each pixel then needs more bits to store its colour.

Calculation check

  • 100 × 100 × 8 = 80000
  • 100 × 100 × 16 = 160000
