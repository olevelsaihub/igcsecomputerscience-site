Pixels, resolution and colour depth

Written

A bitmap is a grid of pixels, the smallest elements, each with one colour. Resolution is the detail; colour depth is the bits per pixel. More depth means more bits for every pixel.

  • A bitmap image is made of a grid of tiny squares called pixels.
  • A pixel (picture element) is the smallest part of a bitmap image; each pixel has one colour.
  • Resolution describes how much detail there is: often given as width x height in pixels, or as pixels per inch (ppi), pixels per centimetre or dots per inch (dpi).
  • Colour depth is the number of bits used to store the colour of each pixel.
  • More colour depth means more possible colours (2^n) but more bits for every pixel.
  • File size grows with the number of pixels and with the colour depth.
  • Image file size in bits = width x height x colour depth (before any metadata or compression).

Worked explanation

  1. Colour depth is the number of bits stored for each pixel.
  2. If colour depth goes up, every single pixel now needs more bits.
  3. The number of pixels stays the same, so the total number of bits for the image goes up.
  4. Example: a 100 x 100 image at 8 bits per pixel needs 80,000 bits; at 16 bits per pixel it needs 160,000 bits.
Model answer · written by olevels.com, not an official Pearson mark scheme

Increasing the colour depth means every pixel is stored using more bits, and since the image has the same number of pixels, the total number of bits needed for the whole image (and so the file size) increases.

How the marks are earned

One mark for referring to each pixel, and a linked second mark for explaining that each pixel then needs more bits to store its colour.

Calculation check

  • 100 × 100 × 8 = 80000
  • 100 × 100 × 16 = 160000
