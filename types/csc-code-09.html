Knowledge card

The final 20-mark program

Written
  • The last Paper 2 question is worth 20 marks: 11 for meeting the listed requirements and up to 9 for overall quality (a levels band).
  • Decomposition means breaking the problem into smaller parts; writing a subprogram for each part shows this clearly.
  • Parallel arrays hold related data at the same index, e.g. tbl_breed[3] and tbl_count[3] describe the same breed.
  • A two-dimensional array is a list of lists; table[row][column] picks one item.
  • Loop with range(len(array)) or for item in array so the program still works if the data changes size (no hard-coded counts).
  • A tracker variable (such as bestIndex or longestWord) remembers the best item found so far while a loop runs.
  • Comments, meaningful names, constants and labelled, tidy output all help earn the band marks.
  • Test every requirement against the running program before you finish.

Before you begin

  • 1D, 2D and parallel arrays
  • for and while loops
  • Selection with relational and logical operators
  • Subprograms with parameters and return
  • String handling and formatted output
1

The method

  1. Turn every bullet into a numbered checklist and decide which subprogram or loop will meet each one.

    Why: Each requirement is a functionality point, and planning the parts shows decomposition for the band.

  2. Study the data: which arrays, which index means what, and what needs a total or a tracker.

    Why: Correct use of the data structures is credited and avoids indexing mistakes.

  3. Build and run one requirement at a time, looping with len() rather than fixed numbers.

    Why: Small steps find errors early, and avoiding hard-coding is needed for the flexibility marks.

  4. Use selection and trackers for searches, best/worst values and ordering.

    Why: The comparison logic is usually several of the 11 points.

  5. Add comments, clear names and labelled output that suits the stated audience.

    Why: Readability and fitness for purpose decide the band.

  6. Re-read every bullet and test with the given data and one changed data set.

    Why: The band's top level needs every requirement met and a flexible program.

Do not lose marks here

  • ✗
    Hard-coding the number of items (range(12)) or the answer itself, which loses flexibility marks.
  • ✗
    Starting a tracker at 0 when looking for a smallest value, so it is never replaced; start from the first item instead.
  • ✗
    Mixing up indexes between parallel arrays or rows and columns of a 2D array.
  • ✗
    Meeting only some bullets because the checklist was not re-read at the end.
  • ✗
    One long block of code with no comments or subprograms, which keeps the band low.
  • ✗
    Output with no headings or labels, which is not fit for the audience.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. Checklist: (1) daily volume per breed, (2) store it in tbl_dailyVolume, (3) header line, (4) one row per breed, (5) herd total, (6) find best breed, (7) show it by name.
  2. Data: four parallel arrays, so index i means the same breed in each. Loop with range(len(tbl_breed)) so more or fewer breeds still work.
  3. calculateDailyVolumes(): for each index, volume per cow x count, appended to tbl_dailyVolume (e.g. Red Chittagong 7.5 x 6 = 45.0).
  4. displayTable(): print a header naming every column, a dividing line, then each breed's values in lined-up columns.
  5. calculateHerdTotal(): a running total of tbl_dailyVolume, rounded to 1 decimal place: 905.4 litres.
  6. findBestBreed(): bestIndex starts at 0. A breed wins if its rating number is lower (1 is best), or if the rating is the same and its milk per cow is higher. Joining the two tests with or, and the second pair with and, is the key logic.
  7. Rating-1 breeds are Red Chittagong 7.5, Vorderwald 15.2, Jersey 18.3 and Alderney 9.0, so Jersey is recommended.
  8. Main program: call the subprograms in order and print the total and the recommended breed with labels.

# Q06

tbl_breed = ["Red Chittagong", "Sussex", "Dexter", "Abondance", "Sahiwal", "Vorderwald", "Ayrshire", "Jersey", "Randall", "Alderney", "Carora", "Gloucester"] tbl_rating = [1, 2, 3, 2, 3, 1, 2, 1, 2, 1, 3, 2] tbl_count = [6, 3, 8, 7, 6, 4, 3, 7, 3, 3, 4, 7] tbl_volume = [7.5, 5.7, 11.4, 11.4, 22.0, 15.2, 21.0, 18.3, 19.0, 9.0, 23.1, 16.0] tbl_dailyVolume = []

# ---------------------------------------------- # Write your code below this line

# The arrays are "parallel": index i in every array describes the same breed. # len(tbl_breed) is used everywhere, so the program still works if breeds are added or removed.

def calculateDailyVolumes(): # Daily volume for a breed = milk per cow x number of cows. # Each answer is added to the end of tbl_dailyVolume, so it lines up with the other arrays. for index in range(len(tbl_breed)): dailyVolume = tbl_volume[index] * tbl_count[index] tbl_dailyVolume.append(round(dailyVolume, 1)) # round(…, 1) hides tiny float errors

def displayTable(): # Header row tells the farmer what each column holds print(f"{'Breed':<16}{'Rating':>7}{'Volume per cow':>16}{'Count':>7}{'Total volume':>14}") print("-" * 60) for index in range(len(tbl_breed)): print(f"{tbl_breed[index]:<16}{tbl_rating[index]:>7}{tbl_volume[index]:>16}" f"{tbl_count[index]:>7}{tbl_dailyVolume[index]:>14}") print("-" * 60)

def calculateHerdTotal(): # Running total of every breed's daily volume total = 0.0 for index in range(len(tbl_dailyVolume)): total = total + tbl_dailyVolume[index] return round(total, 1)

def findBestBreed(): # Best breed = best care rating (1 is best, so the LOWEST number wins); # when two breeds share that rating, the larger volume per cow wins. bestIndex = 0 # start by assuming the first breed is best for index in range(1, len(tbl_breed)): betterRating = tbl_rating[index] < tbl_rating[bestIndex] sameRatingMoreMilk = (tbl_rating[index] == tbl_rating[bestIndex]) and \ (tbl_volume[index] > tbl_volume[bestIndex]) if betterRating or sameRatingMoreMilk: bestIndex = index return bestIndex

# ---------------- main program ---------------- calculateDailyVolumes() displayTable()

herdTotal = calculateHerdTotal() print("Total daily volume for the whole herd:", herdTotal, "litres")

best = findBestBreed() print("Recommended breed:", tbl_breed[best], "(care rating", str(tbl_rating[best]) + ",", tbl_volume[best], "litres per cow per day)")

Band: four small subprograms, comments, meaningful names, len()-controlled loops and a lined-up table aim at the top band.

# Worked example for CSC-CODE-09 (4CP0-2023-JUN-02-standard-Q06-whole). Authored by olevels.com; not Pearson's code.
# Q06

tbl_breed = ["Red Chittagong", "Sussex", "Dexter", "Abondance",
             "Sahiwal", "Vorderwald", "Ayrshire", "Jersey",
             "Randall", "Alderney", "Carora", "Gloucester"]
tbl_rating = [1, 2, 3, 2, 3, 1, 2, 1, 2, 1, 3, 2]
tbl_count = [6, 3, 8, 7, 6, 4, 3, 7, 3, 3, 4, 7]
tbl_volume = [7.5, 5.7, 11.4, 11.4,
              22.0, 15.2, 21.0, 18.3,
              19.0, 9.0, 23.1, 16.0]
tbl_dailyVolume = []

# ----------------------------------------------
# Write your code below this line

# The arrays are "parallel": index i in every array describes the same breed.
# len(tbl_breed) is used everywhere, so the program still works if breeds are added or removed.


def calculateDailyVolumes():
    # Daily volume for a breed = milk per cow x number of cows.
    # Each answer is added to the end of tbl_dailyVolume, so it lines up with the other arrays.
    for index in range(len(tbl_breed)):
        dailyVolume = tbl_volume[index] * tbl_count[index]
        tbl_dailyVolume.append(round(dailyVolume, 1))   # round(…, 1) hides tiny float errors


def displayTable():
    # Header row tells the farmer what each column holds
    print(f"{'Breed':<16}{'Rating':>7}{'Volume per cow':>16}{'Count':>7}{'Total volume':>14}")
    print("-" * 60)
    for index in range(len(tbl_breed)):
        print(f"{tbl_breed[index]:<16}{tbl_rating[index]:>7}{tbl_volume[index]:>16}"
              f"{tbl_count[index]:>7}{tbl_dailyVolume[index]:>14}")
    print("-" * 60)


def calculateHerdTotal():
    # Running total of every breed's daily volume
    total = 0.0
    for index in range(len(tbl_dailyVolume)):
        total = total + tbl_dailyVolume[index]
    return round(total, 1)


def findBestBreed():
    # Best breed = best care rating (1 is best, so the LOWEST number wins);
    # when two breeds share that rating, the larger volume per cow wins.
    bestIndex = 0                      # start by assuming the first breed is best
    for index in range(1, len(tbl_breed)):
        betterRating = tbl_rating[index] < tbl_rating[bestIndex]
        sameRatingMoreMilk = (tbl_rating[index] == tbl_rating[bestIndex]) and \
                             (tbl_volume[index] > tbl_volume[bestIndex])
        if betterRating or sameRatingMoreMilk:
            bestIndex = index
    return bestIndex


# ---------------- main program ----------------
calculateDailyVolumes()
displayTable()

herdTotal = calculateHerdTotal()
print("Total daily volume for the whole herd:", herdTotal, "litres")

best = findBestBreed()
print("Recommended breed:", tbl_breed[best],
      "(care rating", str(tbl_rating[best]) + ",", tbl_volume[best], "litres per cow per day)")
