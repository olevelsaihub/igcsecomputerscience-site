Knowledge card

The TCP/IP model: four layers and what each does

Written
  • Data sent over a network is broken into small pieces called packets.
  • The TCP/IP model has four layers, from top to bottom: application, transport, network and data link.
  • Application layer: holds the protocols that programs use, such as HTTP, FTP and SMTP, and talks to the user's software.
  • Transport layer: on sending, splits data into packets and numbers them; on receiving, checks they all arrived, puts them back in order and asks for any missing or damaged ones to be sent again.
  • Network layer: adds the sender's and receiver's IP addresses and routes each packet across networks towards its destination.
  • Data link layer: moves the packets across the physical connection between two devices, using MAC addresses.
  • When sending, data passes down the layers; when receiving, it passes back up, and each layer removes what its partner layer added.
  • Using layers means each layer can be changed or fixed without changing the others.

The method

  1. Write the four layers in order down the margin: application, transport, network, data link.

    Why: Having the list in front of you stops you naming a layer that is already given or inventing one.

  2. Find the job in the question and match it to its layer using the key words: protocols for programs, split and reassemble, IP addresses and routing, physical transfer and MAC addresses.

    Why: Each job belongs to one layer.

  3. Check whether the question is about sending or receiving.

    Why: Receiving-end tasks are the reverse: reassembling, checking, stripping addresses.

  4. Write the layer name and its function next to each other.

    Why: In tables, the function only earns its mark if it matches the layer named.

  5. Do not repeat layers or tasks the question has already given.

    Why: Answers copied from the stem earn nothing.

Do not lose marks here

  • ✗
    Writing 'data layer' or 'network' instead of 'data link layer'.
  • ✗
    Giving the network layer the job of splitting data into packets (that is the transport layer).
  • ✗
    Naming the layers already given in the question.
  • ✗
    Giving a function that belongs to a different layer from the one named in the same row.
  • ✗
    Writing 'receives packets from the network layer' as a task when the question already says that.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

How each command word is answered

Command wordTimes askedWhat to write
State1Two short, different tasks, each a few words starting with a verb (checks, reassembles, requests).
Give2Name the layer(s) or one task, briefly. Use the full layer name, for example 'data link', not just 'data'.
Complete1Write a layer name in each row and a function that belongs to that same layer.
multiple-choice2Choose exactly one letter. Cross out a wrong choice cleanly; two marked boxes score zero. Physical transfer across a link is data link; routing end to end is network.

Now see it used on a real past-paper question

What a complete response includes

One mark per correct layer name and one per function that truly belongs to the layer named. Receiving-side tasks such as reordering, checking and asking for re-sends are credited.

Worked explanation

  1. Choose two layers you know best: transport and network.
  2. Transport: think about what happens to the data first. It is split into packets and each packet is numbered.
  3. Network: think about how packets find their way. IP addresses are added and packets are routed.
  4. Write each function next to its own layer in the table.
Model answer · written by olevels.com, not an official Pearson mark scheme

Layer 1: Transport. Function: splits the data into packets and gives each packet a sequence number so they can be put back in order. Layer 2: Network. Function: adds the source and destination IP addresses to each packet and routes it across the networks to its destination.

How the marks are earned

One mark for each correct layer name (transport, network). One mark for each function that matches its own layer (splitting and numbering for transport; adding IP addresses and routing for network).
