Knowledge card

Write a short number program from a list of requirements

Written
  • Every program has inputs, processing and outputs; list them before you write code.
  • int(input(...)) reads a whole number and float(input(...)) reads a decimal.
  • Python's arithmetic operators are + - * / plus // (whole-number division), % (remainder) and ** (power).
  • A band table (such as prices for 1-5, 6-9, 10 or more) becomes an if/elif/else chain with exact boundaries.
  • Testing the largest band first lets each elif rely on the earlier tests having failed.
  • A for loop with range repeats a known number of times; range(1, 13) gives 1 to 12.
  • A while loop repeats until a condition becomes False, which suits 'stop when...' requirements.
  • Print results with labels so the user knows what each number means.

Before you begin

  • Variables, data types and conversion
  • Arithmetic operators
  • if/elif/else
  • for and while loops
1

The method

  1. Underline each requirement and write it as a comment in the seed.

    Why: Each requirement is usually one mark, and comments make the plan easy to follow.

  2. Read and convert the inputs with int() or float().

    Why: Calculations and comparisons need numbers, not strings.

  3. Write the selection or loop the requirements describe, with exact boundaries.

    Why: Boundaries such as 'at least' and 'more than' are where marks are lost.

  4. Do each calculation once, outside the if where possible.

    Why: This avoids repeated code, and some schemes reward it directly.

  5. Print labelled results and test with the example and every boundary.

    Why: Output must match what the question shows.

Do not lose marks here

  • ✗
    Leaving gaps or overlaps between bands, such as testing quantity > 5 and quantity > 6 so 6 lands in the wrong band.
  • ✗
    Repeating the cost calculation and print inside every branch instead of once after the if.
  • ✗
    Forgetting int() so the input is treated as text.
  • ✗
    Using range(12) when the values 1 to 12 are needed (range(12) gives 0 to 11).
  • ✗
    Printing numbers with no labels.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. Inputs: number of textbooks. Processing: choose a price, multiply. Outputs: price each and total.
  2. Initialise: quantity = 0, pricePerBook = 0.0, totalCost = 0.0.
  3. quantity = int(input("Enter the number of textbooks required: ")).
  4. Bands: test the biggest first. if quantity >= 10: 12.00; elif quantity >= 6: 15.00; else: 20.00. An order of 6 to 9 reaches the elif only because the first test failed.
  5. After the if: totalCost = quantity * pricePerBook (one line, not one per branch).
  6. Print both values with labels and two decimal places using format(value, ".2f").
  7. Test 5, 6, 9 and 10 (the boundaries): £20.00/£100.00, £15.00/£90.00, £15.00/£135.00, £12.00/£120.00.
Model answer · written by olevels.com, not an official Pearson mark scheme

quantity = 0 pricePerBook = 0.0 totalCost = 0.0 quantity = int(input("Enter the number of textbooks required: ")) if quantity >= 10: pricePerBook = 12.00 elif quantity >= 6: pricePerBook = 15.00 else: pricePerBook = 20.00 totalCost = quantity * pricePerBook print("Price per textbook: £" + format(pricePerBook, ".2f")) print("Total cost of the order: £" + format(totalCost, ".2f"))

How the marks are earned

A meaningful variable name (1); one band and price right (1); all three bands right (1); total = quantity x price (1); both values displayed (1); the calculation and output written once, after the if (1).

Calculation check

  • 5 × 20.00 = 100.0
  • 6 × 15.00 = 90.0
  • 9 × 15.00 = 135.0
  • 10 × 12.00 = 120.0

Worked program

Written by olevels.com and tested against the paper’s examples.

# Worked example for CSC-CODE-05 (4CP0-2022-JUN-02-standard-Q03-whole). Authored by olevels.com; not Pearson's code.
# Q03

#  Initialise variables
quantity = 0
pricePerBook = 0.0
totalCost = 0.0

#  Print prompt and take number of textbooks required
quantity = int(input("Enter the number of textbooks required: "))

#  Generate and display the price per textbook and the total cost
# Test the biggest band first, so each elif only sees smaller orders
if quantity >= 10:
    pricePerBook = 12.00
elif quantity >= 6:
    pricePerBook = 15.00
else:
    pricePerBook = 20.00

# The calculation and output sit outside the if, so they are written only once
totalCost = quantity * pricePerBook

print("Price per textbook: £" + format(pricePerBook, ".2f"))
print("Total cost of the order: £" + format(totalCost, ".2f"))
