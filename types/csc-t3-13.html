Knowledge card

Sound sampling: analogue to digital

Written
  • Sound in the real world is an analogue signal: a smooth wave that changes continuously.
  • A computer stores sound as a digital signal: a list of separate binary numbers.
  • Sampling means measuring the amplitude (height) of the sound wave at regular time intervals.
  • Each measurement (sample) is stored as a binary number.
  • Sampling frequency (sample rate) is the number of samples per second, measured in hertz (Hz).
  • Bit depth is the number of bits used for each sample.
  • A higher sampling frequency or bit depth gives a closer copy of the original sound but a larger file.
  • On a sound graph the x-axis is time (seconds) and the y-axis is amplitude.

Before you begin

  • Binary numbers
  • Reading graphs
  • 2 to the power n for bit depth (CSC-T3-08)
1

The method

  1. Identify the smooth curve as analogue and the stepped line as digital.

    Why: Many short questions ask which line is which.

  2. To find the sampling frequency, count how many samples are taken in one second and give the unit Hz.

    Why: Frequency means 'per second'.

  3. When describing conversion, give the steps in order: set the sample rate and bit depth, measure the amplitude at each interval, turn each measurement into a binary number, store the numbers.

    Why: A describe question rewards each linked step.

  4. For effects of a change, say both what happens to quality and what happens to file size.

    Why: Either effect earns a mark, and giving both is safer.

  5. When plotting, put each sample value at the correct time and join them as steps.

    Why: Marks go for correct points, the start and the digital shape.

Do not lose marks here

  • ✗
    Swapping analogue and digital.
  • ✗
    Leaving out the unit Hz for sampling frequency.
  • ✗
    Describing playback (speakers) instead of recording and storage.
  • ✗
    Labelling the x-axis 'amplitude' and the y-axis 'time'.
  • ✗
    Saying a higher sample rate changes the volume.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

What a complete response includes

Short questions earn one mark for each correct identification, value with unit, axis label or effect. Describe questions give one mark for each distinct step in order. Plotting earns marks for correct points, the right starting point and drawing the digital wave.

Worked explanation

  1. Start with the analogue sound, a smooth wave picked up by a microphone.
  2. Choose the sample rate (samples per second) and bit depth (bits per sample).
  3. Measure the amplitude of the wave at each regular time interval.
  4. Turn each measurement into a binary number using the chosen bit depth.
  5. Store all the binary values, with the sample rate, as the digital sound file.
  6. Example: at 44,100 Hz, 2 seconds of sound gives 88,200 samples.
Model answer · written by olevels.com, not an official Pearson mark scheme

First the sample rate and bit depth are set. Then the analogue sound is sampled: its amplitude is measured at regular time intervals. Each measured amplitude is given a binary value using the chosen number of bits. Finally these binary values are stored, together with the sample rate, as the digital sound file.

How the marks are earned

One mark per distinct step, up to three: setting the sample rate or bit depth, measuring the amplitude at intervals, giving each measurement a binary value, and storing the values.

Calculation check

  • 44100 × 2 = 88200
