Knowledge card

Sound sampling: analogue to digital

Written

Real sound is a smooth analogue wave. To store it, the computer samples it: it measures the amplitude at regular times and stores each as a binary number. More samples or bits mean a closer copy and a bigger file.

  • Sound in the real world is an analogue signal: a smooth wave that changes continuously.
  • A computer stores sound as a digital signal: a list of separate binary numbers.
  • Sampling means measuring the amplitude (height) of the sound wave at regular time intervals.
  • Each measurement (sample) is stored as a binary number.
  • Sampling frequency (sample rate) is the number of samples per second, measured in hertz (Hz).
  • Bit depth is the number of bits used for each sample.
  • A higher sampling frequency or bit depth gives a closer copy of the original sound but a larger file.
  • On a sound graph the x-axis is time (seconds) and the y-axis is amplitude.

The method

  1. Spot the type

    Smooth is analogue; stepped is digital.

  2. Frequency

    Count samples in one second; add Hz.

  3. Describe conversion

    Set rate and depth, measure, make binary, store.

  4. Effects

    Say quality and file size.

  5. Graphs

    x is time; y is amplitude.

Worked explanation

  1. Start with the analogue sound, a smooth wave picked up by a microphone.
  2. Choose the sample rate (samples per second) and bit depth (bits per sample).
  3. Measure the amplitude of the wave at each regular time interval.
  4. Turn each measurement into a binary number using the chosen bit depth.
  5. Store all the binary values, with the sample rate, as the digital sound file.
  6. Example: at 44,100 Hz, 2 seconds of sound gives 88,200 samples.
Model answer · written by olevels.com, not an official Pearson mark scheme

First the sample rate and bit depth are set. Then the analogue sound is sampled: its amplitude is measured at regular time intervals. Each measured amplitude is given a binary value using the chosen number of bits. Finally these binary values are stored, together with the sample rate, as the digital sound file.

How the marks are earned

One mark per distinct step, up to three: setting the sample rate or bit depth, measuring the amplitude at intervals, giving each measurement a binary value, and storing the values.

Calculation check

  • 44100 × 2 = 88200
