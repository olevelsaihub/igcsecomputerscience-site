Knowledge card

Bubble sort, one pass at a time

Written

A bubble sort compares neighbouring pairs and swaps them if they are in the wrong order. Each pass pushes the largest unsorted item to the end, and the sort stops after a pass with no swaps.

  • A bubble sort puts a list in order by comparing each pair of neighbouring items and swapping them if they are in the wrong order.
  • One pass means going through the whole list once, from the first pair to the last pair.
  • After the first pass of an ascending sort, the largest item has 'bubbled' to the end; after the second pass, the two largest are in place.
  • The sort stops after a pass in which no swaps happen; that final checking pass still counts as a pass.
  • Bubble sort sorts in place: it only needs one extra variable to hold a value during a swap.
  • Ascending means smallest to largest; descending means largest to smallest; for words, alphabetical order is used.

The method

  1. Compare the first pair

    Swap if they are in the wrong order.

  2. Move one place along

    Repeat to the last pair, counting swaps.

  3. Write the row

    Write the whole list once, after the pass.

  4. Repeat passes

    Keep going until a pass makes no swaps.

  5. Count passes

    Include that last no-swap pass.

Do not lose marks here

  • ✗
    A row per swap

    Rows are for complete passes only.

  • ✗
    Too much moved

    Pass 1 puts only the largest item in place.

  • ✗
    Missing check pass

    The final no-swap pass still counts.

  • ✗
    Wrong direction

    Check: ascending or descending?

What a complete response includes

One mark for each correct completed pass. Swap counts and number of passes earn one mark each, and the pass count must include the final checking pass. Rows showing single swaps are ignored, and putting the fully sorted list first scores nothing.

Worked explanation

  1. Start: 9, 11, 12, 19, 14, 18, 15 and 17.
  2. Pass 1: 9/11, 11/12 and 12/19 are in order. 19/14 swap, 19/18 swap, 19/15 swap, 19/17 swap. After the first pass: 9, 11, 12, 14, 18, 15, 17 and 19 (4 swaps).
  3. Pass 2: pairs up to 14/18 are in order. 18/15 swap, 18/17 swap, 18/19 in order. After pass 2: 9, 11, 12, 14, 15, 17, 18 and 19 (2 swaps).
  4. Pass 3: no swaps, so the sort stops. The least number of passes is 3.
  5. After pass 2 the unsorted tail (19, 14, 18, 15, 17 at the start) has become 14, 15, 17, 18, 19 in order, so pass 3 is the check pass with no swaps: 3 passes in all.
Model answer · written by olevels.com, not an official Pearson mark scheme

After the first pass: 9, 11, 12, 14, 18, 15, 17 and 19. After the second pass: 9, 11, 12, 14, 15, 17, 18 and 19. (Swaps in pass 1: 4. Least number of passes: 3.)

How the marks are earned

One mark for the pass 1 row, where only 19 has moved, to the end. One mark for the pass 2 row, where only 18 has moved, into second-last place.

Calculation check

  • sum(1 for x in [14, 18, 15, 17] if x < 19) = 4
  • sum(1 for x in [15, 17] if x < 18) = 2
  • sum(1 for i in [0, 1, 2, 3, 4] for j in [0, 1, 2, 3, 4] if i < j and [19, 14, 18, 15, 17][i] > [19, 14, 18, 15, 17][j]) = 6
  • str(sorted([19, 14, 18, 15, 17])) = [14, 15, 17, 18, 19]
