What algorithms are and how we write them down

Written

An algorithm is a precise, ordered list of steps. It can be written as a flowchart, pseudocode, plain English or program code. A trace table tests one by hand; it is not a way of writing one.

  • An algorithm is a precise, ordered list of steps that solves a problem or carries out a task.
  • An algorithm can be written as a flowchart, as pseudocode, as a written description in plain English, or as program code.
  • A flowchart is visual and needs no programming knowledge, so it suits a non-technical audience.
  • Pseudocode looks like simple code written with English words but is not tied to the syntax (exact rules) of one language.
  • A trace table has a column for each variable or output and rows that show how the values change as the algorithm runs.
  • Trace tables are filled in by hand to test an algorithm, follow how it works, and find logic errors.
  • A truth table tests logic, and a cipher is a method of encryption; neither is a way of writing an algorithm.

Worked explanation

  1. The audience is non-technical managers, so they do not know programming languages.
  2. Choose a method they can follow: a flowchart.
  3. Justify it with a feature that suits them: it is visual and does not need any code syntax.
Model answer · written by olevels.com, not an official Pearson mark scheme

Method: flowchart. Justification: it shows the steps visually with shapes and arrows, so the managers can follow the logic without knowing the syntax of any programming language.

How the marks are earned

One mark for naming a suitable method (flowchart). One mark for a reason that fits the audience: it is visual and needs no knowledge of programming syntax.
