How many patterns from n bits

Knowledge card

How many patterns from n bits

Calculation
  • Each extra bit doubles the number of different patterns.
  • n bits can make 2 to the power n different patterns (2^n).
  • 1 bit gives 2, 2 bits give 4, 3 bits give 8, 4 bits give 16, 8 bits give 256.
  • Colour depth is the number of bits used for each pixel; 2^n colours are possible with n bits.
  • Bit depth in sound is the number of bits per sample; 2^n levels are possible.
  • To find the minimum bits for k items, find the smallest n where 2^n is at least k.
  • With n bits, unsigned values run from 0 to 2^n - 1.
  • Every item must get its own different code, and all codes should be the same length.

Before you begin

  • Powers of 2
  • Binary counting
1

The method

  1. Decide which way round the question is: bits to patterns, or items to bits.

    Why: The two directions use the same rule in reverse.

  2. Bits to patterns: work out 2 to the power n.

    Why: Each bit doubles the choices.

  3. Items to bits: list 2, 4, 8, 16, 32 ... and stop at the first number that is at least the number of items.

    Why: Fewer bits would not give every item its own code.

  4. If asked for codes, give each item a different pattern using exactly that many bits (start at 000 and count up).

    Why: Counting up guarantees no code is repeated.

  5. If asked to justify, link the number of bits to the number of values it can hold.

    Why: The justification mark needs the 2^n link.

Do not lose marks here

  • ✗
    Using n x 2 or n squared instead of 2 to the power n.
  • ✗
    Giving 2^n - 1 (the largest value) when the question asks for the number of patterns.
  • ✗
    Using codes of different lengths, such as 0, 1, 10, 11, 100.
  • ✗
    Repeating a code for two colours.
  • ✗
    Choosing more bits than the minimum needed.

Now see it used on a real past-paper question

What a complete response includes

Single answers earn one mark for the right count or bit number. Code tables earn one mark for using the minimum length throughout and one for no repeats. Justifications earn a mark for linking the bits to how many values they can store.

Worked explanation

  1. There are 5 colours.
  2. 2 bits give 4 patterns: not enough. 3 bits give 8 patterns: enough.
  3. So use 3 bits for every colour.
  4. Count up in 3-bit binary, starting from 001 here (starting from 000 is just as good): Green 001, Black 010, White 011, Red 100, Blue 101.
  5. Check: all five codes are 3 bits long and no two are the same.
Model answer · written by olevels.com, not an official Pearson mark scheme

Green 001; Black 010; White 011; Red 100; Blue 101 (any five different 3-bit patterns are correct).

How the marks are earned

One mark for using 3 bits in every code and one mark for having no code repeated.

Calculation check

  • len(bin(5 - 1)) - 2 = 3
  • 2 × × 3 = 8
  • 2 × × 2 = 4
  • [format(i, '03b') for i in range(1, 6)] = ['001', '010', '011', '100', '101']
