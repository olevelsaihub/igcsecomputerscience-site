Knowledge card

How many patterns from n bits

Calculation

Each extra bit doubles the patterns: n bits give 2ⁿ patterns. To find the fewest bits for k items, find the smallest n where 2ⁿ ≥ k.

  • Each extra bit doubles the number of different patterns.
  • n bits can make 2 to the power n different patterns (2^n).
  • 1 bit gives 2, 2 bits give 4, 3 bits give 8, 4 bits give 16, 8 bits give 256.
  • Colour depth is the number of bits used for each pixel; 2^n colours are possible with n bits.
  • Bit depth in sound is the number of bits per sample; 2^n levels are possible.
  • To find the minimum bits for k items, find the smallest n where 2^n is at least k.
  • With n bits, unsigned values run from 0 to 2^n - 1.
  • Every item must get its own different code, and all codes should be the same length.

The calculation

Patterns = 2ⁿ (n bits)

1 bit: 2, 2 bits: 4, 3 bits: 8, 4 bits: 16, 8 bits: 256

  • Unsigned values run from 0 to 2ⁿ − 1.
  • Fewest bits: stop at the first 2ⁿ that is enough.

Try itGive codes to 5 colours using the fewest bits.

  1. 2 bits give 4: not enough.
  2. 3 bits give 8: enough, so use 3 bits each.
  3. Count up: 001, 010, 011, 100, 101.
  4. All five are 3 bits long and all different.

The method

  1. Pick the direction

    Bits to patterns, or items to bits.

  2. Bits to patterns

    Work out 2ⁿ.

  3. Items to bits

    List 2, 4, 8, 16, 32 and stop at the first that is enough.

  4. Write codes

    Count up in binary, all the same length.

  5. Justify

    Link the bits to the 2ⁿ patterns.

Do not lose marks here

  • ✗
    n × 2 or n²

    The rule is 2 to the power n.

  • ✗
    2ⁿ − 1

    That is the largest value, not the count.

  • ✗
    Too many bits

    Use the minimum.

Worked explanation

  1. There are 5 colours.
  2. 2 bits give 4 patterns: not enough. 3 bits give 8 patterns: enough.
  3. So use 3 bits for every colour.
  4. Count up in 3-bit binary, starting from 001 here (starting from 000 is just as good): Green 001, Black 010, White 011, Red 100, Blue 101.
  5. Check: all five codes are 3 bits long and no two are the same.
Model answer · written by olevels.com, not an official Pearson mark scheme

Green 001; Black 010; White 011; Red 100; Blue 101 (any five different 3-bit patterns are correct).

How the marks are earned

One mark for using 3 bits in every code and one mark for having no code repeated.

Calculation check

  • len(bin(5 - 1)) - 2 = 3
  • 2 × × 3 = 8
  • 2 × × 2 = 4
  • [format(i, '03b') for i in range(1, 6)] = ['001', '010', '011', '100', '101']
