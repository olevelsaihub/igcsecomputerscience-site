Knowledge card

What the operating system does, and system vs application software

Written
  • System software runs and looks after the computer itself; the operating system (OS) and utility programs are system software.
  • Application software lets the user do a task, such as writing a letter or editing a photo.
  • Operating system functions include process management, memory management, file management, peripheral (device) management, security and user management, and providing a user interface.
  • Multitasking on one CPU works because the OS scheduler gives each process a short time slice in turn.
  • Processes wait in a queue, and some processes may be given higher priority.
  • When storing a file, the OS checks there is enough free space and splits the file into blocks.
  • The blocks can be stored anywhere on the disc, and the OS records where each block is in a file allocation table.
  • The OS also stores metadata about each file, such as its permissions and the date it was created.

The method

  1. Decide whether the question is about OS functions, a specific OS process, or the two software categories.

    Why: Each needs different content.

  2. For functions, name them as 'X management' (process, memory, file, peripheral, security, user).

    Why: A bare word like 'memory' or 'files' may not be credited; the management idea is needed.

  3. For a 'how' question, describe the steps in order (check space, split into blocks, store blocks, update the table).

    Why: Each correct step is a separate mark.

  4. For sharing the CPU, mention the scheduler, a queue, priorities and short time slices.

    Why: These are the creditable ideas; memory management is off-topic here.

  5. For system versus application, say what each one does in one linked sentence using 'whereas'.

    Why: A difference needs both sides.

Do not lose marks here

  • ✗
    Repeating the user interface when the question has already given it.
  • ✗
    Writing 'memory' or 'files' alone instead of memory management or file management.
  • ✗
    Describing memory management when the question asks how the CPU is shared.
  • ✗
    Describing only one category when asked for a difference between system and application software.
  • ✗
    Giving brand names (such as a particular word processor) instead of the purpose.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

What a complete response includes

One mark per correct, distinct function or step. Comparison questions need a linked statement covering both system and application software. Process-sharing answers are credited for scheduler, queue, priority and time-slice ideas only.

Worked explanation

  1. The question is about sharing one CPU between several processes.
  2. Recall the OS part that decides who goes next: the scheduler.
  3. Recall how it shares: processes wait in a queue and each gets the CPU for a short time slice.
  4. Write two separate points.
Model answer · written by olevels.com, not an official Pearson mark scheme

The operating system uses a scheduler, which keeps the processes waiting in a queue. Each process is then given the CPU for a short time slice before being swapped out for the next one, so all of them appear to run at the same time.

How the marks are earned

One mark for the scheduler or queue idea and one mark for each process getting a short time slice before being swapped (any two creditable points).
