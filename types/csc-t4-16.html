Knowledge card

Translators: assembler, compiler and interpreter

Written

An assembler translates assembly language. A compiler translates the whole program once. An interpreter translates and runs one line at a time, every run.

  • A translator converts source code into machine code that the CPU can run.
  • An assembler translates assembly language (low-level) into machine code.
  • A compiler translates the whole high-level program in one go and produces an executable file of object code.
  • Once compiled, the program runs without the compiler, runs quickly, and the source code does not need to be shared.
  • A compiler reports a list of errors after it has translated the whole program.
  • An interpreter translates and runs a high-level program one line at a time, every time it is run.
  • An interpreter stops when it reaches an error, which helps during testing, and the same source code can run on any machine that has the interpreter.
  • Assembled and compiled code can run without the translator in memory; interpreted code needs the interpreter each time.

Worked explanation

  1. Statement 1: does not have to be in memory to run the translated code. Assembled and compiled code run on their own, so tick Assembler and Compiler.
  2. Statement 2: translates high-level source code. Interpreters and compilers do this, so tick Interpreter and Compiler.
  3. Statement 3: runs high-level code until it ends or hits a syntax error. Only an interpreter runs code as it translates, so tick Interpreter.
  4. Statement 4: translates low-level source code into machine code. That is the assembler's job, so tick Assembler.
  5. Check each column: Assembler (1, 4), Interpreter (2, 3), Compiler (1, 2).
Model answer · written by olevels.com, not an official Pearson mark scheme

Does not have to be in memory to execute the translated code: Assembler and Compiler. Translates high-level source code: Interpreter and Compiler. Executes high-level code until finished or a syntax error: Interpreter. Translates low-level source code into machine code: Assembler.

How the marks are earned

One mark for each fully correct column: Assembler ticked for statements 1 and 4, Interpreter for statements 2 and 3, Compiler for statements 1 and 2.

November 2020 · Paper 1 · Q6(c)

Answer plan

  1. Note the command word: discuss similarities AND differences of compiler and interpreter.
  2. Open with 2 similarities: both turn high-level code into machine code; one statement becomes many instructions; both find errors.
  3. Difference 1: whole program at once and saved executable vs one line at a time, nothing saved; explain the effect on run speed.
  4. Difference 2: error reporting; list at the end vs stops at the first error; explain why interpreters help while testing.
  5. Difference 3: distribution; executable needs no extra software and hides source but is machine-specific vs interpreter needed on every machine, source visible but portable.
  6. Write each difference as a pair joined by 'whereas' or 'but', then say what it means for the user or programmer.
  7. Conclude: which suits development and which suits the finished product, linked to the scenario.
