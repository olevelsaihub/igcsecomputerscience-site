Knowledge card

Simulations and models: why we use them and their limits

Written

A model uses rules and data to represent a real system, and a simulation runs it. Give one point and a linked effect, and remember the results are only as good as the data.

  • A model is a set of rules and data that represents a real system; a simulation runs the model to see what happens over time.
  • Simulations let people test situations that would be dangerous, costly or impossible in real life.
  • Variables can be changed to ask 'what if' questions and see how the outcome changes.
  • A simulation can be run faster or slower than real time, so long-term trends can be seen quickly.
  • Simulations help to predict outcomes and test ideas (hypotheses).
  • A simulation is only as good as its data and assumptions; if these are wrong, the results will be wrong.
  • Simulations can need a powerful processor because they handle large amounts of data and many calculations, sometimes with complex graphics.

The method

  1. Pick the aim

    Benefit, problem or hardware need.

  2. One clear point

    Variables changed, run faster, safer.

  3. Link it

    Say the effect in the scenario.

  4. Skip given points

    Do not repeat or use banned ones.

  5. Use 'so'

    Point, so effect.

Do not lose marks here

  • ✗
    Two unrelated points

    One point plus its link scores more.

  • ✗
    Always accurate

    It depends on data.

  • ✗
    Powerful because big

    Say data and calculations.

Worked explanation

  1. The question has already used 'simpler than monitoring real animals', so choose a different benefit.
  2. Pick one: the simulation can run much faster than real life.
  3. Link it to the scenario: years of rabbit and fox populations can be seen in minutes.
  4. So the long-term trends become visible quickly.
Model answer · written by olevels.com, not an official Pearson mark scheme

The simulation can be run much faster than real life, so Peter can see what happens to the rabbit and fox populations over many generations in a short time and spot long-term trends.

How the marks are earned

One mark for the benefit (running faster than real time) and one linked mark for the result in the scenario (many generations and long-term trends seen quickly).
