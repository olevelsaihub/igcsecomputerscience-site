Knowledge card

Read and write text files line by line

Written

Open the file with the right mode, loop over each line, then strip, split and convert with int(). When writing, join the fields with commas and end every record with \n. Always close.

  • open(name, "r") opens a file to read; "w" creates a new file to write (wiping any old one); "a" adds to the end.
  • for line in theFile: visits each line of an open file in turn.
  • Each line read from a file ends with a newline character; .strip() removes it.
  • .split(",") breaks a line into a list of strings at each comma.
  • Values read from a file are strings; use int() or float() before doing arithmetic.
  • To write, build one string per record, join fields with commas, add "\n" at the end and call write().
  • Always close a file with .close() when you have finished with it.
  • A running total starts at 0 before the loop and grows inside it.

Before you begin

  • for loops over a list
  • String methods strip() and split()
  • int() / str() conversion
  • Running totals

  3. Split: stringSales = line.strip ().split (COMMA) gives five strings such as '264'.
  4. subTotal = 0 for each line, then for sale in stringSales: subTotal = subTotal + int (sale).

  • sum([799,811,788,814,788]) = 4000
  • sum([982,1007,1013,989,1009]) = 5000

Worked program

Written by olevels.com and tested against the paper’s examples.

# Worked example for CSC-CODE-08 (4CP0-2024-JUN-02-standard-Q05-c). Authored by olevels.com; not Pearson's code.
# Q05c

INPUT_FILE = "Sales.txt"    # Output file name
COMMA = ","                 # Use as a constant

subTotal = 0        # Subtotal for each line
grandTotal = 0      # Running total

# Complete the code to open the file for reading
theFile = open (INPUT_FILE, "r")

# Complete the code to read each line of the input file
for line in theFile:

    # Complete the code to split the line into a set of five strings
    stringSales = line.strip ().split (COMMA)

    subTotal = 0
    # Add code to sum up each value in the set of five strings
    for sale in stringSales:
        subTotal = subTotal + int (sale)

    # Add code to display the subtotal for the line
    print (subTotal)

    # Add code to calculate the running total
    grandTotal = grandTotal + subTotal

# Add code to display the total of all lines in the file
print ("Grand total:", grandTotal)

# Complete the code to close the opened file
theFile.close ()
