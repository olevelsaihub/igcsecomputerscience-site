Knowledge card

Binary to denary and back (unsigned, 0 to 255)

Written

Every bit in a byte has a place value: 128, 64, 32, 16, 8, 4, 2, 1. Add the values under the 1s to get denary; take away the biggest value that fits to get binary.

  • Binary is base 2: each digit (a bit) is either 0 or 1.
  • Denary is our everyday base 10 number system.
  • In an 8-bit number the place values, from left to right, are 128, 64, 32, 16, 8, 4, 2 and 1.
  • Unsigned means the number has no sign, so it is always zero or positive.
  • With 8 unsigned bits you can store whole numbers from 0 (00000000) to 255 (11111111).
  • A nibble is a group of 4 bits; a byte is 8 bits, or two nibbles.
  • To change binary to denary, add up the place values that sit under each 1.
  • To change denary to binary, take away the biggest place value that fits, write a 1 there, and repeat with what is left.
  • If the bit on the far right (worth 1) is 0, the number is even; if the far-left bit (worth 128) is 1, the number is at least 128.

2

The routine

Denary = sum of the place values under each 1

Place values: 128 64 32 16 8 4 2 1

  • 8 bits go from 0 (0000 0000) to 255 (1111 1111).
  • Start at 128, not 256.
  • Something left over at the end means a subtraction slip.

Try itConvert 200 to 8-bit binary.

  1. 128 fits: 1. 200 − 128 = 72 left.
  2. 64 fits: 1. 72 − 64 = 8 left.
  3. 32 and 16 do not fit: 0 0.
  4. 8 fits: 1. 8 − 8 = 0 left.
  5. 4, 2 and 1: 0 0 0.
  6. 1100 1000. Check: 128 + 64 + 8 = 200.

The method

  1. Write the headers

    128 64 32 16 8 4 2 1 above your working.

  2. Binary → denary

    Add the place values above every 1; ignore the 0s.

  3. Denary → binary

    From 128 down: if it fits, write 1 and subtract; if not, write 0.

  4. Finish at zero

    At the 1 column, nothing should be left.

  5. Check backwards

    Convert your answer back. It takes seconds.

Do not lose marks here

  • ✗
    Too few bits

    8-bit means 8 digits: pad with zeros on the left.

  • ✗
    Reversed order

    The 128 bit is on the left.

  • ✗
    Negative options

    Unsigned numbers are never negative, so cross those out in a multiple-choice question.

Worked explanation

  1. Write the headers: 128 64 32 16 8 4 2 1.
  2. 128 does not fit into 60, so write 0. 64 does not fit, so write 0.
  3. 32 fits: write 1; 60 - 32 = 28 left.
  4. 16 fits into 28: write 1; 28 - 16 = 12 left.
  5. 8 fits into 12: write 1; 12 - 8 = 4 left.
  6. 4 fits: write 1; 4 - 4 = 0 left.
  7. Nothing is left, so the 2 and 1 columns are 0.
  8. Pattern: 0011 1100. Check: 32 + 16 + 8 + 4 = 60.
Model answer · written by olevels.com, not an official Pearson mark scheme

0011 1100

How the marks are earned

One mark for the left nibble 0011 and one mark for the right nibble 1100, each in the correct position.

Calculation check

  • format(60, '08b') = 00111100
  • int('00111100', 2) = 60
  • 32 + 16 + 8 + 4 = 60
