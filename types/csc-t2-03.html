Knowledge card

Local and global variables

Written

The scope of a variable is where it can be used. A global variable is created in the main program and can be used anywhere. A local variable is created inside a subprogram and can be used only there.

  • The scope of a variable is the part of the program where it can be used.
  • A global variable is created in the main program, at the top level, outside any subprogram.
  • A global variable can be read from anywhere in the program.
  • A local variable is created inside a subprogram (a def block in Python).
  • A local variable can only be used inside the subprogram where it was created.
  • A local variable disappears when its subprogram finishes, which frees its memory.
  • Parameters behave like local variables: they only exist inside their subprogram.
  • Two subprograms can each have a local variable with the same name without clashing.

Worked explanation

  1. Start with the global variable: where is it made? In the main program, outside every subprogram.
  2. Where can it be used? Anywhere in the program.
  3. Now the local variable: where is it made? Inside a subprogram.
  4. Where can it be used? Only inside that subprogram.
  5. Write both sentences.
Model answer · written by olevels.com, not an official Pearson mark scheme

A global variable is created in the main program and can be used from any part of the program. A local variable is created inside a subprogram and can only be used within that subprogram.

How the marks are earned

One mark for the global sentence (created in main program / usable anywhere). One mark for the local sentence (created in a subprogram / usable only there).
