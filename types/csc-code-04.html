Knowledge card

Turn a flowchart or pseudocode into Python

Written

Each flowchart box or pseudocode line has a Python partner: process → assignment, input → int(input()), diamond → if, loop-back arrow → while. Keep the design's names and order.

  • An algorithm is a step-by-step set of instructions for solving a problem; a flowchart and pseudocode are two ways of writing one down.
  • A rectangle (process box) or SET line becomes an assignment, e.g. answer = 1.
  • An input box or RECEIVE ... (INTEGER) line becomes int(input(...)).
  • A diamond (decision) or IF line becomes an if or if/else in Python.
  • An arrow that loops back, or a WHILE line, becomes a while loop with the same condition.
  • Pseudocode DIV is Python //, MOD is %, and RANDOM(n) maps to random.randint.
  • Keep the variable names and messages from the design, so each part can be matched and marked.
  • A loop needs a variable that changes inside it, or it will never stop.

Worked explanation

  1. Initialise variables: base = 1 (anything but 0, so the loop starts), exponent = 0, answer = 1, count = 0.
  2. The 'Is base equal to 0?' diamond leads to Stop, and the other arrows lead back to 'Enter value for base'. So wrap everything in while base != 0: and input base at the top.
  3. Only carry on if base is not 0: input exponent with int().
  4. 'Is exponent negative?' Yes leads to an error message: if exponent < 0: print an error.
  5. Otherwise set answer = 1 and count = 0, then while count < exponent: answer = answer * base and count = count + 1.
  6. When the inner loop ends, inform the user: print(base, "to the power of", exponent, "is", answer).
  7. Test: 2 and 0 gives 1; 3 and 4 gives 81; 5 and -1 gives the error; 0 stops the program.

How the marks are earned

Sensible names and starting values (2 marks); a while loop that keeps the program running and a test that ends it when base is 0 (2); an if that catches a negative exponent and a clear error message (2); the answer worked out and worked out with a counting loop as in the flowchart (2); clear prompts and output (1); correct results for the test data (1).

Calculation check

  • pow(2, 0) = 1
  • pow(3, 4) = 81
  • pow(-2, 3) = -8

# Worked example for CSC-CODE-04 (4CP0-2023-JUN-02-standard-Q03-c). Authored by olevels.com; not Pearson's code.
# Q03c

# -----------------------------------------------------
# Write your code below this line

# Initialise variables
base = 1          # any value except 0, so the main loop starts
exponent = 0
answer = 1
count = 0

# Main loop: keep going until the user enters 0 for the base
while base != 0:
    base = int(input("Enter the base (0 to stop): "))

    if base != 0:
        exponent = int(input("Enter the exponent: "))

        # A negative exponent is not allowed
        if exponent < 0:
            print("Error: the exponent must be 0 or more")
        else:
            # Multiply answer by base, exponent times
            answer = 1
            count = 0
            while count < exponent:
                answer = answer * base
                count = count + 1

            # Inform the user of the result
            print(base, "to the power of", exponent, "is", answer)
