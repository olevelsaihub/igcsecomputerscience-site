Knowledge card

Compression: lossy or lossless?

Written

Compression makes files smaller, so they use less storage and send faster. Lossy removes data for ever (JPEG, MP3). Lossless loses nothing and rebuilds exactly (PNG, RLE). Text and code must be lossless.

  • Compression means making a file smaller.
  • Smaller files take less storage space and are faster to send over a network.
  • Lossy compression permanently removes some data, so the original can never be rebuilt exactly; examples are JPEG and MP3.
  • Lossy compression usually gives much smaller files, and people often cannot notice the missing detail in pictures or music.
  • Lossless compression shrinks the file without losing any data, so the original can be rebuilt exactly; examples are PNG and run-length encoding.
  • Lossless files are usually bigger than lossy ones.
  • Text, documents and program code must use lossless compression, because losing any character changes the meaning.
  • Drawbacks of compression include the time to compress and decompress and the need for compatible software.

Worked explanation

  1. The file is an instruction manual: text.
  2. The proofreader must see every word exactly as written.
  3. Lossy compression would permanently delete some data, which could remove or change letters.
  4. So choose lossless: the file is rebuilt exactly when it is decompressed.
Model answer · written by olevels.com, not an official Pearson mark scheme

Method: lossless. Justification: lossless compression keeps all of the data, so the manual can be decompressed back to exactly the original. With lossy compression some characters could be lost for ever, which would change the meaning of the instructions and stop the proofreader checking and correcting the real text.

How the marks are earned

One mark for choosing lossless, and up to two for linked reasons: no data is lost so the original is rebuilt exactly, and losing data would change the text so it could not be checked properly.
