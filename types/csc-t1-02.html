Knowledge card

Say what an algorithm (or one line) does

Written

To say what an algorithm does, dry-run it with a tiny example and compare what goes in with what comes out. Name the job in one plain sentence, then add a second linked point for 2 marks.

  • The purpose of an algorithm is the job it does for the user, said in plain words (for example: reverses a list, checks whether a number is prime).
  • The best way to find the purpose is to dry-run it with a tiny example and compare what goes in with what comes out.
  • A temporary variable (often called temp) holds one value during a swap, because copying a over b would otherwise lose b's old value.
  • Adding 1 to an index or counter moves the algorithm to the next item; without it a loop could repeat for ever (an infinite loop).
  • A FOR loop that counts from LENGTH(list) - 1 down to 0 with STEP -1 visits the items from last to first.
  • A test can be redundant: if an earlier IF has already limited the possible values, a later IF that checks the only remaining value is not needed.
  • A subprogram is a named block of code that can be called; its purpose is described by what it returns or outputs for its parameters.

The method

  1. Pick a small input

    Easy numbers.

  2. Dry-run quickly

    Compare input with output.

  3. Name the job

    One sentence, not line by line.

  4. Add a linked point

    For 2 marks: the result or what is output.

  5. For one line

    What it changes, then what goes wrong without it.

Do not lose marks here

  • ✗
    Retelling lines

    Name the overall job.

  • ✗
    One point only

    2 marks need 2 linked points.

  • ✗
    Using the name

    Describe what the code does, not what its name suggests.

Give3One reason or purpose only, in a single sentence.
Describe3Two linked points: the main task and then what it produces or outputs.
Explain1A point and its reason, joined with 'because' or 'so', e.g. what the line does and what would be lost without it.

Worked explanation

  1. Ignore the fault on line 8, as the question says to assume it has been fixed (score is set to 0 only once, before the loop).
  2. The loop runs 10 times. Each time, first and second get random numbers and answer is set to their sum.
  3. The question is shown, the user types an answer, and if it equals answer the score goes up by 1.
  4. After the loop, the score is displayed.
  5. So the job is an addition quiz of 10 questions that reports how many the user got right.
Model answer · written by olevels.com, not an official Pearson mark scheme

It is an addition quiz: it asks the user ten questions that add two random numbers, compares each typed answer with the correct total, and adds one to the score for each correct answer. At the end it displays the score, showing how many questions were answered correctly.

How the marks are earned

First mark: saying it asks repeated adding questions with random numbers (the quiz idea). Second mark: the linked point that it checks the answers, keeps a score, and outputs that final score.

Calculation check
