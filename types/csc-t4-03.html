Knowledge card

The stored program concept and the parts of the CPU

Written

The stored program concept: instructions and data are kept together in main memory, and the CPU fetches, decodes and executes them one at a time. The CU controls, the ALU calculates, registers are fast stores.

  • The stored program concept (from von Neumann) means both program instructions and data are kept together in main memory.
  • The CPU fetches the instructions from memory one at a time, decodes them and executes them.
  • A program instruction is a single command that tells the CPU what action to carry out.
  • A memory address is a number that identifies one location in memory, like a house number on a street.
  • The control unit (CU) controls the fetch-decode-execute cycle and sends signals to other parts of the computer.
  • The arithmetic logic unit (ALU) does calculations (such as adding) and logic comparisons (such as greater than).
  • Registers are tiny, very fast storage locations inside the CPU that hold data or addresses while they are being used.
  • Named registers include the program counter (PC), memory address register (MAR), memory data register (MDR), current instruction register (CIR) and accumulator (ACC).

The method

  1. Find the term

    Instruction, address, register, CU or ALU.

  2. One plain sentence

    What it does or identifies.

  3. Stored program

    Storing and running.

  4. Labelling

    CU and ALU inside the CPU; memory outside.

  5. Registers

    PC, MAR, MDR, CIR, ACC.

Do not lose marks here

  • ✗
    Only instructions

    Data is stored too.

  • ✗
    CU or ALU

    The CU controls; the ALU calculates.

  • ✗
    Address as data

    An address is a place.

Worked explanation

  1. Read the term: program instruction.
  2. Think: a program is a list of commands. One command in that list is one instruction.
  3. Say what it does: it tells the CPU what action to perform, such as add two numbers or move data.
  4. Write it as one clear sentence.
Model answer · written by olevels.com, not an official Pearson mark scheme

A program instruction is a single command that tells the CPU what operation to carry out, for example to add two numbers.

How the marks are earned

One mark for saying the instruction is an operation or command that the CPU carries out or is told to do.
