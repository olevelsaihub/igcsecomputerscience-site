Knowledge card

Spot selection and iteration, and pick the right loop

Written

Sequence runs steps in order, selection chooses a path with a condition, and iteration repeats a block. A for loop counts, a while loop tests first, and REPEAT ... UNTIL tests last.

  • Sequence means instructions run one after another in order.
  • Selection means the program chooses a path using a condition: IF ... THEN ... ELSE (if/elif/else in Python).
  • Iteration means repeating a block of code; it is also called a loop.
  • In a flowchart, a decision diamond with no arrow going back up is selection; an arrow looping back is iteration.
  • A count-controlled loop repeats a fixed number of times: FOR in pseudocode, for in Python.
  • A pre-conditioned loop checks its condition before each pass and may run zero times: WHILE in pseudocode and Python.
  • A post-conditioned loop checks its condition after each pass, so it always runs at least once: REPEAT ... UNTIL in pseudocode.
  • A condition-controlled loop can stop as soon as its job is done, which avoids wasted passes.
  • The keyword if starts selection; for and while start iteration.

Worked explanation

  1. The loop on lines 10 to 15 keeps adding 1 to testNum and checks whether testNum divides the number exactly.
  2. It stops when testNum reaches the number OR when flag becomes TRUE (a divisor is found).
  3. Try number = 9: testNum = 2 does not divide 9; testNum = 3 does (9 MOD 3 = 0), so flag becomes TRUE and the loop stops after only 2 passes.
  4. A count-controlled loop from 2 to 9 would always do 8 passes, even after the answer is known.
  5. So the benefit is efficiency, because the loop ends as soon as a divisor is found.
Model answer · written by olevels.com, not an official Pearson mark scheme

It is more efficient, because the post-conditioned loop ends the moment a factor of the number is found (number MOD testNum = 0), whereas a count-controlled loop would keep going for a fixed number of passes even after the answer is known.

How the marks are earned

One mark for the benefit (more efficient / fewer comparisons). One mark for the linked reason (it ends the moment a factor is found).

Calculation check

  • 9 % 2 = 1
  • 9 % 3 = 0
  • 9 - 2 + 1 = 8
