Knowledge card

Network topologies: bus, ring, star and mesh

Written
  • A topology is the layout of how the devices in a network are connected.
  • Bus: every device joins one shared main cable (the backbone) with a terminator at each end.
  • Bus: cheap and needs little cable, but if the main cable breaks the whole network fails, and it slows down with more devices because data collides more often.
  • Ring: devices are joined in a closed loop and data travels in one direction, so packets do not collide; if one link breaks the ring can fail.
  • Star: every device has its own cable to a central switch (or hub); one broken cable affects only that device and faults are easy to find.
  • Star: if the central switch fails, the whole network stops, and it needs more cable than a bus.
  • Mesh: each device is connected to several others (full mesh = every device connects to every other); there are many routes, so data can go around a broken link.
  • Mesh: very reliable but expensive, with lots of cabling and harder to set up and manage.
  • The internet is a huge partial mesh, which lets it grow and keep working when parts fail.

The method

  1. Look at the layout: one shared cable = bus; closed loop = ring; everything to one central box = star; many cross-links = mesh.

    Why: Naming the topology correctly is the first mark and the basis for everything else.

  2. Recall that topology's typical strength and weakness.

    Why: Benefits and drawbacks are specific to each layout.

  3. For Explain, name the structural feature first, then its effect, joined with 'so' or 'because'.

    Why: Two-mark explanations need the feature and the consequence.

  4. In a matching table, put exactly one tick per row.

    Why: A row with two ticks scores nothing.

Do not lose marks here

  • ✗
    Calling a star a bus because the drawing has a line across the middle; look for the central box.
  • ✗
    Saying 'it is cheaper' with no comparison or reason.
  • ✗
    Giving a drawback of a different topology, such as 'if the main cable fails' for a star.
  • ✗
    Explaining fault tolerance with only 'it is reliable' and no mention of multiple routes.
  • ✗
    Saying 'the computer fails' when the point is a link or node failing and traffic rerouting.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. The figure shows a partially connected mesh: each computer has links to several others.
  2. Feature: there is more than one path between any two devices.
  3. Consequence: if one link breaks or is busy, packets go another way and still arrive.
  4. Join the two parts with 'so'.
Model answer · written by olevels.com, not an official Pearson mark scheme

In a mesh, every node is linked to two or more other nodes, so there are several possible routes between any two devices. If one cable or node fails or becomes congested, the packets are simply sent along another route and still reach their destination.

How the marks are earned

One mark for the effect: packets still reach the destination when a link is damaged or congested. One mark for the reason: each node has several connections, giving multiple routes.
