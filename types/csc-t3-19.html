Knowledge card

Vigenere cipher

Written

The Vigenere cipher repeats a keyword under the message, giving each letter its own Caesar shift. Encrypt: keyword row, plaintext column. Decrypt: find the cipher letter in the keyword row, read the column heading.

  • The Vigenere cipher uses a keyword to give a different Caesar shift to each letter.
  • The keyword is written again and again under the message until every letter has a keyword letter.
  • In the Vigenere square, each row starts with a different letter: row a is no shift, row b is shift 1, and so on.
  • To encrypt: find the keyword letter's row and the plaintext letter's column; the letter where they meet is the ciphertext.
  • To decrypt: go to the keyword letter's row, find the ciphertext letter in that row, and read the letter at the top of its column.
  • Using numbers (a=0 ... z=25): ciphertext = (plain + key) mod 26 and plain = (cipher - key) mod 26.
  • Because the shift keeps changing, Vigenere is harder to crack than a Caesar cipher.

The method

  1. Write the keyword

    Repeat it under the message.

  2. Find the row

    The row starting with the keyword letter.

  3. Use the square

    Encrypt: read to the column. Decrypt: read the heading.

  4. Check

    The result should make words.

Do not lose marks here

  • ✗
    Keyword not repeated

    Repeat it all the way.

  • ✗
    Wrong row

    Use the keyword row, not the plaintext row.

  • ✗
    Meeting letter

    When decrypting, read the heading.

Worked explanation

  1. The encrypted text is flmktrwhee.
  2. Repeat the keyword 'thirty' under it, one keyword letter per encrypted letter: thirtythir.
  3. Letter 1: in row t, find f; its column heading is m.
  4. Letter 2: in row h, find l; column heading e. Letter 3: row i, find m; heading e. Letter 4: row r, find k; heading t.
  5. Letters 5 to 10: row t, r gives a; row y, r gives t; row t, w gives d; row h, h gives a; row i, e gives w; row r, e gives n.
  6. Read the decrypted letters together: meetatdawn, which is 'meet at dawn'.
Model answer · written by olevels.com, not an official Pearson mark scheme

Keyword row (one letter per cell): thirtythir. Decrypted row (one letter per cell): meetatdawn. Message: meet at dawn.

How the marks are earned

One mark for lining up the keyword letters with the encrypted letters, one for at least one correct letter, one for at least one correct word, and one for the full message 'meet at dawn'.

Calculation check

  • ''.join(chr((ord(c) - ord(k)) % 26 + 97) for c, k in zip('flmktrwhee', 'thirtythir')) = meetatdawn
  • ('thirty' × 2)[:10] = thirtythir
