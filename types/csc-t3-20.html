Knowledge card

Rail Fence cipher

Written

The Rail Fence cipher is a transposition cipher: the letters stay the same but their order changes. The key is the number of rails. Write in a zig-zag, then read rail by rail, top to bottom.

  • The Rail Fence cipher is a transposition cipher: the letters stay the same but their order changes.
  • The key is the number of rails (rows).
  • Write the message diagonally down the rails, then back up, in a zig-zag, one letter per column.
  • Read the ciphertext off one rail at a time, from the top rail to the bottom, left to right.
  • To find the key from a diagram, count the rails.
  • It is weak because there are only a few sensible keys, so an attacker can try each one (brute force).

The method

  1. Draw the rails

    As many rows as the key.

  2. Zig-zag

    Down to the bottom, then up, one letter per column.

  3. Read the rails

    Top rail first, left to right.

  4. Check

    Same number of letters as the plaintext.

  5. Weakness

    Few keys, so try them all.

Do not lose marks here

  • ✗
    Straight across

    Write in a zig-zag.

  • ✗
    Reading columns

    Read along each rail.

  • ✗
    Repeated end rail

    Bounce, do not repeat the end rail.

Worked explanation

  1. Key 4, so draw 4 rails.
  2. Write COMPUTATIONAL in a zig-zag: C (rail 1), O (rail 2), M (rail 3), P (rail 4), U (rail 3), T (rail 2), A (rail 1), T (rail 2), I (rail 3), O (rail 4), N (rail 3), A (rail 2), L (rail 1).
  3. Rail 1 reads C A L.
  4. Rail 2 reads O T T A.
  5. Rail 3 reads M U I N.
  6. Rail 4 reads P O.
  7. Join the rails in order: CALOTTAMUINPO (13 letters, same as the plaintext).
Model answer · written by olevels.com, not an official Pearson mark scheme

Working: rail 1 C...A...L; rail 2 O.T.T.A; rail 3 M.U.I.N; rail 4 P...O (zig-zag). Encrypted text: CALOTTAMUINPO

How the marks are earned

Full marks for the correct ciphertext. If the final answer is wrong, marks can still come from drawing 4 rails, using a zig-zag arrangement, and reading each rail correctly.

Calculation check

  • ''.join(''.join('COMPUTATIONAL'[i] for i in range(13) if min(i % 6, 6 - i % 6) == r) for r in range(4)) = CALOTTAMUINPO
  • len('CALOTTAMUINPO') = 13
