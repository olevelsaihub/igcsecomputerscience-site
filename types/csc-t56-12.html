IPv4 and IPv6: sizes, formats and why IPv6 exists

Written

IPv4 is 32 bits: four numbers of 8 bits. IPv6 is 128 bits: eight groups of four hex digits, each digit 4 bits. IPv6 exists because IPv4 was running out of addresses.

  • An IP address is a number that identifies a device on a network.
  • An IPv4 address is 32 bits long, written as four denary numbers from 0 to 255 separated by dots, for example 192.168.1.78.
  • Each IPv4 number is 8 bits (one byte), so 4 x 8 = 32 bits.
  • An IPv6 address is 128 bits long, written as eight groups of four hexadecimal digits separated by colons.
  • Each hexadecimal digit stands for exactly 4 bits, because 4 bits give 16 values (0-F).
  • So each IPv6 group is 4 x 4 = 16 bits, and the whole address is 8 x 16 = 128 bits (or 32 hex digits x 4 bits).
  • IPv6 was introduced because the number of internet-connected devices grew so much that IPv4 was running out of addresses.
  • IPv4 allows about 4.3 billion addresses (2 to the power 32); IPv6 allows vastly more (2 to the power 128).

Worked explanation

  1. Count the groups between colons in 2024:0eb8:3c4d:0015:0000:0000:1a2f:1a2b: there are 8.
  2. Count the hex digits in each group: 4, so 8 x 4 = 32 hex digits in total.
  3. Each hex digit needs 4 bits, so each group is 4 x 4 = 16 bits.
  4. Total: 8 groups x 16 bits = 128 bits (check: 32 digits x 4 bits = 128 bits).
Model answer · written by olevels.com, not an official Pearson mark scheme

The address is made of 8 groups separated by colons, and each group has 4 hexadecimal digits, so there are 8 x 4 = 32 hexadecimal digits. Each hexadecimal digit needs 4 bits, so each group needs 16 bits. Altogether the address needs 8 x 16 = 128 bits (the same as 32 x 4).

How the marks are earned

Any three of these facts earn the three marks: 8 groups of 4 digits; 32 hex digits in total; 4 bits per hex digit; 16 bits per group; 128 bits in total (shown as 8 x 16 or 32 x 4).

Calculation check

  • len('2024:0eb8:3c4d:0015:0000:0000:1a2f:1a2b'.split(':')) = 8
  • len('2024:0eb8:3c4d:0015:0000:0000:1a2f:1a2b'.replace(':', '')) = 32
  • len(format(15, 'b')) = 4
  • 4 × 4 = 16
  • 8 × 16 = 128
  • 32 × 4 = 128
  • len(format(int('20240eb83c4d0015000000001a2f1a2b', 16), '0128b')) = 128
