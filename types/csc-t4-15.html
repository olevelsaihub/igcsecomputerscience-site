Knowledge card

High-level and low-level languages

Written

High-level languages read like English and are portable. Low-level languages sit close to the hardware, giving direct control but running on one processor type only.

  • A high-level language (such as Python) uses English-like words and is easy for people to read and write.
  • A low-level language is close to the hardware: machine code (binary) or assembly language (short mnemonics such as ADD and LDA).
  • High-level code is portable: it can run on different types of computer once translated.
  • Low-level code is written for one type of processor, so it is not portable.
  • Low-level code can directly control hardware and registers, and can run fast using little memory.
  • Low-level code is harder to read, slower to write and easier to make mistakes in.
  • High-level languages provide built-in functions, libraries and tools that make programming easier.
  • Low-level languages are often used for device drivers and embedded systems; high-level languages for general applications.

The method

  1. Pick the level

    High or low, and benefit or drawback.

  2. Pick a feature

    Readability, portability, hardware, speed.

  3. Compare

    Use 'whereas' on one feature.

  4. Link it

    Tie to the device or task.

  5. Avoid banned ideas

    Skip translation time if ruled out.

Do not lose marks here

  • ✗
    One side only

    Compare means both languages.

  • ✗
    Low-level is easier

    It is harder to read and write.

  • ✗
    Vague words

    Say how it is better.

What a complete response includes

Compare questions give one mark per feature where both language levels are contrasted. Give questions credit each valid point. Explain questions give one mark for a benefit and one for a linked reason in context.

Worked explanation

  1. The smartwatch software is written in assembly language, a low-level language.
  2. Recall the key benefit: low-level code can directly access the hardware and registers.
  3. Link it to the device: a smartwatch has limited hardware, so it must be used as efficiently as possible.
  4. Write the benefit and the reason together.
Model answer · written by olevels.com, not an official Pearson mark scheme

The programmers can make the best use of the smartwatch's limited hardware, because low-level code lets them directly access and control specific hardware features and registers.

How the marks are earned

One mark for the benefit (best use of, or optimised code for, the hardware) and one linked mark for the reason (direct access to hardware features or registers).
