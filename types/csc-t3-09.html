Knowledge card

ASCII and Unicode character sets

Written
  • A character set gives every character (letter, digit, symbol) its own binary code.
  • Standard ASCII uses 7 bits per character, so it has 2^7 = 128 codes (0 to 127).
  • ASCII covers English letters, digits, punctuation and some control codes.
  • Codes for letters and digits run in order: if 'A' is 65 then 'H' is 65 + 7 = 72.
  • Unicode is a much larger character set than ASCII. Its encodings use more bits for many characters: UTF-16 uses 16 or 32 bits per character, and UTF-8 uses 8 to 32 bits (8 for the ASCII characters).
  • Unicode can represent the characters of almost every language, plus symbols and emoji.
  • ASCII uses less storage per character than Unicode, and it is a widely agreed standard.
  • The first 128 Unicode codes are the same as ASCII.

Before you begin

  • Binary conversion (CSC-T3-01)
  • 2 to the power n (CSC-T3-08)

The method

  1. For counts, recall 7 bits and 128 characters for standard ASCII.

    Why: These two facts answer most short questions.

  2. To find a code, count on from the code you are given and convert to binary if needed (7 bits).

    Why: Characters of the same kind are numbered in sequence.

  3. For Unicode explanations, make one point (Unicode has far more codes / covers all languages) and link it to a reason (it uses more bits; ASCII has only 128 codes).

    Why: A two-mark explain needs a point and a linked reason.

  4. For ASCII benefits, give separate, different points such as fewer bits per character or a universal standard.

    Why: Each different benefit earns one mark.

Do not lose marks here

  • ✗
    Saying standard ASCII uses 8 bits or has 256 characters (that is extended ASCII).
  • ✗
    Off-by-one counting when finding a code (for example taking 'H' as 65 + 8).
  • ✗
    Giving a 6-bit answer such as 11 0101 when ASCII needs 7 bits.
  • ✗
    Saying Unicode is 'better' without any reason such as more bits or more languages.
  • ✗
    Mixing up the order: claiming ASCII covers all languages.

Worked explanation

  1. Point: languages such as Arabic, Chinese or Urdu use many characters that are not English letters.
  2. ASCII has only 7 bits, which is 2^7 = 128 codes, enough for English but not for these characters.
  3. Unicode uses 16 or more bits per character, which gives 2^16 = 65,536 codes or more.
  4. So Unicode can give every character in those languages its own code, and ASCII cannot.
Model answer · written by olevels.com, not an official Pearson mark scheme

Unicode can give a unique code to the characters of nearly every language, such as Arabic or Chinese letters, because it uses 16 or more bits per character (65,536 or more codes), whereas ASCII's 7 bits give only 128 codes, which is only enough for English.

How the marks are earned

One mark for the point that Unicode can represent characters from other languages, and one for the linked reason: it uses more bits so has far more codes than ASCII's 128.

Calculation check

  • 2 × × 16 = 65536
