Knowledge card

Keeping a network secure: access rights, physical security and authentication

Written

Match the threat to the control: authentication proves identity, physical security protects hardware, access rights limit data. Validation checks data, not identity.

  • Networks need protecting because they let malware spread between computers and let outsiders try to get in and steal or change data.
  • Access control gives each user only the rights they need for their job; common rights are none, read, write and execute.
  • A strong password policy forces long, complex passwords that are changed if compromised, making accounts harder to break into.
  • Authentication checks that a user really is who they claim to be.
  • Authentication methods include a username with a password, a security question, biometrics (fingerprint, face or iris) and two-factor authentication (2FA).
  • 2FA asks for two different kinds of proof, for example a password plus a one-time code sent to the user's phone.
  • Physical security protects the hardware itself, for example locked server rooms, swipe cards, CCTV cameras and security guards.
  • A firewall checks traffic coming into and leaving a network and blocks anything that breaks its rules.
  • Validation is different from authentication: validation checks that entered data is sensible and follows rules (such as a minimum length), while authentication checks identity.

Written-answer check

After your attempt, see the full worked explanation

Worked explanation

  1. Notice that biometrics are already in the question, so they cannot be used.
  2. Choose another way to prove identity: two-factor authentication.
  3. Say what the employee has to do: enter a password, then a one-time code sent to their phone or shown by an app.
  4. Say why that proves identity: only the real employee should have both.
Model answer · written by olevels.com, not an official Pearson mark scheme

The facility could use two-factor authentication. After entering their password, the employee must also type in a one-time code that is sent to their phone or produced by an authenticator app. Only the real employee should have both the password and the phone, so this confirms that they are who they claim to be.

How the marks are earned

One mark for naming two-factor authentication. One mark for describing the second piece of proof (a code sent to the employee's phone or app that they then enter).
