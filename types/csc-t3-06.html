Knowledge card

Adding binary numbers and overflow

Calculation
  • Binary addition works column by column from the right, like denary addition.
  • The rules are: 0 + 0 = 0; 0 + 1 = 1; 1 + 1 = 10 (write 0, carry 1); 1 + 1 + 1 = 11 (write 1, carry 1).
  • A register is a small store inside the processor that holds a fixed number of bits, for example 8.
  • Overflow happens when the result of a calculation is too big to fit in the bits available.
  • In 8-bit addition, overflow shows up as a carry out of the leftmost column, which would need a ninth bit.
  • The extra bit is lost, so the stored result is wrong.
  • Overflow can make a program give wrong results or crash.
  • Check your sum by converting both numbers and the answer to denary.

Before you begin

  • Unsigned binary conversion (CSC-T3-01)
  • Column addition in denary
1

The method

  1. Line up the two numbers and start at the rightmost column.

    Why: Carries move from right to left.

  2. Add each column using the four rules and write any carry above the next column on the left.

    Why: Recording carries stops them from being forgotten.

  3. Continue to the leftmost column.

    Why: Every bit of the answer must be filled in.

  4. If a 1 is carried out of the leftmost column, say an overflow has occurred.

    Why: That carry would need a ninth bit, which the register does not have.

  5. When explaining overflow, name it and give the cause: the result needs more bits than are available.

    Why: A linked explanation (name plus reason) is needed for both marks.

  6. Check by converting to denary: the two values should add to your answer.

    Why: A fast way to catch carry mistakes.

Do not lose marks here

  • ✗
    Forgetting to carry when 1 + 1 gives 10.
  • ✗
    Writing 2 in a column instead of 0 with a carry.
  • ✗
    Saying only 'an error happened' without naming overflow.
  • ✗
    Naming overflow but not saying why (the result needs more bits than are available).
  • ✗
    Adding from left to right.

Now see it used on a real past-paper question

What a complete response includes

For the sum, one mark for each correct nibble of the answer. For overflow, one mark for naming it and one for linking it to the result needing more bits than the register holds (or the lost carry out of the most significant bit).

Worked explanation

  1. Top: 0011 0100. Bottom: 0001 0110.
  2. Column 1 (right): 0 + 0 = 0.
  3. Column 2: 0 + 1 = 1.
  4. Column 3: 1 + 1 = 10, write 0, carry 1.
  5. Column 4: 0 + 0 + carry 1 = 1.
  6. Column 5: 1 + 1 = 10, write 0, carry 1.
  7. Column 6: 1 + 0 + carry 1 = 10, write 0, carry 1.
  8. Column 7: 0 + 0 + carry 1 = 1.
  9. Column 8: 0 + 0 = 0. No carry out, so no overflow.
  10. Answer: 0100 1010. Check: 52 + 22 = 74, and 0100 1010 is 64 + 8 + 2 = 74.
