Knowledge card

What makes a CPU faster: clock speed, cores and cache

Written
  • Clock speed is the number of cycles (pulses) the CPU clock makes each second, measured in hertz, for example 3 GHz = 3 billion cycles per second.
  • A higher clock speed means more fetch-decode-execute cycles each second, so more instructions are processed in the same time.
  • A higher clock speed also makes the CPU use more power and get hotter, so it needs more cooling.
  • A core is a separate processing unit inside the CPU; more cores can work on more instructions at the same time.
  • Cache is a small amount of very fast memory inside or close to the CPU.
  • Cache holds instructions and data that are used often, so the CPU does not have to wait for slower RAM.
  • A larger cache can hold more of these items, so the CPU finds what it needs in cache more often.
  • Other factors include the width of the data bus (word length) and the width of the address bus.

The method

  1. Name the factor (clock speed, number of cores, cache size or type).

    Why: Factor questions give a mark for each correctly named factor.

  2. Say what the factor changes inside the CPU (more cycles per second, more instructions at once, fewer slow trips to RAM).

    Why: This is the 'how' that turns a name into an explanation.

  3. Link it to the result: faster or slower processing.

    Why: The second mark is often for the effect on speed.

  4. If there is a scenario (a game, a laptop), say what the user would notice, such as lag or fewer frames per second.

    Why: Scenario questions need the effect described in that context, not just 'it is slower'.

  5. For cache, always mention that it is faster than RAM and holds frequently used items.

    Why: Without the speed difference the explanation does not show why cache helps.

Do not lose marks here

  • ✗
    Writing just 'cache' as a factor without saying its size or type.
  • ✗
    Saying 'it is faster' or 'low performance' without saying why or what the user notices.
  • ✗
    Saying cache stores all data, or stores data permanently.
  • ✗
    Confusing clock speed with internet speed or storage speed.
  • ✗
    Forgetting that higher clock speeds also bring heat and power problems.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

What a complete response includes

Give questions credit each correctly named factor or benefit. Explain questions give one mark for what the factor does and one for the linked effect; in a scenario, the second mark needs a consequence for that scenario, not a generic 'slower'.

Worked explanation

  1. The question asks for one reason cache is used.
  2. Recall the key fact: cache is very fast memory, much faster than RAM.
  3. Recall what it holds: instructions and data used often.
  4. Link the two: the CPU finds these items in cache, so it does not wait for slow RAM, so processing is faster.
Model answer · written by olevels.com, not an official Pearson mark scheme

Cache speeds up processing because it stores frequently used instructions and data close to the CPU, so the CPU does not have to wait while they are fetched from the much slower main memory (RAM).

How the marks are earned

One mark for saying cache speeds up processing, and a linked mark for the reason: frequently used items are held near the CPU so it avoids waiting for RAM.
