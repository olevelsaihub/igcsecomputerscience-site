Knowledge card

RAM, ROM, virtual memory and flash memory

Written

RAM holds what is running now and is volatile. ROM keeps the start-up instructions and cannot normally be changed. Virtual memory is disc space used as extra RAM. Flash is non-volatile and rewritable.

  • RAM (random-access memory) holds the programs and data the computer is using right now.
  • RAM is volatile: its contents are lost when the power is switched off.
  • ROM (read-only memory) is non-volatile and its contents cannot normally be changed.
  • ROM stores start-up instructions, such as the BIOS or firmware that boots the computer.
  • Virtual memory is space on secondary storage (hard disc or SSD) used as extra RAM when RAM is full.
  • With virtual memory, data not being used is moved out of RAM to the disc, and moved back when it is needed again.
  • Flash memory is non-volatile memory that can be written and rewritten; it is used in SSDs and memory cards.
  • A computer needs RAM for running programs and ROM to start up, because RAM is empty when the power comes on.

The method

  1. Name the type

    RAM, ROM, virtual or flash.

  2. State its property

    Volatile, read-only, rewritable, disc as RAM.

  3. Link to a use

    Working data, start-up, overflow.

  4. Cover both

    If two are named, mention both.

  5. Virtual memory

    Unused data out to disc and back.

Do not lose marks here

    Wrong volatility

    RAM is volatile; ROM is not.

  • ✗

    The OS loads from storage later.

Worked explanation

  1. The question asks why a computer needs both RAM and ROM, so the answer must mention both.
  2. Recall RAM's key property: it is volatile, so it is empty when the computer is switched on.
  3. So the computer needs somewhere permanent to keep the start-up instructions. That is ROM.
  4. Link the two: because RAM loses its contents, ROM is needed to hold the boot-up instructions.
Model answer · written by olevels.com, not an official Pearson mark scheme

RAM is volatile, so everything in it is lost when the power is switched off. Therefore ROM is needed, because it is permanent and keeps the BIOS (the start-up instructions) that boot the computer each time it is turned on.

How the marks are earned

One mark for the RAM point (volatile, contents lost without power) and one linked mark for ROM being needed to hold the permanent start-up instructions.
