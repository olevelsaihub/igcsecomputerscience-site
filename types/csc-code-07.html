Knowledge card

Subprograms and strings: complete the function and its call

Written
  • A subprogram is a named block of code that does one job; Python defines one with def.
  • A parameter is the name inside the brackets of the def line; it receives a value when the subprogram is called.
  • An argument is the actual value passed in the call, e.g. genNewKey(myString, myNumber).
  • A function sends a value back with return; the calling line must store or use that value.
  • A procedure does a job (such as printing) without returning a value.
  • Inside a subprogram, use its parameters rather than the main program's variable names.
  • A menu uses if/elif on the user's choice to call the right subprogram.
  • Convert and check inputs (int(), range tests) before passing them to a subprogram.
  • A string is a sequence of characters; each has an index starting at 0.
  • len(text) gives the number of characters in a string.

Before you begin

  • def, parameters and return
  • String slicing or array loops
  • if/elif for menus
  • int() conversion
  • String indexing from 0
  • Slicing
  • Type conversion with str(), int(), float()
  • while loops
1

The method

  1. Read each def line and note its parameters and whether it must return a value.

    Why: The parameters are the only data the subprogram should rely on.

  2. Write the body using the parameters, looping over data where needed.

    Why: Marks are given for the body using the parameters correctly.

  3. End a function with return and the result variable.

    Why: A return with no value, or a print instead of return, does not hand the answer back.

  4. Complete each call with the right arguments in the right order, and store or print what comes back.

    Why: Each correct call is a separate mark.

  5. Run with the example input and with an invalid input.

    Why: Shows both the subprogram and the checks around it work.

  6. Write down an example input and the exact output you must produce.

    Why: The example shows which characters go where.

  7. Validate the length with a while loop and an error message, if the task asks.

    Why: The test, the loop and the message are usually separate marks.

Do not lose marks here

  • ✗
    Printing the result inside a function instead of returning it.
  • ✗
    Writing return on its own, with no value.
  • ✗
    Using the main program's variable names inside the subprogram instead of its parameters.
  • ✗
    Calling the subprogram without arguments, or with them in the wrong order.
  • ✗
    Joining a number to a string without str().
  • ✗
    Using an if instead of a while, so a second wrong input is accepted.

What a complete response includes

Points for a body that uses the parameters to do the job, for each correct piece of processing inside it, for returning the result, and for every correct call with suitable arguments; input conversion and range checks earn their own points when asked for.

Worked explanation

  1. Example: abcd and 123 gives ab123cd. So key = first two characters + number + last two characters.
  2. In genNewKey, pString holds the text and pNum the number. First two: pString[0:2]. Last two: pString[2:4].
  3. pNum is an integer, so join it with str(pNum).
  4. newKey = pString[0:2] + str(pNum) + pString[2:4], then return newKey.
  5. Complete the call in the main program: myNewKey = genNewKey (myString, myNumber).
  6. Test: abcd and 123 prints New word: ab123cd; abc is stopped by the length check.

def genNewKey (pString, pNum): newKey = "" newKey = pString[0:2] + str(pNum) + pString[2:4] return newKey

# in the main program, inside the else: myNewKey = genNewKey (myString, myNumber)

How the marks are earned

Both parameters used to build the key (1); indexing used to reach characters (1); the first two and last two characters taken (1); the key joined in the right order (1); the key returned (1); the call line completed with both arguments (1).

Calculation check

  • 'abcd'[0:2] + str(123) + 'abcd'[2:4] = ab123cd
  • 'wxyz'[0:2] + str(7) + 'wxyz'[2:4] = wx7yz
