Knowledge card

Find named items in a program

Written

An identifier is the name of a variable, constant or subprogram. Each kind sits in a fixed place: a parameter in the def header, an argument in the call, and the receiving variable left of =.

  • An identifier is the name given to a variable, constant, array or subprogram.
  • A parameter is a name inside the brackets of a subprogram header, e.g. inSales in def getWages(inSales, inAge):
  • An argument is the value or variable passed in the brackets when the subprogram is called, e.g. sales in getWages(sales, age).
  • The variable on the left of x = someFunction(...) receives the value returned by the function.
  • A user-written subprogram is one defined in the program with def (FUNCTION or PROCEDURE in pseudocode).
  • A built-in subprogram comes with Python, e.g. print, input, int, float, len.
  • A variable created inside a def block is local; one created in the main program is global.
  • A constant is often written in capitals, e.g. TAX = 0.05; a data structure is shown with square brackets, e.g. [23, 22, 41].
  • A variable's data type comes from its value: float(input(...)) or 0.0 gives a real; str or text in quotes gives a string.

The method

  1. Underline the kind

    Parameter, local, built-in: say which.

  2. Go to its place

    def header, call brackets, or left of =.

  3. Check the scope

    Created inside def is local; in main is global.

  4. Copy it exactly

    The name, not a line number.

Do not lose marks here

  • ✗
    Parameter or argument

    Header names are parameters; call names are arguments.

  • ✗
    Wrong variable

    The receiver is left of = function(...).

  • ✗
    Line number given

    The mark needs the name.

Worked explanation

  1. Find the subprogram header: def getWages (inSales, inAge):
  2. The names inside the header brackets are the parameters: inSales and inAge.
  3. Do not confuse them with sales and age on the last line; those are arguments passed in the call.
  4. Write one parameter name exactly as spelt.
