Knowledge card

Complete a truth table

Written
  • A truth table lists every possible combination of inputs and shows the output for each one.
  • In logic, 1 means true and 0 means false.
  • With 2 inputs there are 4 rows; with 3 inputs there are 8 rows (2 to the power of the number of inputs).
  • List input rows in binary counting order: 000, 001, 010, 011, 100, 101, 110, 111.
  • AND gives 1 only when both inputs are 1.
  • OR gives 1 when at least one input is 1.
  • NOT flips the value: NOT 1 = 0 and NOT 0 = 1.
  • Work out brackets and NOT columns first, then combine those columns to get the final column.

Before you begin

  • Binary counting from 0 to 7
  • Meaning of AND, OR and NOT
1

The method

  1. If the input rows are not filled in, write all combinations in binary counting order.

    Why: Missing or repeated rows lose marks, and binary order makes sure none is missed.

  2. Work out each simple column (like NOT P or O AND S) row by row, looking only at the inputs it uses.

    Why: Each middle column is usually worth its own mark.

  3. Work out the final column by combining the middle columns, not the raw inputs.

    Why: This splits a hard expression into easy steps and allows follow-through credit.

  4. Check each AND column has 1s only where both parts are 1, and each OR column has 0s only where both parts are 0.

    Why: This quick scan catches most slips.

  5. If a scenario is given, check one row against common sense (for example, LED on only when the system is on, sunny and power is spare).

    Why: It confirms the logic matches the story.

Do not lose marks here

  • ✗
    Missing or repeating input combinations when writing the rows.
  • ✗
    Treating OR as 'only one of the two' (exclusive) instead of 'at least one'.
  • ✗
    Working the final column straight from the inputs and making a slip, instead of using the middle columns.
  • ✗
    Forgetting to flip every value in a NOT column.
  • ✗
    Copying a column into the wrong position in the table.

Now see it used on a real past-paper question

What a complete response includes

Usually one mark per correct column (or per correct pair of rows), plus a mark for listing all input combinations when that is required. The final column is often marked with follow-through from your own middle columns.

Worked explanation

  1. The inputs O, S, P are already listed in binary order: 000, 001, 010, 011, 100, 101, 110, 111.
  2. Column O AND S: 1 only when O and S are both 1 (the last two rows). Reading down the eight rows: 00000011.
  3. Column NOT P: flip P. P reads 01010101 down the rows, so NOT P reads 10101010.
  4. Final column (O AND S) AND (NOT P): 1 only where both middle columns are 1. Only row 110 has both. Reading down the eight rows: 00000010.
  5. Sense check: the LED is on only when the system is on, the sun shines and the house is not using all the power (O=1, S=1, P=0). Correct.
Model answer · written by olevels.com, not an official Pearson mark scheme

Rows in order O S P = 000, 001, 010, 011, 100, 101, 110, 111. Reading each column from top row to bottom row: O AND S = 00000011; NOT P = 10101010; final column = 00000010.

How the marks are earned

One mark for the correct O AND S column, one for the correct NOT P column, and one for the correct final column.

Calculation check

  • ''.join(str(int(r[0]) & int(r[1])) for r in ('000','001','010','011','100','101','110','111')) = 00000011
  • ''.join(str(1 - int(r[2])) for r in ('000','001','010','011','100','101','110','111')) = 10101010
  • ''.join(str(int(r[0]) & int(r[1]) & (1 - int(r[2]))) for r in ('000','001','010','011','100','101','110','111')) = 00000010
