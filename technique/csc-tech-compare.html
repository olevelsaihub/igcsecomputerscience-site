Computer Science / Compare and evaluate (2-4 marks)

Pearson Edexcel · International GCSE Computer Science · 4CP0

Compare and evaluate (2-4 marks)

Compare: show how two things are alike or different, talking about both. Evaluate and Assess: weigh up strengths and weaknesses, then reach a judgement that you support with reasons.

Command words: Compare, Evaluate, AssessUsually 2-4 marksAbout 1 minute per mark.

What Pearson asks

Compare: show how two things are alike or different, talking about both. Evaluate and Assess: weigh up strengths and weaknesses, then reach a judgement that you support with reasons.

How the marks are earned

In a comparison each mark usually needs a matched pair: what one thing does and what the other does on the same feature (size, speed, cost, security). Writing about only one side, or giving the same difference twice, scores less. Where a judgement is asked for, a clear conclusion backed by a reason is needed for the top marks.

Method

  1. Name the two things and pick features to compare (area covered, speed, cost, ownership, data stored).

    Why: Comparing on a shared feature makes every point a real difference.

  2. Write each point as 'X ... whereas Y ...'.

    Why: This covers both sides in one sentence, as comparison marks require.

  3. Use a different feature for each extra mark.

    Why: Two versions of the same difference count only once.

  4. For Evaluate or Assess, give at least one strength and one weakness.

    Why: A one-sided answer is not a balanced judgement.

  5. End an evaluation with a clear conclusion and the main reason for it.

    Why: The judgement is what separates evaluate from describe.

Answer frame

1. X [feature] whereas Y [feature]. 2. X [different feature] whereas Y [different feature]. (Evaluate: Overall... because...)

Common errors

Inferred, not measured: Inferred from the official schemes' credit patterns; not measured student-error statistics.

  • Writing only about one of the two things.
  • Giving the same difference twice, once from each side.
  • Using vague words like 'better' without saying on which feature.
  • Describing each thing in separate paragraphs without ever linking them.
  • In an evaluation, listing points but never reaching a judgement.

Model answer · written by olevels.com, not an official Pearson mark scheme

1. A WAN links computers spread over a wide geographical area, such as different cities or countries, whereas a LAN covers a small area such as one school site. 2. A WAN usually relies on connections rented from outside companies, whereas a LAN's cables and devices are normally owned by the organisation itself.

Why it earns the marks

Each line compares both networks on one feature, using 'whereas'. The two lines use different features (area, then ownership), so they are two separate differences rather than one repeated.

Question types that use this card

  • Compare sorts and searches

  • Functions, procedures, parameters and libraries

  • Caesar cipher
  • Kilobytes and kibibytes
  • RAM, ROM, virtual memory and flash memory
  • High-level and low-level languages
  • Translators: assembler, compiler and interpreter
  • Network types: LAN, WAN, PAN and why we network
  • Emerging tech: quantum, DNA computing, AI and nanotechnology
