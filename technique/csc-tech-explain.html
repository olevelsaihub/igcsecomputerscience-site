Computer Science / Explain (2-4 marks)

Pearson Edexcel · International GCSE Computer Science · 4CP0

Explain (2-4 marks)

Make a point and then justify it: say why or how it is true. 'State and justify' questions work the same way: a choice first, then the reason for it.

Command word: ExplainUsually 2-4 marksAbout 1 minute per mark.

What Pearson asks

Make a point and then justify it: say why or how it is true. 'State and justify' questions work the same way: a choice first, then the reason for it.

How the marks are earned

Marks come in linked pairs: one for a valid point and one for the reason or consequence attached to it. Two separate points with no reason usually cap at one mark. To get full marks at least one mark must come from reasoning. In 'state and justify', the choice must be correct before the justification can score.

Method

  1. Underline what you must explain and check whether it asks for 'one' reason or more.

    Why: Explaining one point fully beats listing several half points.

  2. Write the point in one clear sentence with the correct term.

    Why: This earns the first mark of the pair.

  3. Add 'because', 'so' or 'which means' and give the reason or effect.

    Why: The linked reason is what turns a statement into an explanation.

  4. Make the reason specific to the question's context (the device, user or program).

    Why: Context-free reasons are often too vague to credit.

  5. For 'state and justify', name the choice first, then give the reason.

    Why: The reason only scores if it supports a correct choice.

Answer frame

[Point]... because... [reason], so... [effect in this context].

Common errors

Inferred, not measured: Inferred from the official schemes' credit patterns; not measured student-error statistics.

  • Giving two unconnected statements instead of one point with its reason.
  • Repeating the point in other words instead of giving a reason.
  • Writing 'faster' or 'better' without saying what is faster or why.
  • Choosing the wrong option in 'state and justify', so the reason cannot score.
  • Using a reason that the question has already given.

Model answer · written by olevels.com, not an official Pearson mark scheme

Cache keeps copies of the instructions and data the CPU is using most often, and it is much faster to reach than RAM. This means the CPU spends less time waiting for each item to arrive from main memory, so programs run more quickly.

Why it earns the marks

It makes one point (cache holds frequently used items in very fast memory) and links it with 'this means' to the result (less waiting, faster processing). The point and its reason are joined, which is what an Explain mark pair needs.
