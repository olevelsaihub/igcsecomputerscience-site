Computer Science / Describe (2-4 marks)

Pearson Edexcel · International GCSE Computer Science · 4CP0

Describe (2-4 marks)

Give an account of what something is, what happens, or the steps in a process. The statements should link together and build up the picture, but you do not need to say why.

Command word: DescribeUsually 2-4 marksAbout 1 minute per mark.

What Pearson asks

Give an account of what something is, what happens, or the steps in a process. The statements should link together and build up the picture, but you do not need to say why.

How the marks are earned

Usually one mark per relevant point, or a pair of marks for a point plus the detail that develops it. For a process, each correct step in a sensible order earns credit. For a difference, both things must be mentioned. Simply naming the topic, or giving a formula with no words, is not enough on its own.

Method

  1. Find what you are describing and count the marks.

    Why: Marks tell you how many linked points or steps to write.

  2. Start with the key idea using the correct term.

    Why: The first point sets up the description and usually earns the first mark.

  3. Add the detail that develops it: what it does, what it affects or what happens next.

    Why: Describe rewards statements that build on each other, not separate fragments.

  4. For a process, write the steps in order, one per sentence.

    Why: Clear, ordered steps let each one be credited.

  5. For a difference, write about both things in the same sentence using 'whereas'.

    Why: A difference only counts when both sides are covered.

Answer frame

[Key idea with correct term]... This means/so... [develop]. (For differences: X ... whereas Y ...)

Common errors

Inferred, not measured: Inferred from the official schemes' credit patterns; not measured student-error statistics.

  • Writing one word or a heading instead of a full statement.
  • Describing only one side when asked for a difference.
  • Giving a formula or definition without saying what it means in this situation.
  • Listing steps in the wrong order or skipping a key middle step.
  • Drifting into a different topic (for example memory management when the question is about sharing the CPU).

June 2023 · Paper 1 · Q3(b)(ii)

The complete original question is shown; the illustration answers part (b)(ii).

Model answer · written by olevels.com, not an official Pearson mark scheme

Colour depth is the number of bits used to store the colour of one pixel. If the colour depth goes up, every single pixel now needs extra bits, so across all the pixels in the image many more bits have to be stored.

Why it earns the marks

The answer links two ideas: what is affected (each pixel) and what changes (more bits per pixel), then builds them into the effect on the whole file. It is in words rather than just quoting width x height x depth.
