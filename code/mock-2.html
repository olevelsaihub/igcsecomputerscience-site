Swimming lesson bookings

Daniyal manages the swimming lessons at a leisure centre. He has started to write a program that lets reception staff view the lessons, book places and cancel places. Test data has been included in the code: tbl_lesson stores the lesson names, tbl_capacity stores the maximum number of places on each lesson and tbl_booked stores the number of places already booked. The program already contains a subprogram that displays this menu: Menu [1] View lessons [2] Book a place [3] Cancel a place [4] Exit

  • Open Q06 in the code editor.
  • Write the program code so that:
  • the menu is displayed and the user is asked for a menu choice, repeatedly, until they choose [4] Exit
  • the menu choice is validated: any input other than 1, 2, 3 or 4 (including letters or a blank entry) gives an error message and the user is asked again; the program must not crash
  • Menu choice [1] View lessons: display, for every lesson, its lesson number (starting at 1), its name, the places booked and the places left. If no places are left, FULL is displayed instead of 0
  • Menu choice [2] Book a place: the user inputs a lesson number. If the lesson has a place left, one place is booked and a message showing the lesson name and the places left is displayed. If the lesson is full, a suitable message is displayed
  • Menu choice [3] Cancel a place: the user inputs a lesson number. If the lesson has at least one booking, one place is cancelled and a message showing the lesson name and the places left is displayed. If the lesson has no bookings, a suitable message is displayed
  • for options [2] and [3] the lesson number must be validated: it must be a whole number from 1 to the number of lessons, otherwise an error message is displayed and the user is asked again
  • Menu choice [4] Exit: display the number of places booked and the number of places cancelled during this session, then end the program.
  • Your program should include at least two subprograms that you have written yourself, one of which validates the lesson number and is used by both options [2] and [3].
  • Your program should function correctly even if the number of lessons is changed.
  • You must include comments in the code to explain the logic of your solution.
  • Save your amended code as Q06FINISHED with the correct file extension for the programming language.
