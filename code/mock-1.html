Orchard harvest analysis

Mrs Ahmed runs an apple orchard with several fields. Each week of the harvest she records how many kilograms of apples are picked in each field. She wants a program to analyse the harvest and to recommend which field she should plant new trees in. Test data has been included in the code: tbl_field stores the field names, tbl_trees stores the number of trees in each field and the two-dimensional array tbl_harvest stores the kilograms picked in each field (row) in each week (column). TARGET stores the harvest target for one field.

  • Open Q06 in the code editor.
  • Write a program to:
  • calculate and display the total harvest of each field
  • calculate and display the yield per tree of each field (the field's total divided by its number of trees), to one decimal place
  • calculate and display the total harvest of the whole orchard
  • display the name and total of the field with the highest total and the field with the lowest total (ignore the possibility of two fields having the same total)
  • display the names of the fields whose total is below TARGET, or a suitable message if every field reached the target
  • display the name of the recommended field for new trees: the field with the highest yield per tree.
  • Your program should function correctly even if the number of fields or the number of weeks is changed.
  • You should use techniques to make your code easy to read.
  • Save your amended code as Q06FINISHED with the correct file extension for the programming language.
