Here is the flowchart. Start Initialise variables Enter username and password Are username No Display error and password message correct? Yes Display welcome message Stop Write a program to implement the logic in the flowchart. Open Q02a in the code editor. You must use the structure given in Q02a to write the program. Do not add any further functionality. Save your code as Q02aFINISHED with the correct file extension for the programming language. (11)
