Subprograms and strings: complete the function and its call · June 2024 · Paper 2 · Question 4 · part (c) · 6 marks

(c) A program is required to create a new key. The program takes two inputs. The first input is a four‑character string. The second input is a whole number. The key is constructed by joining the first two characters from the string, the number and the final two characters from the string. When the user enters the four‑character string abcd and the integer 123, the program must construct and display the new key ab123cd Open Q04c in the code editor. Amend the code to: • complete the subprogram to construct the new key • complete the call to the subprogram. Do not add any further functionality. Save your code as Q04cFINISHED with the correct file extension for the programming language. (6)
