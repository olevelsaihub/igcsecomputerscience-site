Running club results file

Kofi is the secretary of a running club. After each weekly 5 km run he types every runner's time into a text file called Times.txt. Each line holds the runner's first name and surname, a comma, then their time in minutes and seconds, for example Amira Khan,24:35. Some lines are typed wrongly and have no comma, and there may be blank lines. Kofi wants a program that produces a tidy results file and a short summary.

  • Open Q06 in the code editor. The file Times.txt is in the same folder.
  • Write a program to:
  • read every line of Times.txt, ignoring blank lines
  • count any line that does not contain a comma as an invalid line; invalid lines are not processed further
  • for each valid line, calculate the runner's time in seconds (minutes x 60 + seconds)
  • write one line to a new text file called Results.txt for each valid runner in the form SURNAME INITIAL SECONDS, where SURNAME is the surname in capital letters and INITIAL is the first letter of the first name, for example KHAN A 1475
  • add SUB25 to the end of a runner's line if their time is under 25 minutes (fewer than 1500 seconds)
  • write a final line Runners: followed by the number of valid runners to Results.txt
  • display the number of valid runners and the number of invalid lines
  • display the full name and time (as minutes:seconds) of the fastest runner (ignore the possibility of two runners having the same time)
  • display the average time of the valid runners in seconds, rounded to the nearest whole number.
  • Your program should include at least one subprogram that you have written yourself.
  • Your program should function correctly even if the number of lines in Times.txt is changed.
  • You should use techniques to make your code easy to read.
  • Save your amended code as Q06FINISHED with the correct file extension for the programming language.
