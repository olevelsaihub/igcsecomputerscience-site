Problem solving · Type 5

Compare sorts and searches

How linear search, binary search, bubble sort and merge sort work in words, and their relative advantages, drawbacks, memory use and suitability for a given data set.

Problem solving · Type 6

Make an algorithm faster or work for any amount of data

Judging which of two working algorithms is more efficient, or improving a working algorithm so it copes with any amount of data (array instead of separate variables, LENGTH instead of a hard-coded count).

Medium ★★☆☆☆ 4 question parts

Grade 9 Plan

Problem solving · Type 7

Say what an algorithm (or one line) does

Reading a supplied flowchart, pseudocode algorithm, subprogram or opened program and explaining in words either its overall job or the role of a particular line or variable (a temporary swap variable, an index increment, a redundant test, a count-down loop variable).

Medium ★★★★★ 11 question parts

A-Grade Plan

Problem solving · Type 8

Binary search step by step

Stepping through binary search on a sorted list (order of items examined, low/high/mid values), worst-case number of checks, and why it fails on unsorted data.

Difficult ★★☆☆☆ 4 question parts

A-Grade Plan

Problem solving · Type 9

Trace tables: run the algorithm by hand

Executing a supplied flowchart, pseudocode algorithm or short program by hand for given inputs to find the outputs, the final or returned value of a variable, or to fill a trace table or output table.

Difficult ★★★★★ 13 question parts

A-Grade Plan

Problem solving · Type 10

Turn a flowchart or pseudocode into Python

The algorithm is already designed - as numbered pseudocode, a flowchart or a trace table plus requirements - and the student implements its logic in Python inside a given structure (5-11 marks).

Difficult ★★★★★ 8 question parts

A-Grade Plan

Problem solving · Type 11

Write an algorithm on paper: flowcharts and pseudocode

Producing an algorithm on paper that meets a written requirement list using sequence, selection and iteration: drawing a flowchart, arranging supplied flowchart boxes, or filling in the missing statements of a pseudocode skeleton.

Difficult ★★★★★ 6 question parts

A-Grade Plan

Problem solving · Type 12

Find and fix errors in an algorithm

Logic and off-by-one errors in supplied pseudocode or flowchart algorithms: locating the faulty line, explaining the wrong result it causes, and writing a corrected line.
