Programming · Type 6

Spot constructs, operators, keywords and comments

Reading opened Python code, printed pseudocode or a lettered list of algorithm steps and pointing to an element: a relational or logical operator, the selection keyword, comment text, the line where selection or iteration starts, a line that defines a subprogram, initialises a variable or takes input, including marking such a line with a comment in the editor; also recognising arithmetic, relational and logic operators and why brackets change the order of operations.

Subprograms and strings: complete the function and its call

A short Paper 2 program built around subprograms and string handling: completing a function or procedure body, passing arguments, returning a value, calling it from the main program or a menu, and string work inside it (slicing, joining with numbers, reversing, checking length with re-input).

Programming · Type 15

Write a short number program from a list of requirements

From a bullet list of requirements (no design given) the student writes a short numeric program: inputs converted to numbers, calculations with arithmetic/modulus operators, selection for bands or tests, and count- or condition-controlled loops, including stepping through an array.

Read and write text files line by line

The program opens a text file to read lines (strip, split on commas, cast, check or total) and/or writes records to a file (from input or from an array, comma-separated, one record per line), then closes the file.

Programming · Type 17

The final 20-mark program

The last question of Paper 2: a multi-requirement program, usually built on 1D/2D or parallel arrays of test data, sometimes with a menu, subprograms, validation, searching or ordering; 11 functionality marks plus a 9-mark levels band.
