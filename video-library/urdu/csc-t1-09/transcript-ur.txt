Idea۔ تصور کریں کہ آپ name cards کے بڑے ڈھیر کو sort کر رہے ہیں۔ سب ایک ساتھ کرنا مشکل ہے۔ تو آپ ڈھیر کو آدھا آدھا کرتے ہیں، پھر دوبارہ آدھا، جب تک ہر شخص کے پاس صرف ایک card نہ رہ جائے۔ ایک اکیلا card پہلے ہی ترتیب میں ہوتا ہے۔ پھر آپ چھوٹے ڈھیر دو دو کر کے واپس جوڑتے ہیں، انہیں ترتیب میں رکھتے ہوئے۔ یہ merge sort ہے۔ یہ divide and conquer algorithm ہے: مسئلے کو چھوٹے حصوں میں بانٹیں، انہیں حل کریں، پھر نتائج کو combine کریں۔

Method۔ Step ایک: list کو آدھا آدھا کریں۔ ہر آدھے کو اس وقت تک split کرتے رہیں جب تک ہر list میں صرف ایک item نہ رہ جائے۔ Split کرتے وقت کچھ sort نہ کریں۔ صرف کاٹیں۔ Step دو: merge۔ دو sorted lists لیں اور ان کی سامنے والی items compare کریں۔ چھوٹی والی نئی list میں ڈالیں، پھر دوبارہ سامنے والی items compare کریں۔ جب ایک list خالی ہو جائے، تو باقی ساری copy کر دیں۔ Levels میں merge کریں: single items سے pairs، pairs سے fours، اور fours سے پوری list۔ صرف ساتھ ساتھ بیٹھی lists merge کریں، اور ہر merge پر پوچھی گئی ترتیب چیک کریں۔

Worked Example۔ یہ نومبر دو ہزار اکیس کے Paper دو کا اصل question ہے۔ Merge sort سے نو، ایک، سات، چھ، تین، پانچ، دو، آٹھ کو ascending order میں رکھیں۔ یہ پانچ marks کا ہے۔ پہلے، آٹھ numbers کو چار چار کے دو halves میں split کریں: نو، ایک، سات، چھ، اور تین، پانچ، دو، آٹھ۔ دھیان دیں کہ ابھی کچھ sort نہیں ہوا۔ ہر half کو pairs میں split کریں، پھر pairs کو single items میں۔ ہر split level پر ایک mark ملتا ہے۔ اب ساتھ والوں کو sorted pairs میں merge کریں۔ نو اور ایک بنتے ہیں ایک، نو۔ سات اور چھ بنتے ہیں چھ، سات۔ تین، پانچ اور دو، آٹھ پہلے ہی ترتیب میں ہیں۔ Pairs کو sorted fours میں merge کریں۔ ایک، نو کے ساتھ چھ، سات دیتا ہے ایک، چھ، سات، نو۔ تین، پانچ کے ساتھ دو، آٹھ دیتا ہے دو، تین، پانچ، آٹھ۔ آخری merge دیتا ہے ایک، دو، تین، پانچ، چھ، سات، آٹھ، نو۔ تین split rows میں سے ہر ایک پر ایک mark، اور دو merge rows میں سے ہر ایک پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی split کرتے ہوئے sort کرنا ہے۔ Splitting صرف list کو کاٹتی ہے۔ Sorting merge کے وقت ہوتی ہے۔ ایک اور غلطی کوئی level چھوڑ دینا ہے، یعنی pairs سے سیدھا پوری list پر جانا۔ پہلے pairs کو fours میں merge کریں۔

Your Turn۔ اب آپ کوشش کریں۔ Merge sort سے چار، نو، ایک، چھ کو descending order میں رکھیں۔ ہر split اور ہر merge دکھائیں۔ رک کر حل کریں۔

Answer۔ Halves میں split کریں: چار، نو اور ایک، چھ۔ پھر single items میں split کریں۔ Descending کا مطلب ہے سب سے بڑا پہلے۔ Pairs میں merge کریں: نو، چار اور چھ، ایک۔ پھر سامنے والی items compare کریں: نو چھ سے پہلے، چھ چار سے پہلے، پھر چار ایک سے پہلے۔ Answer ہے نو، چھ، چار، ایک۔ Method یاد رکھیں۔ تب تک split کریں جب تک ہر list میں ایک item نہ رہ جائے، ساتھ والوں کو level by level merge کریں، اور ہر merge پر direction چیک کریں۔ اب اس type کے practice questions کریں۔
