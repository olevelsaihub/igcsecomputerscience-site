Idea۔ سوچیں کہ آپ دوست کو jigsaw puzzle چھوٹے envelopes میں post کر رہے ہیں۔ آپ ہر envelope کو number دیتے ہیں اور پتا لکھتے ہیں، اور post van انہیں لے جاتی ہے۔ آپ کا دوست ٹکڑوں کو دوبارہ ترتیب میں لگاتا ہے۔ Networks بھی data اسی طرح چھوٹے ٹکڑوں میں بھیجتے ہیں، جنہیں packets کہتے ہیں۔ T C P I P model کام کو چار layers میں بانٹتا ہے۔ اوپر سے نیچے: application، transport، network، اور data link۔ Application layer میں وہ protocols ہیں جو programs استعمال کرتے ہیں، جیسے H T T P، F T P اور S M T P۔ Transport layer data کو packets میں تقسیم کرتی ہے اور انہیں number دیتی ہے۔ Receive کرتے وقت وہ چیک کرتی ہے کہ سب پہنچے، انہیں دوبارہ ترتیب میں لاتی ہے، اور جو غائب ہوں انہیں دوبارہ مانگتی ہے۔ Network layer بھیجنے والے اور وصول کرنے والے کے I P addresses شامل کرتی ہے، اور ہر packet کو networks کے پار route کرتی ہے۔ Data link layer packets کو دو devices کے درمیان physical connection کے پار منتقل کرتی ہے، M A C addresses استعمال کر کے۔ بھیجتے وقت data layers سے نیچے جاتا ہے۔ Receive کرتے وقت وہ واپس اوپر جاتا ہے، اور ہر layer وہ ہٹا دیتی ہے جو اس کی partner نے شامل کیا تھا۔ Layers کی وجہ سے ایک layer کو بدلا جا سکتا ہے بغیر باقیوں کو بدلے۔

Method۔ چاروں layers margin میں نیچے لکھیں۔ Question میں کام ڈھونڈیں اور key words سے match کریں۔ چیک کریں کہ بات بھیجنے کی ہے یا وصول کرنے کی۔ پھر layer اور اس کا function ساتھ ساتھ لکھیں۔ یہ key words ہر layer کی طرف اشارہ کرتے ہیں۔ Programs کے protocols: application۔ Split اور reassemble: transport۔ I P addresses اور routing: network۔ M A C addresses اور physical link: data link۔

Worked Example۔ یہ November دو ہزار اکیس کے Paper ایک کا اصل question ہے۔ T C P I P stack کی دو layers کے نام بتائیں، اور ہر ایک کا ایک function دیں۔ اس کے چار marks ہیں۔ وہ layers چنیں جو آپ کو سب سے اچھی آتی ہوں۔ Transport: وہ data کو packets میں تقسیم کرتی ہے، اور ہر packet کو sequence number دیتی ہے، تاکہ انہیں ترتیب میں واپس لگایا جا سکے۔ Network: وہ ہر packet میں source اور destination I P addresses شامل کرتی ہے، اور اسے networks کے پار اس کی destination تک route کرتی ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake network layer کو data کو packets میں تقسیم کرنے کا کام دینا ہے۔ تقسیم کرنا اور numbering transport layer کا کام ہے۔ ایک اور mistake نام ہے۔ Data layer نام کی کوئی layer نہیں۔ پورا نام لکھیں: data link layer۔

Your Turn۔ اب آپ try کریں۔ ایک laptop پر file پہنچتی ہے۔ Packet seven غائب ہے، اور باقی ترتیب کے بغیر پہنچے۔ کون سی layer اسے سنبھالتی ہے؟ اس کے دو کام بتائیں۔ یہاں رک کر حل کریں۔

Answer۔ یہ transport layer ہے۔ وہ چیک کرتی ہے کہ ہر packet پہنچ گیا، packets کو ان کے numbers سے واپس ترتیب میں لگاتی ہے، اور packet seven دوبارہ بھیجنے کا کہتی ہے۔ چاروں layers اور ان کے کام یاد رکھیں: application programs کے protocols کے لیے، transport تقسیم اور دوبارہ جوڑنے کے لیے، network addresses اور routes کے لیے، data link physical link کے لیے۔ اب اس type کے practice questions کریں۔
