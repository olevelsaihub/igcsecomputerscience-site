Idea۔ Football scoreboard کا سوچیں۔ وہ nil، nil سے شروع ہوتا ہے۔ ہر بار goal ہو تو صرف اسی team کا number بدلتا ہے۔ Trace table بھی algorithm کے variables کے لیے ایسے ہی کام کرتی ہے۔ Dry-running کا مطلب ہے algorithm کو line by line، اصل values کے ساتھ، بالکل ویسے چلانا جیسے computer چلاتا ہے۔ یہ algorithm ایک، دو اور تین کو جمع کرتا ہے۔ Total صفر سے شروع ہوتا ہے۔ i ایک ہو تو total ایک بنتا ہے۔ i دو ہو تو total تین بنتا ہے۔ i تین ہو تو total چھ بنتا ہے۔ loop کے بعد چھ output ہوتا ہے۔

Method۔ پہلے، ہر variable کی starting value پہلی row میں لکھیں۔ پھر inputs ایک ایک کر کے پڑھیں، اور lines کو ترتیب سے follow کریں۔ ہر IF، WHILE یا UNTIL پر، موجودہ values سے طے کریں کہ condition true ہے یا false۔ نئی value صرف اسی column میں لکھیں جو بدلتا ہے۔ جب output ہو تو بالکل صحیح message اور value لکھیں۔ جب loop کہے stop تو رک جائیں، مگر loop کے بعد والی lines بھی چلائیں۔

Worked Example۔ یہ جون دو ہزار بائیس کے Paper ایک کا اصل question ہے۔ Reba کا game algorithm colours پڑھتا ہے جب تک minus ایک input نہ ہو۔ outputs دکھانے کے لیے trace table مکمل کریں۔ یہ چار marks کا ہے۔ پانچوں variables صفر یا خالی سے شروع ہوتے ہیں۔ ہر pass ایک colour پڑھتا ہے۔ Red، RedPoints میں ایک add کرتا ہے۔ Orange، OrangePoints میں آٹھ add کرتا ہے، اور NumOranges میں ایک۔ پہلی row میں starting values ہیں۔ Input red: RedPoints ایک بن جاتا ہے۔ Input orange: OrangePoints آٹھ اور NumOranges ایک بن جاتا ہے۔ Red، پھر دوبارہ red: RedPoints دو، پھر تین بنتا ہے۔ Orange: OrangePoints سولہ، اور NumOranges دو بن جاتا ہے۔ Minus ایک loop کے اندر پڑھا جاتا ہے، مگر وہ نہ red ہے نہ orange، اس لیے کچھ نہیں بدلتا۔ واپس اوپر پہنچ کر، Colour minus ایک ہے، اس لیے loop ختم ہو جاتا ہے۔ Score ہے تین plus سولہ، یعنی انیس۔ پھر تین outputs آتے ہیں۔ Score انیس۔ Number of reds تین۔ اور number of oranges سولہ، کیونکہ line تیئیس OrangePoints بھیجتی ہے، NumOranges نہیں۔ اسی لیے Reba حیران ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی minus ایک والی row چھوڑ دینا ہے۔ رکنے والی value loop کے اندر پڑھی جاتی ہے، اس لیے وہ pass بھی چلتا ہے۔ Test صرف واپس اوپر پہنچ کر ہوتا ہے۔ ایک اور غلطی ہر value کو ہر row میں copy کرنا ہے۔ صرف وہ value لکھیں جو بدلی ہے، تاکہ ہر step واضح رہے۔
