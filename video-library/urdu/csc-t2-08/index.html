Idea۔ recipe follow کرنے کا سوچیں۔ اگر وہ ایسی زبان میں لکھی ہو جو آپ پڑھ نہیں سکتے، تو آپ شروع ہی نہیں کر سکتے۔ اگر oven بیچ میں خراب ہو جائے، تو آپ رک جاتے ہیں۔ اگر sugar کی جگہ salt لکھا ہو، تو آپ پکا لیتے ہیں، مگر cake کا ذائقہ غلط ہوتا ہے۔ programs بھی انہی تین طریقوں سے غلط ہوتے ہیں۔ Syntax error، language کے grammar rules توڑتی ہے، اس لیے program translate نہیں ہوتا اور شروع ہی نہیں ہوتا۔ یہاں if line میں colon نہیں ہے۔ Runtime error اس وقت ہوتی ہے جب program چل رہا ہو۔ کوئی instruction پوری نہیں ہو سکتی، جیسے zero سے divide کرنا، اس لیے program crash ہو جاتا ہے۔ Logic error سب سے چالاک ہے۔ program آخر تک چلتا ہے اور کوئی message نہیں آتا، مگر result غلط ہوتا ہے۔ یہاں subtraction الٹی ہے۔

Method۔ error classify کرنے کے لیے ترتیب سے تین سوال پوچھیں۔ کیا یہ translate ہوتا ہے؟ نہیں، تو syntax error ہے۔ کیا چلتے ہوئے crash ہوتا ہے؟ تو runtime error ہے۔ کیا غلط جواب کے ساتھ ختم ہوتا ہے؟ تو logic error ہے۔ tick table میں ہر description ایک ہی error type سے match ہوتی ہے۔ اس لیے ہر row میں ایک tick لگائیں، دو کبھی نہیں۔

Worked Example۔ یہ June دو ہزار پچیس کے Paper دو کا اصل سوال ہے۔ تین descriptions کے لیے error type پر tick لگا کر table complete کریں۔ اس کے تین marks ہیں۔ یہ table ہے۔ تین descriptions ہیں، اور ہر ایک پر بالکل ایک tick لگانا ہے: syntax، logic یا runtime۔ Row ایک: program expected output نہیں دیتا۔ یہ چلا، اس لیے syntax نہیں۔ یہ crash نہیں ہوا، اس لیے runtime نہیں۔ یہ logic error ہے۔ Row دو: program translate نہیں ہوتا۔ اس نے language کا ایک rule توڑا ہے، اس لیے یہ syntax error ہے۔ Row تین: program execution کے دوران crash ہوتا ہے۔ Execution کا مطلب چلنا ہے، اس لیے یہ runtime error ہے۔ ہر صحیح tick پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ zero سے divide کو logic error کہنا عام غلطی ہے۔ اس سے program crash ہوتا ہے، اس لیے یہ runtime error ہے۔ ایک اور غلطی، الٹی subtraction کو syntax error کہنا۔ code ہر rule مانتا ہے، اس لیے یہ logic error ہے۔

Your Turn۔ اب آپ کوشش کریں۔ ہر fault کی error type بتائیں۔ A، غلط spelling والا keyword، print کی جگہ prnt۔ B، ایک loop جو ایک کم number جمع کرتا ہے۔ C، پانچ items کی list میں دسویں item مانگنا۔ رک کر فیصلہ کریں۔

Answer۔ A، syntax error ہے، کیونکہ غلط spelling والا keyword language کے rules توڑتا ہے۔ B، logic error ہے، کیونکہ program چلتا ہے مگر total غلط ہے۔ C، runtime error ہے، کیونکہ list سے باہر index استعمال کرنے سے program crash ہوتا ہے۔ method یاد رکھیں: کیا یہ translate ہوگا، کیا crash ہوگا، یا جواب غلط ہے؟ ایک سوال ہر بار error type بتا دیتا ہے۔ اب اس type کے practice questions کریں۔
