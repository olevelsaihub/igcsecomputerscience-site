Idea۔ ایک library کا سوچیں۔ آپ librarian کو shelf number دیتے ہیں۔ وہ اس shelf کو ڈھونڈ کر کتاب آپ کے پاس لاتی ہے۔ Shelf number صرف ایک طرف جاتا ہے، librarian کی طرف۔ کتابیں دونوں طرف جاتی ہیں، باہر اور واپس۔ Computer کے اندر buses نام کی wires کے sets CPU اور memory کے درمیان signals لے جاتے ہیں۔ Address bus addresses لے جاتی ہے، ایک طرف، CPU سے memory تک۔ Data bus data اور instructions دونوں طرف لے جاتی ہے۔ Control bus read، write اور clock جیسے signals لے جاتی ہے۔ CPU ایک cycle بار بار دہراتا ہے۔ Memory سے instruction fetch کریں۔ اسے decode کریں، تاکہ پتا چلے اس کا مطلب کیا ہے۔ اسے execute کریں، یعنی اس پر عمل کریں۔

Method۔ یہ fetch کی تفصیل ہے۔ Program counter کا address memory address register میں copy ہوتا ہے۔ وہ address، address bus پر جاتا ہے۔ ایک read signal، control bus پر جاتا ہے۔ Instruction data bus پر واپس آتی ہے۔ Program counter ایک سے بڑھ جاتا ہے۔ اگلا، decode۔ Control unit سمجھتا ہے کہ instruction کا مطلب کیا ہے۔ پھر execute۔ Instruction پر عمل ہوتا ہے، مثلاً ALU دو numbers add کرتا ہے۔ Bus کی width اہم ہے۔ زیادہ wide data bus ایک بار میں زیادہ bits منتقل کرتی ہے۔ زیادہ wide address bus زیادہ memory locations تک پہنچ سکتی ہے۔ صرف faster کہنا بہت مبہم ہے۔

Worked Example۔ یہ June دو ہزار پچیس کے Paper ایک کا اصل question ہے۔ Describe کریں کہ fetch-decode-execute cycle کے دوران address bus کیسے استعمال ہوتی ہے۔ اس کے دو marks ہیں۔ Point ایک۔ Fetch کے دوران CPU اگلی instruction کا address، جو memory address register میں ہے، address bus پر رکھتا ہے۔ وہ ایک طرف جاتا ہے، main memory تک۔ Point دو، جڑا ہوا۔ Memory اس address سے صحیح location ڈھونڈتی ہے، تاکہ اس سے read یا اس میں write ہو سکے۔ اگر address ایک سو ایک ہو تو location ایک سو ایک read ہوتی ہے۔ تو جواب ہے: CPU memory address کو address bus پر رکھتا ہے، اور یہ main memory میں اس location کی پہچان کرتا ہے جسے read یا write کرنا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake یہ کہنا ہے کہ address bus data لے جاتی ہے، یا وہ two-way ہے۔ وہ صرف addresses لے جاتی ہے، CPU سے memory تک۔ ایک اور mistake یہ کہنا ہے کہ program counter اگلی instruction رکھتا ہے۔ وہ اگلی instruction کا address رکھتا ہے۔

Your Turn۔ اب آپ try کریں۔ Program counter میں چالیس ہے۔ چالیس اگلے کون سے register میں جاتا ہے؟ Instruction واپس کون سی bus پر آتی ہے؟ Fetch کے بعد program counter میں کیا ہے؟ رک کر فیصلہ کریں۔

Answer۔ چالیس memory address register میں copy ہوتا ہے، پھر read signal کے ساتھ address bus پر جاتا ہے۔ Instruction data bus پر واپس آتی ہے۔ Program counter increment ہو کر اکتالیس ہو جاتا ہے۔ یاد رکھیں: address، address bus پر باہر جاتا ہے، instruction، data bus پر واپس آتی ہے، پھر وہ decode اور execute ہوتی ہے۔ اب اس type کے practice questions کریں۔
