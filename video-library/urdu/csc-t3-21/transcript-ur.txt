Idea۔ سوچیں کہ خفیہ note کے ہر letter کو ایک چھوٹی شکل سے بدل دیا گیا ہے۔ صرف وہ دوست جس کے پاس وہی key ہو اسے واپس بدل سکتا ہے۔ یہ substitution cipher ہے۔ یہ لفظ HELLO ہے، Pigpen cipher میں لکھا ہوا۔ Key grids کا ایک set ہے۔ پہلا noughts and crosses grid ہے جس میں A سے I ہیں۔ Letter کی symbol اس کے خانے کے گرد کی lines سے بنتی ہے۔ E بیچ میں ہے، اس لیے اس کی symbol پورا square ہے۔ دوسرا grid اسی شکل کا ہے، جس میں J سے R ہیں، مگر اس کی ہر symbol کے اندر ایک dot ہے۔ J اوپر بائیں ہے، اس لیے اس کی symbol دو lines، دائیں اور نیچے، اور ایک dot ہے۔ آخری دو حصے X شکلیں ہیں۔ S سے V سادہ X میں ہیں، اور W سے Z dotted X میں: اوپر، بائیں، دائیں اور نیچے۔ T بائیں triangle میں ہے، اس کی دو lines دائیں طرف اشارہ کرتا arrowhead بناتی ہیں۔

Method۔ Letter کو encrypt کرنے کے لیے اسے key میں ڈھونڈیں۔ نوٹ کریں کہ وہ کس grid میں ہے، اور اس کی position۔ صرف وہ lines بنائیں جو اس کے خانے کی سرحد ہیں۔ اگر وہ dotted grid میں ہے تو dot لگائیں۔ Decrypt کرنے کے لیے الٹا چلیں۔ outline اور dot کو ایک خانے سے match کریں، اور اس کا letter پڑھیں۔ Key کو پرکھنے کے لیے check کریں کہ ہر letter کی symbol ہے، اور کوئی symbol دو بار استعمال نہیں ہوئی۔

Worked Example۔ یہ June دو ہزار بائیس کے Paper دو کا اصل سوال ہے۔ Figure ایک میں ایک Pigpen key دکھائی گئی ہے۔ لفظ MAY کے ہر letter کی symbol دیں۔ اس کے تین marks ہیں۔ M dotted grid میں ہے، درمیانی row، بایاں خانہ۔ اس کے اوپر ایک line ہے، نیچے ایک line اور دائیں ایک line۔ تو اس کی symbol ایک box ہے جو بائیں طرف کھلا ہے، اندر dot کے ساتھ۔ A سادہ grid میں ہے، اوپر بائیں خانہ۔ اس کے دائیں ایک line ہے اور نیچے ایک line۔ تو اس کی symbol انہی دو lines سے بنا ایک کونا ہے، بغیر dot کے۔ Y dotted X میں ہے، دائیں triangle۔ اس کی دو lines بیچ میں، اس کے بائیں طرف ملتی ہیں، بائیں اشارہ کرتے arrowhead کی طرح، اندر dot کے ساتھ۔ تو لفظ MAY ان تین symbols سے لکھا جاتا ہے۔ ہر صحیح symbol پر ایک mark ملتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی dot بھول جانا ہے۔ ان دو symbols کو دیکھیں۔ پہلی D ہے، سادہ grid سے۔ دوسری M ہے۔ فرق صرف dot کا ہے۔

Your Turn۔ اب آپ کوشش کریں۔ وہی key استعمال کر کے لفظ TREE کی Pigpen symbols بنائیں۔ یہاں رک کر حل کریں۔

Answer۔ T سادہ X میں ہے، بایاں triangle: دائیں اشارہ کرتا arrowhead، بغیر dot کے۔ R dotted grid میں ہے، نیچے دائیں: اس کے اوپر اور بائیں lines، dot کے ساتھ۔ E سادہ grid کا بیچ ہے: پورا square، دو بار بنایا ہوا۔ method یاد رکھیں: letter کا grid اور خانہ ڈھونڈیں، صرف اس خانے کے گرد کی lines بنائیں، اور dotted grids کے لیے dot لگائیں۔ اب اس type کے practice questions کریں۔
