Idea۔ Headphones کا سوچیں۔ Wired والے cable سے لگتے ہیں اور کم ہی ٹوٹتے ہیں۔ Wireless والے آپ کو چلنے پھرنے دیتے ہیں، مگر زیادہ دور جائیں تو آواز کٹ سکتی ہے۔ Networks میں بھی یہی choice ہے: wired یا wireless۔ Wired networks data cables کے ساتھ بھیجتے ہیں۔ Copper cable electrical signals لے جاتی ہے، اور fibre-optic cable روشنی کی pulses۔ Wireless networks data کو ہوا میں radio waves کے طور پر بھیجتے ہیں۔ Wi-Fi دو اعشاریہ چار gigahertz اور پانچ gigahertz bands استعمال کرتا ہے۔ Wired links زیادہ steady ہیں، دیواروں یا فاصلے سے کمزور نہیں ہوتے، ان کو intercept کرنا مشکل ہے، اور اکثر ان کی bandwidth زیادہ ہوتی ہے۔ مگر cables install کرنا پڑتی ہیں، وہ devices کو ایک جگہ باندھ دیتی ہیں، trip hazard بن سکتی ہیں، اور phones میں network port نہیں ہوتا۔ Network speed bits per second میں ناپی جاتی ہے، جیسے megabits per second یا gigabits per second۔ Bytes، mebibits اور mebibytes storage کی units ہیں، network speed کی نہیں۔

Method۔ پہلے چیک کریں کہ question کس طرف سے ہے۔ پھر ہر point کے لیے ایک feature چنیں، اور اسے comparison کے طور پر لکھیں۔ Explain یا describe کے لیے so سے result شامل کریں، یا whereas سے دوسرا پہلو۔ یہ features استعمال کریں: reliability، دیواروں اور فاصلے کا اثر، security، mobility اور installation۔ ہر ایک الگ point دیتا ہے۔

Worked Example۔ یہ June دو ہزار تئیس کے Paper ایک کا اصل question ہے۔ Wired network اور wireless network کے استعمال کردہ media کا ایک difference describe کریں۔ اس کے دو marks ہیں۔ Feature وہ medium ہے جس میں data سفر کرتا ہے۔ Wired طرف، packets cables کے ساتھ سفر کرتے ہیں، copper میں electrical signals کے طور پر، یا fibre-optic cable میں روشنی کی pulses کے طور پر۔ Wireless طرف، packets ہوا میں radio waves کے طور پر سفر کرتے ہیں۔ دونوں پہلوؤں کو whereas سے جوڑیں، تاکہ یہ ایک difference بنے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake یہ کہنا ہے کہ wireless بس waves استعمال کرتا ہے۔ Radio waves کہیں، جو ہوا میں سفر کرتی ہیں۔ Copper کے لیے electrical signals کہیں، صرف electricity نہیں۔ ایک اور mistake speed کی unit ہے۔ Network speed bits per second میں ہے، کبھی bytes per second میں نہیں۔

Your Turn۔ اب آپ try کریں۔ Lena ایک مصروف train میں کام کرتی ہے۔ وہ train کا free Wi-Fi استعمال کر سکتی ہے، یا اپنے phone کا personal hotspot۔ دو وجوہات دیں کہ hotspot بہتر کیوں ہو سکتا ہے۔ یہاں رک کر حل کریں۔

Answer۔ پہلی، hotspot کو کم لوگ share کرتے ہیں، اس لیے Lena کو زیادہ bandwidth ملتی ہے۔ دوسری، صرف وہی devices جڑ سکتی ہیں جنہیں وہ اجازت دے، اس لیے یہ public Wi-Fi سے زیادہ secure ہے۔ Method یاد رکھیں: direction چیک کریں، ہر point کے لیے ایک feature چنیں، اور ہر ایک کو comparison کے طور پر لکھیں۔ اب اس type کے practice questions کریں۔
