Idea۔ باورچی خانے کا سوچیں۔ آٹا jar میں، انڈے box میں، اور دودھ bottle میں۔ ہر container ایک قسم کی چیز کے لیے موزوں ہے۔ Computer بھی ایسا ہی ہے۔ ہر value ایک data type کے ساتھ store ہوتی ہے، جو بتاتی ہے کہ وہ کس قسم کی value ہے اور اس کے ساتھ کیا کیا جا سکتا ہے۔ پانچ data types جاننی ہیں۔ Integer ایک whole number ہے، جیسے انیس۔ Real number میں decimal حصہ ہوتا ہے، جیسے چار اعشاریہ پانچ۔ Boolean صرف True یا False ہے۔ Char ایک اکیلا character ہے، جیسے capital A۔ String characters کی ایک قطار ہے، جیسے word Hello۔ Python میں یہ ایسا نظر آتا ہے۔ Hours equals انیس ایک integer ہے۔ Price equals تین پانچ چھ اعشاریہ دو پانچ ایک real ہے، جسے Python float کہتا ہے۔ Member equals True ایک Boolean ہے۔ Grade میں ایک character ہے، اس لیے یہ char ہے، اور name میں string ہے۔ Text ہمیشہ quotation marks کے اندر ہوتا ہے۔

Method۔ ترتیب سے تین سوال پوچھیں۔ کیا یہ True یا False ہے؟ تو یہ Boolean ہے۔ کیا یہ number ہے؟ Whole number integer ہے، اور کوئی بھی decimal point اسے real بنا دیتا ہے۔ کیا یہ text ہے؟ ایک character char ہے۔ ایک سے زیادہ string ہے۔ اگر justify کرنا ہو، تو وہ feature بتائیں جو آپ نے استعمال کیا۔ Real کے لیے کہیں کہ اس میں decimal حصہ ہے، یا یہ صفر اعشاریہ پانچ سے ضرب دینے سے بنا ہے۔ یہ کہنا کہ یہ number ہے کافی نہیں۔

Worked Example۔ یہ جون دو ہزار چوبیس کے Paper دو کا اصل question ہے۔ Table مکمل کر کے ہر item کی data type دکھائیں: پینتالیس اعشاریہ آٹھ دو، اور True۔ یہ دو marks کا ہے۔ پہلی item پینتالیس اعشاریہ آٹھ دو ہے۔ یہ decimal point والا number ہے، اس لیے یہ real number ہے۔ Python میں یہ float ہے۔ دوسری item True ہے، quotation marks کے بغیر۔ True صرف دو ممکن values میں سے ایک ہے، اس لیے یہ Boolean ہے۔ آپ Python میں اسے check کر سکتے ہیں۔ type function پینتالیس اعشاریہ آٹھ دو کے لیے float دکھاتا ہے، اور True کے لیے bool، یعنی Boolean کا مخفف۔ تو real لکھیں، پھر Boolean، ہر ایک پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی True کو string کہنا ہے۔ Quotation marks کے بغیر، True ایک Boolean ہے۔ ایک اور غلطی char کی مثال کے طور پر پورا word دینا ہے۔ Char صرف ایک character ہوتا ہے۔

Your Turn۔ اب آپ کوشش کریں۔ چار values کے لیے بہترین data type بتائیں: quotation marks میں حرف Q، سترہ، تین اعشاریہ صفر، اور quotation marks کے اندر سترہ۔ رک کر حل کریں۔
