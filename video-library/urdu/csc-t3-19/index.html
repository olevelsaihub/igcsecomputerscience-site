Idea۔ Caesar cipher یاد کریں۔ ہر letter alphabet میں اتنی ہی جگہ آگے جاتا ہے۔ تین کے shift سے cat، f d w بن جاتا ہے۔ اسے توڑنا آسان ہے، کیونکہ ہر letter کا shift ایک جیسا ہے۔ Vigenere cipher ایک keyword استعمال کر کے ہر letter کو اس کا اپنا shift دیتی ہے۔ Letter a کا مطلب shift صفر، b کا مطلب shift ایک، اور اسی طرح آگے۔ چونکہ shift بدلتا رہتا ہے، اسے توڑنا بہت مشکل ہے۔ Vigenere square آپ کے لیے shifting کر دیتا ہے۔ ہر row ایک مختلف letter سے شروع ہوتی ہے۔ Row a میں کوئی shift نہیں۔ Row b ایک سے shifted ہے، row c دو سے، اور square میں نیچے اسی طرح۔

Method۔ پہلے keyword کو message کے نیچے لکھیں، اسے دہراتے ہوئے جب تک ہر letter کے لیے keyword letter نہ ہو۔ پھر ہر letter کے لیے اس row پر جائیں جو اس کے keyword letter سے شروع ہوتی ہے۔ Encrypt کرنے کے لیے اس row میں plain letter کے column تک پڑھیں۔ Decrypt کرنے کے لیے cipher letter کو row کے اندر ڈھونڈیں، پھر اس کے column کے اوپر کا heading پڑھیں۔ Check کریں کہ آپ کا جواب الفاظ بناتا ہے۔

Common Mistake۔ Decrypt کرتے وقت ایک عام غلطی وہ letter پڑھنا ہے جہاں row اور column ملتے ہیں۔ یہ encrypt کرنے کا طریقہ ہے۔ Decrypt کرنے کے لیے cipher letter کو row میں ڈھونڈیں اور column کا heading پڑھیں۔ ایک اور غلطی keyword نہ دہرانا ہے، یا کوئی letter چھوڑ دینا جس سے keyword قدم سے باہر ہو جائے۔ پہلے keyword کو لائن میں لگائیں، ہر خانے میں ایک letter۔
