Idea۔ Car کو service کی ضرورت ہوتی ہے۔ Oil بدلا جاتا ہے، tyres چیک ہوتے ہیں، اور boot میں spare رکھا جاتا ہے۔ Computer کی بھی دیکھ بھال ضروری ہے۔ یہ کام کرنے والے programs utility software کہلاتے ہیں۔ پانچ main utilities جاننی ہیں۔ Anti-malware، defragmentation، backup، file repair اور file conversion۔ Anti-malware نقصان دہ software سے بچاتا ہے۔ اس کی types میں antivirus، anti-spyware، anti-adware اور software firewall شامل ہیں۔ Antivirus viruses کے لیے scan کر سکتا ہے، infected files کو quarantine کر سکتا ہے، انہیں remove کر سکتا ہے، real time میں scan کر سکتا ہے اور خود کو update کر سکتا ہے۔ وقت کے ساتھ file کے blocks hard drive پر بکھر جاتے ہیں۔ File A تین جگہوں میں بٹی ہے، درمیان میں gaps ہیں۔ اسے fragmentation کہتے ہیں، اور اس سے reading slow ہو جاتی ہے۔
