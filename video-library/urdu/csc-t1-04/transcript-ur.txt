Idea۔ ایک recipe کا تصور کریں جو کہے تین سو منٹ bake کریں، تیس کی جگہ۔ آپ ہر step follow کر سکتے ہیں، مگر cake جل جاتا ہے۔ Algorithm میں یہ logic error ہے: یہ چلتا ہے، مگر result غلط ہوتا ہے۔ Exam کے زیادہ تر errors چار قسم کے ہوتے ہیں۔ ایک boundary جو غلط comparison استعمال کرے۔ ایک loop جو array کے آخر سے آگے نکل جائے۔ ایک counter جو بڑھانے کی بجائے replace ہو جائے۔ یا رکنے والی value کو data گن لینا۔ Array کے indexes صفر سے شروع ہوتے ہیں۔ اس array میں سات items ہیں، اس لیے اس کے indexes صفر سے چھ تک ہیں۔ LENGTH سات ہے، اس لیے index سات موجود ہی نہیں۔

Method۔ پہلے پڑھیں کہ algorithm کو کیا کرنا چاہیے، اور expected result نوٹ کریں۔ پھر اسے test data کے ساتھ dry-run کریں۔ پہلی row جہاں value غلط ہو، وہ خراب line کی طرف اشارہ کرتی ہے۔ پھر صحیح کی ہوئی line پوری لکھیں، اسی pseudocode style میں، اور صرف خراب حصہ بدلیں۔ آخر میں test data اپنی fix کے ساتھ دوبارہ چلائیں۔

Worked Example۔ یہ جون دو ہزار چوبیس کے Paper ایک کا اصل question ہے۔ algorithm کو گننا چاہیے کہ کتنی trains early، on time یا late تھیں۔ چار errors ہیں۔ یہ حصہ line گیارہ کا صحیح code مانگتا ہے، ایک mark کے لیے۔ یہ Figure دو ہے۔ یہ سات arrival times store کرتا ہے، پھر ان پر loop چلاتا ہے۔ Line دس اور اس سے نیچے late اور early trains گنتی ہیں، اور lines بائیس سے چوبیس totals display کرتی ہیں۔ Line گیارہ دیکھیں۔ یہ late کو arrival of index کے برابر set کرتی ہے۔ اس سے منٹوں کی تعداد late میں copy ہو جاتی ہے، اور جو پہلے تھا وہ replace ہو جاتا ہے۔ اسے row by row dry-run کریں۔ Early train سے کچھ نہیں بدلتا۔ ایک منٹ late train سے late ایک بنتا ہے۔ پانچ منٹ late train سے late پانچ بنتا ہے، دو نہیں۔ پھر on-time train سے late صفر ہو جاتا ہے، سب مٹ جاتا ہے، اور اگلی early train سے کچھ نہیں بدلتا۔ آخری دو سے چار، پھر ایک بنتا ہے۔ Late کو چار پر ختم ہونا چاہیے، مگر وہ ایک پر ختم ہوتا ہے۔ تو صحیح line یہ ہے: set late to late plus ایک۔ اب late ہر late train کو گنتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔ باقی تین faults بھی انہی مشتبہ جگہوں سے ہیں۔ Line آٹھ کو آخری index پر رکنا چاہیے۔ Line دس میں greater than صفر ہونا چاہیے، تاکہ on time کو late نہ گنا جائے۔ Line تئیس کو on-time trains نکالنی چاہیں۔ Data سے check کریں۔ چار trains late ہیں، دو early ہیں، اور سات minus چھ سے ایک on time بچتی ہے۔

Common Mistake۔ ایک عام غلطی صرف بدلا ہوا حصہ لکھنا ہے۔ question line مانگتا ہے، اس لیے اسے پوری لکھیں۔ ایک اور غلطی LENGTH کو آخری index سمجھنا ہے۔ آخری index LENGTH minus ایک ہے، اس لیے loop کو LENGTH سے پہلے رکنا چاہیے۔
