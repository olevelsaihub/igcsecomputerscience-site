Idea۔ سفر کے لیے packing کرتے وقت آپ کپڑوں کو دبا کر چھوٹے bag میں رکھتے ہیں۔ Compression file کے ساتھ یہی کرتی ہے۔ یہ file کو چھوٹا کرتی ہے، اس لیے وہ کم storage space لیتی ہے اور network پر تیزی سے بھیجی جا سکتی ہے۔ بچت کتنی بڑی ہو سکتی ہے، دیکھیں۔ CD quality کا تین منٹ کا گانا تقریباً بتیس megabytes کا ہوتا ہے۔ Compressed M P تین file کے طور پر یہ تین megabytes سے کم ہے۔ دو قسمیں ہیں۔ Lossy compression کچھ data ہمیشہ کے لیے ہٹا دیتی ہے، اس لیے اصل file کبھی بالکل ویسی دوبارہ نہیں بن سکتی۔ Lossless compression کچھ نہیں کھوتی، اس لیے اصل file بالکل ویسی واپس آ جاتی ہے۔

Method۔ پہلے فیصلہ کریں کہ file کیا ہے۔ کیا یہ text یا program code ہے، جہاں ہر character اہم ہے؟ یا یہ picture، music یا video ہے جو لوگ دیکھتے یا سنتے ہیں؟ پھر چنیں۔ اگر ہر bit بچانی ہو تو lossless۔ Media کے لیے lossy اکثر ٹھیک ہے، کیونکہ لوگ غائب detail شاذ ہی محسوس کرتے ہیں۔ آخر میں justify کریں کہ اس file کے ساتھ کیا ہوگا۔ Compression کے نقصانات بھی ہیں۔ Compress اور decompress کرنے میں وقت لگتا ہے، اور file کھولنے کے لیے compatible software چاہیے۔

Common Mistake۔ ایک عام غلطی یہ کہنا ہے کہ lossless کم data ہٹاتی ہے۔ یہ بالکل کوئی data نہیں ہٹاتی۔ اسی لیے file بالکل ویسی دوبارہ بن سکتی ہے۔ ایک اور غلطی ایک ہی وجہ دو بار دینا ہے۔ Saves space اور takes less storage ایک ہی point ہیں۔ مختلف points دیں، جیسے less storage اور faster to send۔

Answer۔ Lossy چنیں۔ گانے بہت چھوٹے ہوتے ہیں، اس لیے mobile data پر تیزی سے stream ہوتے ہیں اور ہر fan کا کم data استعمال ہوتا ہے۔ سننے والے music میں غائب detail شاذ ہی محسوس کرتے ہیں۔ method یاد رکھیں: فیصلہ کریں کہ file کیا ہے، اگر ہر bit اہم ہو تو lossless چنیں اور اگر لوگ محسوس نہ کریں تو lossy، پھر اس file کے لیے justify کریں۔ اب اس type کے practice questions کریں۔
