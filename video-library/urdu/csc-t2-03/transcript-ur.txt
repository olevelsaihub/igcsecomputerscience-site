Idea۔ ایک school کا سوچیں۔ main hall میں لگا notice ہر کوئی پڑھ سکتا ہے۔ ایک classroom کے board پر لگا note صرف اسی کمرے میں پڑھا جا سکتا ہے، اور lesson کے آخر پر مٹا دیا جاتا ہے۔ Program میں variable کا scope program کا وہ حصہ ہے جہاں اسے استعمال کیا جا سکتا ہے۔ School، main program میں بنایا گیا ہے، کسی بھی subprogram سے باہر، اس لیے یہ global variable ہے۔ اسے کہیں سے بھی پڑھا جا سکتا ہے، حتیٰ کہ show room کے اندر سے بھی۔ Room، subprogram کے اندر بنایا گیا ہے، اس لیے یہ local variable ہے۔ یہ صرف show room کے اندر موجود ہے۔ Subprogram ختم ہو تو room غائب ہو جاتا ہے اور اس کی memory free ہو جاتی ہے۔ اس لیے main program میں room استعمال کرنے سے error آتا ہے۔ دو subprograms میں سے ہر ایک میں ایک ہی نام کا local variable ہو سکتا ہے۔ ان میں ٹکراؤ نہیں ہوتا، کیونکہ ہر ایک صرف اپنے subprogram کے اندر رہتا ہے۔

Method۔ پہلے چیک کریں کہ question کیا پوچھتا ہے: variable کہاں بنایا جاتا ہے، یا کہاں استعمال ہو سکتا ہے۔ یہ الگ حقائق ہیں، اور آپ کا answer اس کے مطابق ہونا چاہیے۔ Global variable main program میں بنایا جاتا ہے اور کہیں بھی استعمال ہو سکتا ہے۔ Local variable subprogram کے اندر بنایا جاتا ہے اور صرف اسی subprogram کے اندر استعمال ہو سکتا ہے۔ لفظ only حد دکھاتا ہے۔

Worked Example۔ یہ جون دو ہزار انیس کے Paper دو کا اصل question ہے۔ Computer program میں local variable اور global variable کے درمیان difference Describe کریں۔ یہ دو marks کا ہے۔ Global variable سے شروع کریں۔ یہ کہاں بنتا ہے؟ Main program میں، ہر subprogram سے باہر۔ یہ کہاں استعمال ہو سکتا ہے؟ Program میں کہیں بھی۔ اب local variable۔ یہ subprogram کے اندر بنتا ہے، اور صرف اسی subprogram کے اندر استعمال ہو سکتا ہے۔ دونوں جملے لکھیں۔ A global variable is created in the main program and can be used anywhere۔ A local variable is created inside a subprogram and can only be used there۔ ہر ایک پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی یہ کہنا ہے کہ local variable ایک line میں استعمال ہوتا ہے۔ یہ اپنے subprogram کے اندر کہیں بھی استعمال ہو سکتا ہے، مگر کہیں اور نہیں۔ ایک اور غلطی صرف ایک طرف describe کرنا ہے۔ Difference کے question میں ہر قسم کے variable کے بارے میں ایک جملہ چاہیے۔

Your Turn۔ اب آپ کوشش کریں۔ کون سا variable global ہے، اور کون سا local؟ Program کیا print کرتا ہے؟ رک کر حل کریں۔

Answer۔ Bonus، main program میں بنا ہے، اس لیے global ہے، اور add bonus کے اندر پڑھا جا سکتا ہے۔ New score، add bonus کے اندر بنا ہے، اس لیے local ہے۔ Parameter p score بھی local ہے۔ پچاس plus دس، ساٹھ، تو ساٹھ print ہوتا ہے۔ Method یاد رکھیں۔ پوچھیں کہ variable کہاں بنتا ہے اور کہاں استعمال ہو سکتا ہے، پھر global کے لیے ایک جملہ اور local کے لیے ایک جملہ لکھیں۔ اب اس type کے practice questions کریں۔
