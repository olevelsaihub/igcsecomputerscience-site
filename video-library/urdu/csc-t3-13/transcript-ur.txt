Idea۔ جب آپ گاتے ہیں تو ہوا ایک ہموار wave میں vibrate کرتی ہے جو مسلسل بدلتی رہتی ہے۔ اس ہموار، continuous signal کو analogue کہتے ہیں۔ Computer ہموار wave store نہیں کر سکتا۔ وہ صرف الگ الگ binary numbers store کر سکتا ہے، جو digital ہے۔ Wave کو numbers میں بدلنے کے لیے computer اسے sample کرتا ہے۔ وہ باقاعدہ وقفوں پر wave کی اونچائی ناپتا ہے، جسے amplitude کہتے ہیں۔ یہ آٹھ samples ہیں۔ ہر sample ایک binary number کے طور پر store ہوتا ہے۔ ہر sample کی bits کی تعداد bit depth ہے۔ تین کی bit depth کے ساتھ، sample تین، جس کی amplitude چھ ہے، ایک ایک صفر کے طور پر store ہوتا ہے۔ Sampling frequency، یا sample rate، ہر second میں لیے جانے والے samples کی تعداد ہے۔ اسے hertz میں ناپتے ہیں۔ Music file اکثر چوالیس ہزار ایک سو hertz استعمال کرتی ہے۔

Method۔ Conversion describe کرنے کے لیے steps ترتیب سے دیں۔ Sample rate اور bit depth set کریں۔ ہر وقفے پر amplitude ناپیں۔ ہر پیمائش کو binary میں بدلیں۔ Binary values store کریں۔ تبدیلی کے اثر کے لیے دونوں پہلو دیں۔ Higher sample rate یا bit depth آواز کی زیادہ قریبی copy بناتی ہے، مگر file بڑی ہو جاتی ہے۔

Worked Example۔ یہ November دو ہزار اکیس کے Paper ایک کا اصل سوال ہے۔ describe کریں کہ analogue sound کو digital sound file میں کیسے convert کیا جاتا ہے۔ اس کے تین marks ہیں۔ پہلے sample rate اور bit depth set کیے جاتے ہیں۔ پھر analogue wave کو sample کیا جاتا ہے۔ اس کی amplitude باقاعدہ وقفوں پر ناپی جاتی ہے۔ اگلا، ہر ناپی گئی amplitude کو چنی گئی bits کی تعداد سے ایک binary value دی جاتی ہے۔ آخر میں binary values کو sample rate کے ساتھ sound file کے طور پر store کیا جاتا ہے۔ مثال کے طور پر، چوالیس ہزار ایک سو hertz پر، دو seconds کی آواز اٹھاسی ہزار دو سو samples دیتی ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی axes الٹنا ہے۔ Time ہمیشہ نیچے چلتا ہے۔ Amplitude سائیڈ میں اوپر کی طرف۔ ایک اور غلطی speakers سے playback describe کرنا ہے۔ سوال آواز record اور store کرنے کے بارے میں ہے، اس لیے sampling اور binary values describe کریں۔

Your Turn۔ اب آپ کوشش کریں۔ ایک voice note آٹھ ہزار hertz پر تین seconds کے لیے record ہوتا ہے۔ کتنے samples store ہوتے ہیں؟ اگر sample rate دوگنا کر دیں تو file size کا کیا ہوگا؟ یہاں رک کر حل کریں۔

Answer۔ ہر second آٹھ ہزار samples، تین seconds کے لیے، چوبیس ہزار samples ہیں۔ Rate دوگنا کریں تو اڑتالیس ہزار samples ہوں گے، اس لیے file دوگنی بڑی ہوگی، بہتر quality کے ساتھ۔ method یاد رکھیں: rate اور bit depth set کریں، باقاعدہ وقفوں پر amplitude ناپیں، ہر sample کو binary میں بدلیں، اور store کریں۔ اب اس type کے practice questions کریں۔
