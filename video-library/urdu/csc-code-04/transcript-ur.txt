Idea۔ Flowchart ایک algorithm کا نقشہ ہے، یعنی step-by-step plan۔ ہر shape Python کا ایک حصہ بن جاتی ہے۔ Rectangle، assignment بنتا ہے۔ Parallelogram، input یا output بنتا ہے۔ Diamond، if بنتا ہے، اور واپس جانے والا arrow while بنتا ہے۔ Pseudocode بھی اسی طرح بدلتا ہے۔ Set، equals بنتا ہے۔ Receive، int of input بنتا ہے۔ D I V، دو slashes بنتا ہے، whole-number division کے لیے، اور M O D، per cent sign بنتا ہے، remainder کے لیے۔ Loop کو ایک variable چاہیے جو اس کے اندر بدلے، ورنہ وہ کبھی نہیں رکتا۔ یہاں count ہر بار ایک بڑھتا ہے، اس لیے تین passes کے بعد count less than تین False ہو جاتا ہے، اور loop ختم ہو جاتا ہے۔

Method۔ design کا ہر box code کرتے ہوئے tick کریں۔ پہلے starting values لکھیں، پھر int کے ساتھ inputs۔ اگلا، ہر loop-back arrow کو while line بنائیں، بالکل وہی condition رکھ کر۔ ہر decision کو if اور else میں code کریں، ہر calculation کو صحیح operator سے، اور واضح outputs شامل کریں۔ پھر test data کے ساتھ run کریں اور compare کریں۔
