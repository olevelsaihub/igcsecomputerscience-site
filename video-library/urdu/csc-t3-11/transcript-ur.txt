Idea۔ آپ کا phone کہتا ہے کہ photo تقریباً تین megabytes کی ہے، اور گانا چند seconds میں download ہو جاتا ہے۔ یہ numbers bits گننے سے آتے ہیں۔ اس type میں آپ وہ calculation لکھتے ہیں جو انہیں گنتی ہے، جسے expression کہتے ہیں۔ ہر قسم کی file کا اپنا شروعاتی product ہوتا ہے۔ Image: width ضرب height ضرب colour depth۔ Sound: sample rate ضرب bit depth ضرب seconds۔ Text: characters ضرب bytes per character۔ پھر units چاہییں۔ آٹھ bits مل کر ایک byte بنتے ہیں۔ اس type میں ایک kilobyte ایک ہزار bytes ہے اور ایک megabyte ایک ہزار ضرب ایک ہزار bytes ہے۔ Mebibytes میں ایک ہزار کی جگہ ایک ہزار چوبیس ہوتا ہے۔

Method۔ اسے ترتیب سے بنائیں۔ Product لکھیں۔ Bytes کے لیے آٹھ سے divide کریں۔ کوئی metadata add کریں، جو bytes میں دیا ہوتا ہے۔ پھر megabytes کے لیے ایک ہزار ضرب ایک ہزار سے divide کریں۔ Transfer time کے لیے size کو bits میں، speed یعنی bits per second سے divide کریں۔ Megabits per second کا مطلب ہر second لاکھوں bits ہے، تو ایک ہزار ضرب ایک ہزار سے multiply کریں۔ Brackets لگائیں تاکہ پوری اوپر والی مقدار divide ہو۔ Brackets کے بغیر صرف آخری حصہ divide ہوگا، اور expression غلط جواب دے گا۔

Worked Example۔ یہ June دو ہزار بائیس کے Paper ایک کا اصل سوال ہے۔ ایک photo تین ہزار پانچ سو انیاسی ضرب چھ ہزار ایک سو اٹھائیس pixels کی ہے، colour depth بتیس bits ہے اور سات سو بتیس bytes کا metadata ہے۔ megabytes میں اس کے size کا expression بنائیں۔ اس کے چار marks ہیں۔ Product سے شروع کریں۔ تین پانچ سات نو ضرب چھ ایک دو آٹھ pixels، ضرب بتیس bits فی pixel۔ یہ bits میں size ہے۔ Bits کو bytes بنانے کے لیے آٹھ سے divide کریں۔ پھر metadata add کریں، سات سو بتیس bytes۔ یہ پہلے سے bytes میں ہے، اس لیے divide کے بعد add ہوتا ہے۔ آخر میں سب کو ایک ہزار ضرب ایک ہزار سے divide کریں، کیونکہ ایک megabyte دس لاکھ bytes ہے۔ اوپر والے حصے کے گرد brackets یقینی بناتے ہیں کہ سب divide ہو۔ حل کریں تو تقریباً ستاسی اعشاریہ سات تین megabytes ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی آٹھ سے divide کرنے سے پہلے metadata add کرنا ہے۔ اس سے سات سو بتیس bytes کو ایسے لیا جاتا ہے جیسے وہ bits ہوں۔ ایک اور غلطی یہ ہے کہ سوال megabytes کہے اور آپ ایک ہزار چوبیس ضرب ایک ہزار چوبیس سے divide کریں۔ وہ factor mebibytes کے لیے ہے۔
