Idea۔ ایک classroom کے whiteboard کا سوچیں۔ آپ کام کے دوران اس پر لکھتے ہیں، مگر دن کے آخر میں وہ صاف ہو جاتا ہے۔ اب دیوار پر لگے چھپے ہوئے safety card کا سوچیں۔ وہ ہمیشہ وہاں رہتا ہے اور کوئی اسے نہیں بدلتا۔ RAM، یعنی random-access memory، whiteboard ہے۔ اس میں وہ programs اور data ہوتے ہیں جو ابھی استعمال ہو رہے ہوں۔ RAM volatile ہے۔ Power بند ہو تو اس کا سب کچھ ختم ہو جاتا ہے۔ ROM، یعنی read-only memory، چھپا ہوا card ہے۔ وہ non-volatile ہے، اس لیے power کے بغیر بھی اپنا contents رکھتی ہے، اور انہیں عام طور پر بدلا نہیں جا سکتا۔ ROM میں start-up instructions ہوتی ہیں، جنہیں BIOS کہتے ہیں۔ دو اور۔ Flash memory non-volatile ہے مگر اسے دوبارہ لکھا جا سکتا ہے، اس لیے وہ SSDs اور memory cards میں استعمال ہوتی ہے۔ Virtual memory، hard disc یا SSD کا ایک حصہ ہے جو RAM بھر جانے پر extra RAM کی طرح استعمال ہوتا ہے۔

Method۔ Memory type کا نام لیں۔ اس کی key property State کریں۔ پھر property کو اس کے use سے جوڑیں۔ اگر question دو memory types کے نام لے تو ہر ایک کے بارے میں کچھ کہیں۔ Virtual memory کے لیے movement کو describe کریں۔ RAM بھر جائے تو جو data استعمال میں نہیں، اسے disc پر منتقل کر دیا جاتا ہے۔ دوبارہ ضرورت ہو تو اسے واپس RAM میں لایا جاتا ہے۔

Worked Example۔ یہ June دو ہزار چوبیس کے Paper ایک کا اصل question ہے۔ Explain کریں کہ computers کو RAM اور ROM دونوں کی ایک وجہ کیا ہے۔ اس کے دو marks ہیں۔ RAM سے شروع کریں۔ RAM volatile ہے۔ اس لیے computer on ہوتے وقت RAM خالی ہوتی ہے۔ اس میں چلانے کے لیے ابھی کچھ نہیں ہوتا۔ اس لیے start-up instructions کسی مستقل جگہ رکھنی ہوں گی۔ وہ ROM ہے۔ وہ power کے بغیر بھی BIOS رکھتی ہے، اور BIOS computer کو boot کرتا ہے۔ انہیں so سے جوڑیں۔ RAM volatile ہے، so power کے بغیر اس کا contents ختم ہو جاتا ہے۔ Therefore start-up instructions کو مستقل رکھنے کے لیے ROM چاہیے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake یہ کہنا ہے کہ ROM volatile ہے، یا ROM operating system store کرتی ہے۔ ROM non-volatile ہے، اور وہ BIOS store کرتی ہے۔ Operating system بعد میں storage سے load ہوتا ہے۔ ایک اور mistake virtual memory کو extra RAM chips کہنا ہے۔ وہ hard disc یا SSD پر جگہ ہے جو RAM کی طرح کام کرتی ہے۔

Answer۔ SSD کا ایک حصہ virtual memory کے طور پر استعمال ہوتا ہے۔ جو data استعمال میں نہیں، وہ RAM سے SSD میں منتقل ہو جاتا ہے۔ دوبارہ ضرورت ہو تو واپس RAM میں آتا ہے۔ Disc، RAM سے slower ہے، اس لیے laptop slow ہو سکتا ہے۔ Method یاد رکھیں: memory کا نام لیں، اس کی property State کریں، اور اسے اس کے use سے جوڑیں۔ اب اس type کے practice questions کریں۔
