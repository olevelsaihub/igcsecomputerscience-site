Idea۔ Shelf پر label لگے boxes کا سوچیں۔ Score نام کا box ایک چیز رکھتا ہے، اور اندر کی چیز آپ جب چاہیں بدل سکتے ہیں۔ Program میں وہ box variable ہے: memory میں ایک named جگہ جس کی value program چلنے کے دوران بدل سکتی ہے۔ Score صفر سے شروع ہوتا ہے۔ Score equals score plus پانچ، تو پانچ print ہوتا ہے۔ Constant ایک named value ہے جو program چلنے کے دوران fixed رہتی ہے۔ Python میں ہم اس کا نام capitals میں لکھتے ہیں، جیسے VAT rate۔ اگر rate کبھی بدلے، تو programmer ایک line update کرتا ہے، ہر وہ جگہ نہیں جہاں یہ استعمال ہوا۔ Array ایک ہی data type کی کئی values ایک نام کے تحت رکھتا ہے۔ ہر value کا ایک index ہوتا ہے، صفر سے شروع۔ Scores index صفر بارہ ہے، اور scores index دو پندرہ ہے۔ One-dimensional array ایک اکیلی row کی طرح ہے۔ Two-dimensional array ایک table کی طرح ہے، rows اور columns کے ساتھ۔ اس کی ہر value پھر بھی وہی data type ہوتی ہے۔ Record ایک item کے متعلق fields کو اکٹھا کرتا ہے، اور fields مختلف data types کی ہو سکتی ہیں۔ ایک product کا یہ record ایک string، ایک real اور ایک integer رکھتا ہے۔

Method۔ پہلے key word پہچانیں: variable، constant، array یا record۔ Definition کے لیے بتائیں کہ کیا store ہوتا ہے اور کیا یہ بدل سکتا ہے۔ Difference کے لیے پہلی item describe کریں، whereas لکھیں، پھر دوسری describe کریں۔ Array versus record کے لیے، data types چیک کریں۔ ایک ہی type کی values array میں جا سکتی ہیں۔ ایک item کے متعلق ملی جلی types کو record چاہیے۔

Worked Example۔ یہ جون دو ہزار پچیس کے Paper دو کا اصل question ہے۔ Variable اور array کے درمیان ایک difference Describe کریں۔ یہ دو marks کا ہے۔ لکھیں کہ ہر ایک کیا store کرتا ہے۔ Variable ایک وقت میں ایک value رکھتا ہے، جیسے score equals بارہ۔ Array ایک نام کے تحت کئی values رکھتا ہے، جیسے scores جس میں بارہ، سات اور پندرہ ہیں۔ دونوں حصوں کو whereas سے جوڑیں۔ A variable holds just one value at a time, whereas an array holds many values under one name۔ ہر حصے پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی صرف ایک طرف describe کرنا ہے۔ Variable ایک value رکھتا ہے، یہ صرف آدھا answer ہے، اس لیے صرف ایک mark ملتا ہے۔ ایک اور غلطی یہ کہنا ہے کہ constant user کو value بدلنے سے روکتا ہے۔ فائدہ programmer کے لیے ہے: value ایک جگہ set ہوتی ہے اور program چلنے کے دوران غلطی سے بدلی نہیں جا سکتی۔

Answer۔ Data types دیکھیں۔ Name string ہے، price real ہے، اور stock میں تعداد integer ہے۔ Types ملی جلی ہیں۔ تو record استعمال کریں، کیونکہ اس کی fields مختلف data types کی ہو سکتی ہیں، اور وہ سب ایک product کو describe کرتی ہیں۔ Method یاد رکھیں۔ key word پہچانیں، بتائیں کہ کیا store ہوتا ہے اور کیا بدل سکتا ہے، اور whereas سے دونوں طرف describe کریں۔ اب اس type کے practice questions کریں۔
