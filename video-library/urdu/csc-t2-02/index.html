Method۔ پہلے key word پہچانیں: variable، constant، array یا record۔ Definition کے لیے بتائیں کہ کیا store ہوتا ہے اور کیا یہ بدل سکتا ہے۔ Difference کے لیے پہلی item describe کریں، whereas لکھیں، پھر دوسری describe کریں۔ Array versus record کے لیے، data types چیک کریں۔ ایک ہی type کی values array میں جا سکتی ہیں۔ ایک item کے متعلق ملی جلی types کو record چاہیے۔

Worked Example۔ یہ جون دو ہزار پچیس کے Paper دو کا اصل question ہے۔ Variable اور array کے درمیان ایک difference Describe کریں۔ یہ دو marks کا ہے۔ لکھیں کہ ہر ایک کیا store کرتا ہے۔ Variable ایک وقت میں ایک value رکھتا ہے، جیسے score equals بارہ۔ Array ایک نام کے تحت کئی values رکھتا ہے، جیسے scores جس میں بارہ، سات اور پندرہ ہیں۔ دونوں حصوں کو whereas سے جوڑیں۔ A variable holds just one value at a time, whereas an array holds many values under one name۔ ہر حصے پر ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی صرف ایک طرف describe کرنا ہے۔ Variable ایک value رکھتا ہے، یہ صرف آدھا answer ہے، اس لیے صرف ایک mark ملتا ہے۔ ایک اور غلطی یہ کہنا ہے کہ constant user کو value بدلنے سے روکتا ہے۔ فائدہ programmer کے لیے ہے: value ایک جگہ set ہوتی ہے اور program چلنے کے دوران غلطی سے بدلی نہیں جا سکتی۔
