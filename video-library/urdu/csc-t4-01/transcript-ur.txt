Idea۔ سوچیں کہ toast بن رہا ہے۔ bread اندر جاتی ہے، toaster اسے گرم کرتا ہے، اور toast باہر آتا ہے۔ کچھ اندر جاتا ہے، کام ہوتا ہے، اور result نکلتا ہے۔ computers بھی ایسے ہی کام کرتے ہیں۔ اس picture کو input, process, output model، یا I P O کہتے ہیں۔ Input وہ data ہے جو اندر جاتا ہے۔ Process اس پر ہونے والا کام ہے۔ Output وہ result ہے جو program بناتا ہے۔ اور models بھی ہیں۔ Sequential کا مطلب ہے instructions ایک کے بعد ایک چلتی ہیں۔ Parallel کا مطلب ہے کام کو processors، یعنی cores میں بانٹ دیا جاتا ہے جو ایک ہی وقت میں چلتے ہیں۔ Multi-agent کا مطلب ہے الگ الگ systems ایک goal پر مل کر کام کرتے ہیں۔

Method۔ Scenario پڑھیں اور ہر value کے نیچے line لگائیں۔ Input باہر سے program کو دیا جاتا ہے۔ وہ type کیا جاتا ہے یا sense ہوتا ہے۔ جو کچھ program خود نکالے، وہ input نہیں ہے۔ Process اصل working ہے۔ اسے scenario کے names کے ساتھ لکھیں، جیسے pay rate times hours۔ صرف لفظ calculate لکھنے سے mark نہیں ملتا۔ Output وہ result ہے جو program آخر میں بناتا ہے۔ وہ screen پر دکھایا جاتا ہے، print ہوتا ہے یا کوئی action ہوتا ہے۔ Parallel question میں ہر core کو الگ حصہ دیں جسے دوسرے کی ضرورت نہ ہو۔ جوابات کو join کرنا بعد کے step میں آئے گا، کیونکہ اس کے لیے دونوں results چاہییں۔

Worked Example۔ یہ June دو ہزار پچیس کے Paper دو کا اصل question ہے۔ ایک payslip میں pay rate، hours، total pay، tax اور income ہیں۔ Program کا استعمال کردہ ایک input، ایک process اور ایک output دیں۔ اس کے تین marks ہیں۔ کون سی values type کی جانی چاہییں؟ Pay rate، اٹھارہ pounds پچھتر، اور hours، انیس۔ Hours کو کوئی calculate نہیں کرتا۔ اس لیے hours input ہے۔ Total pay کیسے بنتا ہے؟ Pay rate times hours۔ اٹھارہ پچھتر ضرب انیس، تین سو چھپن pounds پچیس ہے۔ یہ calculation process ہے۔ باقی چیزیں چیک کریں۔ Tax، total کا بیس per cent ہے، اکہتر pounds پچیس۔ Income، total minus tax ہے، دو سو پچاسی pounds۔ تینوں program بناتا ہے، اس لیے یہ outputs ہیں۔ تو جواب ہے: input، hours۔ Process، pay rate times hours۔ Output، total pay۔ ہر box کا ایک mark ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ سب سے common mistake یہ ہے کہ calculate کی ہوئی value، جیسے total pay، کو input لکھ دیں۔ اگر program اسے خود نکالتا ہے تو وہ output ہے۔ Parallel tables میں ہر core پہلے ایک independent حصہ کرتا ہے۔ حصوں کو جمع کرنا بعد کی row میں جائے گا، کیونکہ اس کے لیے دونوں answers چاہییں۔

Your Turn۔ اب آپ try کریں۔ ایک fitness app کو بتایا جاتا ہے کہ کسی نے آج کتنے steps چلے۔ ہر step صفر اعشاریہ سات metres کا ہے۔ App چلی ہوئی distance دکھاتی ہے۔ ایک input، ایک process اور ایک output دیں۔ یہاں رک کر حل کریں۔

Answer۔ Step count دیا گیا ہے، اس لیے وہ input ہے۔ Process ہے steps times صفر اعشاریہ سات۔ دکھائی جانے والی distance output ہے۔ آٹھ ہزار steps کے لیے یہ پانچ ہزار چھ سو metres ہے۔ Method یاد رکھیں: جو دیا گیا ہے وہ ڈھونڈیں، اصل working لکھیں، پھر result کا نام لیں۔ ترتیب input، process، output رکھیں۔ اب اس type کے practice questions کریں۔
