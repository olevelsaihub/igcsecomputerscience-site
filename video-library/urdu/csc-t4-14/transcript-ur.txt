Idea۔ Trainee pilots flight simulator میں practice کرتے ہیں۔ وہ engine failure کا سامنا محفوظ طریقے سے بار بار کر سکتے ہیں، بغیر کسی کو نقصان پہنچے۔ Computer simulation ہمیں ایسی situations آزمانے دیتی ہے جو حقیقی زندگی میں خطرناک، مہنگی یا ناممکن ہوں۔ Model rules اور data کا set ہے جو کسی حقیقی system کی نمائندگی کرتا ہے۔ Simulation model کو چلاتی ہے، تاکہ دیکھا جائے وقت کے ساتھ کیا ہوتا ہے۔ یہ Python میں ایک چھوٹا model ہے۔ Rule ہے: rabbits ہر سال double ہو جاتے ہیں۔ اسے چلانا simulation ہے۔ تین سال ایک لمحے میں گزر جاتے ہیں: دو سو، چار سو، پھر آٹھ سو۔ Simulations کے بڑے benefits ہیں۔ وہ safe ہیں۔ آپ variables بدل کر پوچھ سکتے ہیں what if۔ وہ real time سے تیز یا آہستہ چل سکتی ہیں۔ اور وہ outcomes predict کرنے اور ideas test کرنے میں مدد دیتی ہیں۔ مگر simulation اتنی ہی اچھی ہے جتنا اس کا data اور rules۔ حقیقی rabbits ہمیشہ double نہیں ہوتے رہتے، اس لیے ہمارا model چند سال بعد غلط ہو جاتا ہے۔ بڑی simulations کو powerful processor بھی چاہیے، کیونکہ وہ بہت data اور بہت calculations سنبھالتی ہیں۔

Method۔ پہلے طے کریں کہ کیا پوچھا گیا ہے: benefit، limit یا hardware need۔ ایک واضح point State کریں۔ پھر scenario میں اس کے جڑے ہوئے اثر سے اسے پھیلائیں۔ وہ benefit کبھی نہ دہرائیں جو question پہلے دے چکا ہو۔

Worked Example۔ یہ June دو ہزار چوبیس کے Paper ایک کا اصل question ہے۔ Peter rabbits اور foxes کی simulation بنا رہا ہے۔ ایک benefit یہ ہے کہ وہ حقیقی animals دیکھنے سے آسان ہے۔ ایک اور benefit Explain کریں۔ اس کے دو marks ہیں۔ Simpler پہلے ہی استعمال ہو چکا ہے، تو ہم دوسرا benefit چنتے ہیں۔ Simulation حقیقی زندگی سے بہت تیز چل سکتی ہے۔ اب اسے Peter کے scenario سے جوڑیں۔ Rabbit اور fox کی تعداد کے کئی سال منٹوں میں دیکھے جا سکتے ہیں، اس لیے وہ long-term trends جلدی پہچان سکتا ہے۔ تو جواب ہے: simulation حقیقی زندگی سے بہت تیز چل سکتی ہے، اس لیے Peter کم وقت میں rabbits اور foxes کی کئی generations دیکھ سکتا ہے، اور long-term trends پہچان سکتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake ایک point اور اس کے جڑے اثر کے بجائے دو الگ facts دینا ہے۔ ایک اور mistake یہ کہنا ہے کہ simulation ہمیشہ accurate ہوتی ہے۔ اس کے results اس کے data اور rules پر منحصر ہیں۔

Your Turn۔ اب آپ try کریں۔ ایک town نئی traffic lights کی planning کے لیے traffic simulation استعمال کرتا ہے۔ Explain کریں کہ town کو اس کے results پر پوری طرح بھروسا کیوں نہیں کرنا چاہیے، ایک وجہ۔ یہاں رک کر حل کریں۔

Answer۔ Point ایک limit ہے: simulation اتنی ہی اچھی ہے جتنا اس کا data اور rules۔ پھر link: اگر traffic data یا drivers کے بارے میں assumptions غلط ہوں تو predicted queues بھی غلط ہوں گی، so lights کی planning بری ہو سکتی ہے۔ Method یاد رکھیں: فیصلہ کریں کیا پوچھا گیا ہے، ایک point State کریں، پھر اسے so کے ساتھ scenario سے جوڑیں۔ اب اس type کے practice questions کریں۔
