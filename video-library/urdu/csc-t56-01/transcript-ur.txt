Idea۔ اپنے گھر کا سوچیں۔ آپ کا phone، laptop اور television سب ایک internet connection share کرتے ہیں، اور ایک دوسرے کو چیزیں بھیج سکتے ہیں۔ دو یا زیادہ devices جو data اور resources share کرنے کے لیے جڑی ہوں، network بناتی ہیں۔ Computers کو کیوں جوڑیں؟ Files share کرنے کے لیے، hardware جیسے printer share کرنے کے لیے، ایک internet connection share کرنے کے لیے، اور communicate کرنے کے لیے۔ ایک organisation ہر computer کو ایک ہی جگہ سے backup، update اور secure بھی کر سکتی ہے۔ فاصلہ type طے کرتا ہے۔ PAN ایک شخص کے ارد گرد کی devices کو جوڑتا ہے، جیسے phone سے جڑے earbuds۔ LAN ایک building یا site کو cover کرتا ہے۔ WAN بڑے علاقے کو cover کرتا ہے اور LANs کو جوڑتا ہے۔ Internet سب سے بڑا WAN ہے۔ دو usage models بھی ہیں۔ Client-server میں ایک central server file storage یا logins جیسی services دیتا ہے، اور clients ان کی درخواست کرتے ہیں۔ Peer-to-peer میں ہر device برابر ہے اور سیدھا share کرتی ہے۔

Method۔ پہلے scenario میں فاصلے کے نیچے line لگائیں۔ پھر اس سے match کرنے والی network type کا نام لیں۔ اگر usage model پوچھا جائے تو چیک کریں کہ کیا ایک central device باقی سب کو serve کر رہی ہے۔ Difference کے لیے ایک feature لیں اور دونوں پہلو لکھیں: WAN کیا کرتا ہے، whereas LAN کیا کرتا ہے۔ Area، ownership، bandwidth اور latency سب اچھے features ہیں۔

Worked Example۔ یہ June دو ہزار چوبیس کے Paper ایک کا اصل question ہے۔ WAN اور LAN کے درمیان دو differences دیں۔ اس کے دو marks ہیں۔ Area کے size سے شروع کریں۔ WAN بڑے علاقے پر پھیلا ہوتا ہے، جیسے کئی cities یا countries، whereas LAN صرف ایک building یا site کو cover کرتا ہے۔ اب ایک مختلف feature: latency، یعنی delay۔ WAN میں عموماً LAN سے زیادہ latency ہوتی ہے، کیونکہ data بہت زیادہ فاصلہ طے کرتا ہے اور بہت زیادہ links سے گزرتا ہے۔ چیک کریں: دو lines، دو مختلف features، اور ہر line میں دونوں networks کا نام۔ ہر line پر ایک mark ملتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common mistake مبہم difference ہے۔ WAN is slower یہ نہیں بتاتا کہ کیا slower ہے۔ Feature کا نام لیں: latency، یا bandwidth۔ ایک اور mistake ایک ہی point دو بار دینا ہے۔ بڑا area اور کئی cities کو cover کرتا ہے، ایک ہی idea ہیں، اس لیے ان پر صرف ایک mark ملتا ہے۔

Answer۔ سب computers ایک ہی building میں ہیں، تو یہ LAN ہے۔ اچھی وجہ: staff کسی بھی computer سے files share کر سکتا ہے، جیسے appointment list۔ Printer یا ایک internet connection share کرنا بھی چلے گا۔ Method یاد رکھیں: فاصلہ پڑھیں، PAN، LAN یا WAN کا نام لیں، اور differences کو ایک feature پر جوڑوں کی صورت میں لکھیں۔ اب اس type کے practice questions کریں۔
