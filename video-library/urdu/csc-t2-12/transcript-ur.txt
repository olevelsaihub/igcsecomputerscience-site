Idea۔ school میں ہر pupil کا نام ہوتا ہے، تاکہ آپ صحیح فرد کو بلا سکیں۔ program میں بھی ہر variable، constant، array اور subprogram کا نام ہوتا ہے۔ اس نام کو identifier کہتے ہیں۔ ایسی recipe سوچیں جس میں لکھا ہو، fruit ڈالیں۔ Fruit ایک placeholder ہے۔ پکاتے وقت آپ اصل apples دیتے ہیں۔ code میں def line کا placeholder parameter ہے۔ call میں دی جانے والی value argument ہے۔ variable کہاں بنا، اس سے اس کا scope طے ہوتا ہے۔ def block کے اندر بنا variable local ہے۔ main program میں بنا variable global ہے۔ اور اس کی پہلی value اس کا data type بتاتی ہے: صفر اعشاریہ صفر یا float سے real بنتا ہے۔

Method۔ پہلے underline کریں کہ بالکل کس قسم کی item مانگی گئی ہے۔ پھر صحیح جگہ جائیں۔ Def headers میں parameters ہوتے ہیں۔ Call کے brackets میں arguments۔ function call کے equals کے بائیں طرف والا نام returned value لیتا ہے۔ آخر میں identifier بالکل ویسے ہی copy کریں جیسے لکھا ہے، انہی capitals کے ساتھ۔ جب نام مانگا گیا ہو تو line number نہ دیں۔

Worked Example۔ یہ June دو ہزار پچیس کے Paper دو کا اصل سوال ہے۔ ایک parameter کا نام identify کریں۔ اس کا ایک mark ہے۔ یہ program ہے، جسے olevels dot com نے دوبارہ بنایا ہے۔ subprogram header تلاش کریں۔ Def get wages، جس کے brackets میں in sales اور in age ہیں۔ header کے brackets کے اندر کے نام parameters ہیں: in sales اور in age۔ آخری line میں sales اور age الگ ہیں۔ یہ arguments ہیں جو call میں دیے گئے۔ تو ایک parameter بالکل صحیح spelling میں لکھیں: in sales، capital S کے ساتھ۔ کوئی بھی parameter mark دلاتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ سب سے عام غلطی parameters اور arguments کو الجھانا ہے۔ Sales call میں دیا گیا ہے، اس لیے یہ argument ہے، parameter نہیں۔ ایک اور غلطی یہ ہے کہ local variable مانگا جائے اور آپ global variable کا نام لکھ دیں۔ Wages def block کے اندر بنا ہے، اس لیے local ہے۔ Sales main program میں بنا ہے، اس لیے global ہے۔

Your Turn۔ اب آپ کوشش کریں۔ اس code سے ایک parameter، ایک local variable، returned value لینے والا variable، اور ایک constant identify کریں۔ یہاں رک کر حل کریں۔

Answer۔ Parameter، p length یا p width ہے، جو def line میں ہے۔ Result def block کے اندر بنا ہے، اس لیے local ہے۔ Answer، line چھ پر returned value لیتا ہے۔ Rate، capitals میں، constant ہے۔ method یاد رکھیں: item کی قسم جانیں، code میں اس کی جگہ پر جائیں، اور نام بالکل ویسے ہی copy کریں۔ اب اس type کے practice questions کریں۔
