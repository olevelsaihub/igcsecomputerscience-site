Idea۔ Fairy lights کا سوچیں۔ کچھ lights میں ایک خراب bulb سے پوری لڑی بجھ جاتی ہے۔ دوسروں میں صرف وہی bulb بجھتا ہے۔ جس طرح چیزیں جڑی ہوں، وہی طے کرتا ہے کہ ایک حصہ خراب ہو تو کیا ہوگا۔ Network میں connections کا layout topology ہے۔ Star میں ہر device کی اپنی cable ایک central switch تک جاتی ہے۔ ایک cable ٹوٹے تو صرف وہی device کٹتی ہے، اور fault آسانی سے ڈھونڈا جا سکتا ہے۔ مگر switch fail ہو جائے تو پورا network رک جاتا ہے۔ Bus میں ہر device ایک مشترک main cable سے جڑی ہوتی ہے، اور ہر سرے پر terminator ہوتا ہے۔ یہ سستی ہے۔ Ring میں devices ایک بند loop بناتی ہیں اور data ایک ہی طرف جاتا ہے، اس لیے packets آپس میں نہیں ٹکراتے۔ Mesh میں ہر device کئی دوسری devices سے جڑی ہوتی ہے، اس لیے بہت سے routes ہیں۔ Data ٹوٹے link کے گرد سے جا سکتا ہے۔ یہ بہت reliable ہے، مگر مہنگی اور set up کرنے میں مشکل ہے۔ Internet ایک بہت بڑی partial mesh ہے۔

Method۔ پہلے شکل پہچانیں۔ ایک مشترک cable bus ہے۔ بند loop ring ہے۔ جو سب ایک central box سے جڑا ہو وہ star ہے۔ بہت سے cross-links mesh بناتے ہیں۔ پھر اس topology کی strength اور weakness یاد کریں۔ Explain question کے لیے feature دیں، پھر اس کا effect، so یا because سے جوڑ کر۔

Worked Example۔ یہ June دو ہزار چوبیس کے Paper ایک کا اصل question ہے۔ Fault tolerant network reliable service دیتا ہے۔ Explain کریں کہ figure والی topology fault tolerant کیوں ہے، ایک وجہ۔ اس کے دو marks ہیں۔ Figure میں ہر computer کئی دوسروں سے جڑا ہے، تو یہ mesh ہے۔ Feature سے شروع کریں: ہر computer کے دو یا زیادہ links ہیں، اس لیے کسی بھی دو devices کے درمیان ایک سے زیادہ path ہے۔ اب effect۔ اگر ایک link ٹوٹے یا مصروف ہو تو packets کسی اور route سے بھیجے جاتے ہیں، اور پھر بھی اپنی destination پر پہنچ جاتے ہیں۔ انہیں so سے جوڑیں۔ ہر node کے کئی links ہیں، so packets ٹوٹے link کے گرد سے جا کر بھی پہنچ سکتے ہیں۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ غلط topology کے drawbacks سے ہوشیار رہیں۔ Star میں main cable نہیں ہوتی۔ اس کا کمزور point central switch ہے۔ ایک اور mistake یہ کہنا ہے کہ mesh fault tolerant ہے کیونکہ وہ reliable ہے۔ یہ تو question کو دہرانا ہے۔ Multiple routes کا ذکر کریں۔
