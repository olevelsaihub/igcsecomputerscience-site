Idea۔ Station پر ticket machine کا سوچیں۔ وہ آپ کا stop پوچھتی ہے، price طے کرتی ہے، اور اگلے شخص کا انتظار کرتی ہے۔ وہ ہر بار وہی steps follow کرتی ہے۔ کاغذ پر ہم ایسے steps کو flowchart یا pseudocode کی شکل میں لکھتے ہیں۔ Flowchart چار shapes استعمال کرتا ہے۔ Rounded box، start یا stop ہے۔ Parallelogram، input یا output ہے۔ Rectangle، process ہے، جیسے calculation۔ Diamond، decision ہے۔ ہر decision diamond کے بالکل دو exits ہوتے ہیں، جن پر Yes اور No لکھا ہوتا ہے۔ ہر line پر arrow ہوتا ہے۔ Loop وہ arrow ہے جو اوپر کسی پچھلے step پر واپس جاتا ہے۔ Pseudocode میں یہی خیالات الفاظ میں ہوتے ہیں۔ یہاں count کو loop سے پہلے صفر set کیا گیا ہے۔ Loop پانچ numbers پڑھتا ہے۔ اگر کوئی number mod تین صفر ہو، تو وہ تین سے پوری طرح divide ہوتا ہے، اس لیے count ایک بڑھتا ہے۔

Method۔ پہلے bullet points سے حصوں کی list بنائیں: inputs، decisions، جو repeat ہوتا ہے، اور outputs۔ ہر bullet پر عموماً ایک mark ملتا ہے۔ اگلا، کسی بھی loop سے پہلے starting values set کریں۔ ہر condition کے لیے ایک decision شامل کریں، معقول ترتیب میں، اور دونوں exits label کریں۔ پھر ہر output صحیح branch پر رکھیں، loop بند کریں، اور یقینی بنائیں کہ Stop تک راستہ ہے۔ آخر میں ہر path کے لیے ایک value سے test کریں۔

Worked Example۔ یہ جون دو ہزار پچیس کے Paper ایک کا اصل question ہے۔ user ایک number n input کرتا ہے۔ اگر n صفر ہو تو program رک جاتا ہے۔ اگر positive ہو تو Positive دکھاتا ہے۔ اگر negative ہو تو Negative دکھاتا ہے۔ یہ صفر input ہونے تک repeat ہوتا ہے۔ چھ marks کے لیے flowchart بنائیں۔ Start کو rounded box میں بنائیں، پھر parallelogram: input n۔ پھر ایک diamond: is n equal to صفر؟ Yes exit Stop پر جاتا ہے۔ No exit سے دوسرا diamond بنائیں: is n greater than صفر؟ Yes، output Positive پر جاتا ہے۔ No، output Negative پر۔ دونوں outputs سے arrows واپس اوپر input n تک بنائیں۔ اب test کریں۔ پانچ: صفر نہیں، صفر سے greater ہے، اس لیے Positive۔ Minus تین: صفر نہیں، صفر سے greater نہیں، اس لیے Negative۔ صفر: پہلے diamond پر Yes، اس لیے Stop۔ Marks ملتے ہیں start اور input پر، ہر labelled decision پر، صحیح branches پر دو outputs پر، arrows اور loop پر، اور صحیح symbols پر۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی ایسا diamond بنانا ہے جس کا ایک exit ہو، یا جس پر Yes اور No labels نہ ہوں۔ ہر decision کے دو labelled exits چاہئیں۔ ایک اور غلطی Start پر واپس loop کرنا ہے۔ اس سے سب کچھ reset ہو جاتا ہے۔ اس کی جگہ input step پر واپس loop کریں۔

Your Turn۔ اب آپ کوشش کریں۔ ایسا pseudocode لکھیں جو دس whole numbers پڑھے، گنے کہ کتنے even ہیں، پھر count display کرے۔ رک کر حل کریں۔

Answer۔ loop سے پہلے evens کو صفر set کریں۔ ایک سے دس تک FOR loop استعمال کریں، اور ہر بار receive n کریں۔ Loop کے اندر، اگر n mod دو صفر ہو، تو evens میں ایک add کریں۔ Loop ختم ہونے کے بعد، count کو display پر بھیجیں۔ Method یاد رکھیں۔ حصوں کی list بنائیں، loop سے پہلے counters set کریں، ہر decision label کریں، پھر ہر path test کریں۔ اب اس type کے practice questions کریں۔
