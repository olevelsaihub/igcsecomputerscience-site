Idea. Picture a supermarket queue. It moves faster if the cashier works faster, if more tills are open, or if popular items are kept right by the till. A CPU speeds up in the same three ways. Clock speed is how many cycles the CPU clock makes each second, measured in hertz. Three gigahertz is three billion cycles each second. More cycles means more instructions processed in the same time. A core is a separate processing unit inside the CPU. A quad-core CPU has four, so it can work on more instructions at the same time. Cache is a small amount of very fast memory inside or close to the CPU. It holds instructions and data used often, so the CPU waits less for slower RAM. A larger cache holds more of them.

Method. To explain a factor, name it. Say what it changes inside the CPU. Link that to speed. In a scenario, say what the user would notice, such as lag in a game. A higher clock speed has a cost. It processes more instructions each second, but it uses more power and makes more heat, so it needs more cooling.

Worked example. Here is a real question from Paper 1 in June 2023. One type of cache sits between main memory and the CPU. Explain one reason cache is used in a computer. It is worth two marks. Two facts. What does cache hold? Instructions and data that are used often. How fast is it? Much faster than RAM. Link them. The CPU finds these items in cache, so it does not wait for slow RAM, so processing is faster. So the answer is: cache speeds up processing because it holds frequently used instructions and data near the CPU, so the CPU does not wait for slower RAM. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is saying cache stores all data, or stores it permanently. Cache is small and temporary. It holds only items used often. Another mistake is a vague answer, like cache, it is faster. Name the factor fully and say why it speeds things up.

Answer. Three point five gigahertz is three and a half billion cycles each second, compared with two billion. More instructions are processed each second, so the game runs more smoothly with less lag. The drawback: the faster CPU uses more power and gets hotter.
