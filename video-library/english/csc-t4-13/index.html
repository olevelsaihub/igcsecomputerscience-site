Idea. A car needs servicing. The oil is changed, the tyres are checked, and a spare is kept in the boot. A computer needs looking after too. The programs that do this are called utility software. There are five main utilities to know. Anti-malware, defragmentation, backup, file repair and file conversion. Anti-malware protects against harmful software. Types include antivirus, anti-spyware, anti-adware and a software firewall. Antivirus can scan for viruses, quarantine infected files, remove them, scan in real time and update itself. Over time, a file's blocks get scattered across a hard drive. File A is split into three places, with gaps between. This is called fragmentation, and it slows reading down.

Method. A defragmentation utility moves each file's blocks together and in order, and gathers the free space at one end. The head moves less, so files open faster. It does not add any space. To choose a utility, match the problem. A slow hard disc needs defragmentation. A corrupt file needs file repair. Damaged or lost files need backup and restore. A wrong format needs file conversion. Malware needs anti-malware.

Worked example. Here is a real question from Paper 1 in June 2024. Anna has four problems. Complete the table with the type of utility software she should use for each. Four marks. Row one: a file cannot be read because it is corrupt. Use a file repair utility. Row two: a JPEG must become a PNG. Changing format needs a file conversion utility. Row three: a flood damaged files on a server, but the data is needed. A backup copy must be restored, so use backup and restore. Row four: the hard drive is slow, so use defragmentation. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is giving a brand name. Brand names are not credited. Give the type of software. Another mistake is saying defragmentation adds space to the disc. The amount of free space stays the same. It is only gathered together.

Your turn. Now you try. File P has blocks P one and P two. File Q has blocks Q one, Q two and Q three. The disc holds, in order: Q two, P one, empty, Q one, P two, empty, Q three. Show the disc after defragmenting. Pause here and work it out.

Answer. Put P one and P two together, then Q one, Q two and Q three in order. The two empty spaces go together at the end. Either file could go first, as long as each file's blocks are together and in order. Remember the method: read the issue, name the type of utility, and never give a brand name.
