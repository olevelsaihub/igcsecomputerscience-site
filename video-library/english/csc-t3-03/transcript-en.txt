Idea. Think of a car's mileage counter showing zero zero zero zero. Wind it back by one, and it rolls round to nine nine nine nine. Eight bits behave the same way: one less than all zeros is all ones. So all ones can stand for minus one. In eight-bit two's complement, the leftmost column is worth minus one hundred and twenty-eight. The rest are sixty-four down to one, as normal. So all ones is minus one hundred and twenty-eight plus one hundred and twenty-seven, which is minus one. The range is minus one hundred and twenty-eight, one zero zero zero, zero zero zero zero, up to plus one hundred and twenty-seven, zero one one one, one one one one. There is only one pattern for zero.

Method. Pattern to denary: write the headers, starting with minus one hundred and twenty-eight, and add the values above every one. For one zero zero zero, zero one zero one, that is minus one hundred and twenty-eight plus four plus one, which is minus one hundred and twenty-three. Negative denary to pattern takes three steps. Write the positive size in eight bits. Flip every bit. Then add one. For minus six: six is zero zero zero zero, zero one one zero. Flip it to get one one one one, one zero zero one. Add one to get one one one one, one zero one zero. Check: minus one hundred and twenty-eight plus one hundred and twenty-two is minus six.

Worked example. Here is a real question from Paper 1 in June 2024. Convert the two's complement binary integer one one zero zero, zero zero zero one to denary. It is worth two marks. Write the headers, starting at minus one hundred and twenty-eight. Place the bits underneath. There are ones under minus one hundred and twenty-eight, sixty-four and one. Add them: minus one hundred and twenty-eight plus sixty-four plus one is minus sixty-three. Check with flip and add one. Flip to get zero zero one one, one one one zero. Add one to get zero zero one one, one one one one, which is sixty-three. So the original was minus sixty-three. One mark is for the minus sign, and one for sixty-three. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is using the wrong system. Read as sign and magnitude, one one zero zero, zero zero zero one gives minus sixty-five. Read as unsigned, it gives one hundred and ninety-three. In two's complement it is minus sixty-three. Another mistake is flipping but forgetting to add one. For minus six, one one one one, one zero zero one is really minus seven.
