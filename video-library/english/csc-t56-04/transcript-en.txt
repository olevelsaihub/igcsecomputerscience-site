Idea. Imagine posting a jigsaw puzzle to a friend in small envelopes. You number each envelope and write the address, and the post van carries them. Your friend puts the pieces back in order. Networks send data the same way, in small pieces called packets. The T C P I P model splits the work into four layers. From top to bottom: application, transport, network, and data link. The application layer holds the protocols programs use, such as H T T P, F T P and S M T P. The transport layer splits data into packets and numbers them. On receiving, it checks they all arrived, reorders them, and asks for missing ones again. The network layer adds the sender's and receiver's I P addresses, and routes each packet across networks. The data link layer moves packets across the physical connection between two devices, using M A C addresses. When sending, data passes down the layers. When receiving, it passes back up, and each layer removes what its partner added. Because of layers, one layer can be changed without changing the others.

Method. Write the four layers down the margin. Find the job in the question and match it by its key words. Check whether it is about sending or receiving. Then write the layer and its function side by side. These key words point to each layer. Protocols for programs: application. Split and reassemble: transport. I P addresses and routing: network. M A C addresses and the physical link: data link.

Worked example. Here is a real question from Paper 1 in November 2021. Name two layers of the T C P I P stack, and give one function for each. It is worth four marks. Choose the layers you know best. Transport: it splits the data into packets, and gives each packet a sequence number, so they can be put back in order. Network: it adds the source and destination I P addresses to each packet, and routes it across the networks to its destination. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is giving the network layer the job of splitting data into packets. Splitting and numbering belong to the transport layer. Another mistake is the name. There is no data layer. Write the full name: data link layer.

Your turn. Now you try. A file arrives at a laptop. Packet seven is missing, and the others arrived out of order. Which layer deals with this? Give two things it does. Pause here and work it out.

Answer. It is the transport layer. It checks that every packet has arrived, puts the packets back in order using their numbers, and asks for packet seven to be sent again. Remember the four layers and their jobs: application for programs' protocols, transport to split and rebuild, network for addresses and routes, data link for the physical link.
