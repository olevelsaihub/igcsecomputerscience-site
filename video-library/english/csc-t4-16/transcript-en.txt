If a book is written in French and you only read English, you need a translator. A CPU only understands machine code. So a program written in any other language must be translated first. An assembler translates assembly language, which is low-level, into machine code. Assembled code can then run on its own. A compiler translates a whole high-level program in one go, and makes an executable file. That file runs quickly without the compiler, and the source code does not need to be shared. Errors are listed after the whole program is translated. An interpreter translates and runs a high-level program one line at a time, every time it runs. Here it prints Start, then stops at the error on line three. Line four never runs.

First ask: is the source code low-level? Then it is the assembler. If it is high-level, ask: whole program at once, or line by line each run? In tick tables, test every translator against every statement. For a task, match its need. Selling finished software suits a compiler. Testing new code suits an interpreter. A hardware driver written in assembly needs an assembler.

Here is a real question from Paper 1 in June 2024. Tick the characteristics of each translator. More than one translator can be ticked for a characteristic. Three marks. Statement one: it does not have to be in memory to run the translated code. Assembled and compiled code run on their own, so tick assembler and compiler. Statement two: translates high-level code. Tick interpreter and compiler. Statement three: runs high-level code until it finishes or hits a syntax error. Only an interpreter runs code as it translates. Statement four: translates low-level code into machine code. That is the assembler. Check each column. Assembler: one and four. Interpreter: two and three. Compiler: one and two. One mark for each fully correct column. This explanation is by olevels.com, not an official mark scheme.

A common mistake is saying an interpreter makes an executable file. Only a compiler does that. An interpreter runs the code line by line. Another mistake is saying a compiled program needs the compiler to run. Once compiled, it runs on its own.

Now you try. A developer will sell a finished photo app. She does not want customers to see her source code. Which translator should she use? Give one reason. Pause and decide.

A compiler. It produces an executable file, so customers receive only the executable, not the source code. It also runs quickly without the compiler. Remember the method: low-level means assembler, whole program means compiler, line by line means interpreter. Now try the practice questions for this type.
