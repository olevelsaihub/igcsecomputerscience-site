Idea. When you sing, the air vibrates in a smooth wave that changes all the time. That smooth, continuous signal is called analogue. A computer cannot store a smooth wave. It can only store separate binary numbers, which is digital. To turn the wave into numbers, the computer samples it. It measures the height of the wave, called the amplitude, at regular time intervals. Here are eight samples. Each sample is stored as a binary number. The number of bits for each sample is the bit depth. With a bit depth of three, sample three, with amplitude six, is stored as one one zero. The sampling frequency, or sample rate, is the number of samples taken each second. It is measured in hertz. A music file often uses forty-four thousand one hundred hertz.

Method. To describe the conversion, give the steps in order. Set the sample rate and bit depth. Measure the amplitude at each interval. Turn each measurement into binary. Store the binary values. For the effect of a change, give both sides. A higher sample rate or bit depth makes a closer copy of the sound, but the file gets bigger.

Worked example. Here is a real question from Paper 1 in November 2021. Describe how an analogue sound is converted into a digital sound file. It is worth three marks. First, the sample rate and bit depth are set. Then the analogue wave is sampled. Its amplitude is measured at regular time intervals. Next, each measured amplitude is given a binary value using the chosen number of bits. Finally, the binary values are stored, with the sample rate, as the sound file. For example, at forty-four thousand one hundred hertz, two seconds of sound gives eighty-eight thousand two hundred samples. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is swapping the axes. Time always goes along the bottom. Amplitude goes up the side. Another mistake is describing playback through speakers. The question asks about recording and storing the sound, so describe sampling and binary values.

Your turn. Now you try. A voice note is recorded at eight thousand hertz for three seconds. How many samples are stored? What happens to the file size if the sample rate is doubled? Pause here and work it out.

Answer. Eight thousand samples each second, for three seconds, is twenty-four thousand samples. Double the rate and there are forty-eight thousand samples, so the file is twice as big, with better quality. Remember the method: set the rate and bit depth, measure the amplitude at regular intervals, turn each sample into binary, and store it. Now try the practice questions for this type.
