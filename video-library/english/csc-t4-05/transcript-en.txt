Picture a classroom whiteboard. You write on it while you work, but it is wiped clean at the end of the day. Now picture a printed safety card on the wall. It is always there, and nobody changes it. RAM, random-access memory, is the whiteboard. It holds the programs and data being used right now. RAM is volatile. When the power goes off, everything in it is lost. ROM, read-only memory, is the printed card. It is non-volatile, so it keeps its contents with no power, and they cannot normally be changed. ROM holds the start-up instructions, called the BIOS. Two more. Flash memory is non-volatile but can be rewritten, so it is used in SSDs and memory cards. Virtual memory is part of the hard disc or SSD, used as extra RAM when RAM is full.

Name the memory type. State its key property. Then link the property to its use. If the question names two memory types, say something about each one. For virtual memory, describe the movement. When RAM is full, data not being used is moved out to the disc. When it is needed again, it is moved back into RAM.

Here is a real question from Paper 1 in June 2024. Explain one reason why computers need both RAM and ROM. It is worth two marks. Start with RAM. RAM is volatile. So when the computer is switched on, RAM is empty. There is nothing in it to run yet. So the start-up instructions must be kept somewhere permanent. That is ROM. It keeps the BIOS even with no power, and the BIOS boots the computer. Join them with so. RAM is volatile, so its contents are lost without power. Therefore ROM is needed to keep the start-up instructions permanently. This explanation is by olevels.com, not an official mark scheme.

A common mistake is saying ROM is volatile, or that ROM stores the operating system. ROM is non-volatile, and it stores the BIOS. The operating system is loaded later from storage. Another mistake is calling virtual memory extra RAM chips. It is space on the hard disc or SSD that acts like RAM.
