Think of a school. A notice in the main hall can be read by everyone. A note on the board in one classroom can only be read in that room, and it is wiped at the end of the lesson. In a program, the scope of a variable is the part of the program where it can be used. School is created in the main program, outside any subprogram, so it is a global variable. It can be read from anywhere, even inside show room. Room is created inside the subprogram, so it is a local variable. It only exists inside show room. When the subprogram finishes, room disappears and its memory is freed. So using room in the main program causes an error. Two subprograms can each have a local variable with the same name. They do not clash, because each one lives only inside its own subprogram.

First, check what the question asks: where the variable is created, or where it can be used. These are separate facts, and your answer must match. A global variable is created in the main program and can be used anywhere. A local variable is created inside a subprogram and can be used only inside that subprogram. The word only shows the limit.

Here is a real question from Paper 2 in June 2019. Describe the difference between a local variable and a global variable in a computer program. It is worth two marks. Start with the global variable. Where is it made? In the main program, outside every subprogram. Where can it be used? Anywhere in the program. Now the local variable. It is made inside a subprogram, and it can only be used inside that subprogram. Write both sentences. A global variable is created in the main program and can be used anywhere. A local variable is created inside a subprogram and can only be used there. One mark for each. This explanation is by olevels.com, not an official mark scheme.

A common mistake is saying a local variable is used in one line. It can be used anywhere inside its own subprogram, but nowhere else. Another mistake is describing only one side. A difference question needs a sentence about each kind of variable.
