Idea. A cinema gives a child ticket if you are under twelve. The question, are you under twelve, is either true or false. In code, a test like this is called a condition. Age less than twelve is True for nine, but False for twelve. Every boundary word has an exact operator. At least means greater than or equal to. More than means greater than. At most means less than or equal to. Exactly means double equals. And is True only when both tests are True, so use it for a range like thirty-one to thirty-nine. Or is True when either test is True. Python checks if, then each elif in order, and runs only the first True branch. Else catches the rest.

Method. Turn each table row into a condition, choosing the exact operator for each boundary word. Join two tests with and or or, as the wording says. Keep the branch order the program gives you. Fill any other gaps, such as the input line or int. Then test one value from every row, plus the values each side of every boundary.

Worked example. Here is a real question from Paper 2 in June 2024. The table shows the message each input should give. We must complete the program. It is worth six marks. Here is Figure 3, the table of messages. An empty input gives, You must provide a number. Any negative number, and zero, give, The number must be greater than zero. One to twenty gives Acceptable, and so does sixty or more. Thirty-one to thirty-nine gives Centre. Thirty gives Perfect. Any other number gives No message. Start with the input. A string equals input, enter a number. We keep it as a string, so an empty entry can be spotted. Next, if a string is not equal to the empty string, something was typed. Inside, convert it: a num equals int of a string. Acceptable is one to twenty, or sixty or more. We are already inside a num greater than zero, so the test is a num less than or equal to twenty, or a num greater than or equal to sixty. Centre is thirty-one to thirty-nine. The number must be inside both limits, so a num greater than or equal to thirty-one, and a num less than or equal to thirty-nine. Perfect is exactly thirty, so a num double equals thirty. Anything else falls through to else, which prints no message. Run it three times. Twenty gives Acceptable, thirty gives Perfect, and thirty-five gives Centre. Test the boundaries too. Common mistake. A common mistake is writing a range as thirty-one less than or equal to a num and less than or equal to thirty-nine. The second half has nothing on its left. Each side needs its own full comparison. Another mistake is using greater than where the table says at least. Then thirty-one would be missed from the Centre range.
