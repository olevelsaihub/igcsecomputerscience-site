Idea. Think of a library. You hand the librarian a shelf number. She finds that shelf and brings the book back to you. The shelf number only goes one way, to the librarian. Books travel both ways, out and back. Inside a computer, sets of wires called buses carry signals between the CPU and memory. The address bus carries addresses, one way, from the CPU to memory. The data bus carries data and instructions both ways. The control bus carries signals like read, write and the clock. The CPU repeats one cycle again and again. Fetch an instruction from memory. Decode it, to work out what it means. Execute it, to carry it out.

Method. Here is the fetch in detail. The address in the program counter is copied to the memory address register. That address goes on the address bus. A read signal goes on the control bus. The instruction comes back on the data bus. The program counter goes up by one. Next, decode. The control unit works out what the instruction means. Then execute. The instruction is carried out, for example the ALU adds two numbers. Bus width matters. A wider data bus moves more bits in one go. A wider address bus can point to more memory locations. Saying only faster is too vague.

Worked example. Here is a real question from Paper 1 in June 2025. Describe how the address bus is used during the fetch-decode-execute cycle. It is worth two marks. Point one. During the fetch, the CPU places the address of the next instruction, held in the memory address register, onto the address bus. It travels one way, to main memory. Point two, linked. Memory uses that address to find the right location, so it can be read from or written to. If the address is one hundred and one, location one hundred and one is read. So the answer is: the CPU puts the memory address on the address bus, and this identifies the location in main memory to read or write. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is saying the address bus carries data, or that it is two-way. It carries addresses only, from the CPU to memory. Another mistake is saying the program counter holds the next instruction. It holds the address of the next instruction.

Your turn. Now you try. The program counter holds forty. Which register does forty go to next? Which bus carries the instruction back? What is in the program counter after the fetch? Pause and decide.

Answer. Forty is copied to the memory address register, then put on the address bus with a read signal. The instruction comes back on the data bus. The program counter increments to forty-one. Remember: the address goes out on the address bus, the instruction comes back on the data bus, then it is decoded and executed. Now try the practice questions for this type.
