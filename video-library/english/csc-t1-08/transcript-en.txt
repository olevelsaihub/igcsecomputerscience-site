Imagine lining up your class by height. You only ever look at two people standing next to each other. If the taller one is on the left, they swap places. Then you move one step along and look again. That is a bubble sort. It compares each pair of neighbouring items and swaps them if they are in the wrong order. For ascending order, smallest first, seven and three are the wrong way round, so they swap. Going through the whole list once, from the first pair to the last pair, is called a pass. After pass one, the largest item, seven, has bubbled to the end. The passes go on until one pass makes no swaps. Here, that is pass four.

Always work from left to right. Compare the first two items and swap them if they are in the wrong order. Move one place along and repeat, right up to the last pair. Count the swaps as you go. Write the whole list only once, at the end of each complete pass. Never write a new row after a single swap. Keep making passes until one pass has no swaps at all. That last checking pass still counts, because the algorithm cannot know the list is sorted until it has checked it.

Here is a real question from Paper 2 in June 2025. A bubble sort puts eight ages into ascending order. You complete the table, one row for each pass. It is worth two marks. Pass one. Nine and eleven are in order. So are eleven and twelve, and twelve and nineteen. Then nineteen is bigger than fourteen, so they swap. Nineteen keeps swapping, with eighteen, fifteen and seventeen. That is four swaps. So the first row is nine, eleven, twelve, fourteen, eighteen, fifteen, seventeen, nineteen. Only nineteen has moved, all the way to the end. Pass two starts again at the left. The pairs are in order up to fourteen and eighteen. Then eighteen swaps with fifteen, and with seventeen. Eighteen and nineteen are in order. That is two swaps. Row two is nine, eleven, twelve, fourteen, fifteen, seventeen, eighteen, nineteen. It looks sorted, but the algorithm does not know that yet. Pass three checks every pair and makes no swaps, so the sort stops. The two rows that changed earn the marks. The first pass made four swaps, and the least number of passes is three. This explanation is by olevels.com, not an official mark scheme.

A common mistake is writing a new row after every single swap. Those rows are ignored. Write the list once, at the end of each complete pass. Another mistake is forgetting the last pass when counting. The pass with no swaps still counts, so the answer is three, not two.

Now you try. Use a bubble sort to put eight, three, six, one, nine into ascending order. Write the list after each pass, and count the passes. Pause here and work it out.

Pass one: eight swaps with three, six and one, then stops behind nine. The list is three, six, one, eight, nine, after three swaps. Pass two: six swaps with one, giving three, one, six, eight, nine. Pass three: three swaps with one, giving one, three, six, eight, nine. Pass four makes no swaps, so the sort stops. That is four passes in all. Remember the method: compare neighbours from left to right, write the list once per pass, and stop after a pass with no swaps, counting it too. Now try the practice questions for this type.
