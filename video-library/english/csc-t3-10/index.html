Pixels, resolution and colour depth

Idea. Zoom right into a photo on your phone and it turns into tiny coloured squares. Each square is a pixel, short for picture element. A bitmap image is simply a grid of pixels. Resolution tells you how much detail there is. It can be the width times the height in pixels, or a measure such as pixels per inch or dots per inch. Colour depth is the number of bits used to store the colour of one pixel. One bit gives two colours. Two bits give four. Eight bits give two hundred and fifty-six colours.

Method. For a definition, give the short key phrase. A pixel is the smallest element of a bitmap image. For resolution, give a unit such as pixels per inch. For a file size question, start with one pixel. More colour depth means more bits for that pixel. Then scale up. Every pixel needs those extra bits, so the whole file is bigger.

Worked example. Here is a real question from Paper 1 in June 2023. Increasing the colour depth of an image makes its file bigger. Describe the reason for this. It is worth two marks. Start with one pixel. Colour depth is the number of bits stored for each pixel. If the colour depth goes up, every single pixel now needs more bits. The number of pixels stays the same. So the total number of bits for the image goes up. A one hundred by one hundred image at eight bits per pixel needs eighty thousand bits. At sixteen bits it needs one hundred and sixty thousand. So the answer is: each pixel is stored with more bits, and since there are the same number of pixels, the file gets bigger. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is saying more colour depth means more pixels. It does not. The pixel count stays the same. Each pixel just holds more bits. Another mistake is giving megabytes as a measure of resolution. Megabytes measure file size. Resolution needs a unit such as pixels per inch or dots per inch.

Your turn. Now you try. An icon is fifty pixels wide and forty pixels high, with a colour depth of eight bits. Work out its size in bits, then in bytes. Pause here and work it out.

Answer. Fifty times forty is two thousand pixels. Times eight bits is sixteen thousand bits. Divide by eight to get two thousand bytes. Using one kilobyte equals one thousand bytes, that is two kilobytes. Remember the method: define with one exact phrase, then for file size start at one pixel and scale up to the whole image.
