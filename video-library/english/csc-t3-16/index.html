A kilogram is one thousand grams, and a kilometre is one thousand metres. So you would expect a kilobyte to be one thousand bytes. It is. But computers count in twos, so there is a second unit too. Two to the power ten is one thousand and twenty-four, which is very close to one thousand. So a kibibyte is one thousand and twenty-four bytes. A kibibyte is slightly bigger than a kilobyte. Decimal units are the SI units: kilobyte, megabyte, gigabyte, each a thousand times the last. Binary units are the IEC units: kibibyte, mebibyte, gibibyte, each one thousand and twenty-four times the last.

First, decide which unit is decimal and which is binary. Then change the amount into bytes using its own factor. Finally, divide by the factor for the unit you want. For a compare question, give both sides of each point. A kilobyte is one thousand bytes, whereas a kibibyte is one thousand and twenty-four bytes. Kilobytes are base ten, whereas kibibytes are base two.

Here is a real question from Paper 1 in June 2023. Construct an expression to convert thirteen kilobytes into kibibytes. It is worth two marks. Kilobytes are decimal. One kilobyte is one thousand bytes. So thirteen kilobytes is thirteen times one thousand, which is thirteen thousand bytes. A kibibyte is one thousand and twenty-four bytes. So divide the bytes by one thousand and twenty-four. The expression is thirteen times one thousand, all divided by one thousand and twenty-four. Check: the answer, about twelve point seven, is a little less than thirteen. That makes sense, because each kibibyte is a little bigger. This explanation is by olevels.com, not an official mark scheme.

A common mistake is multiplying by one thousand and twenty-four instead of dividing. That gives over thirteen million, which cannot be right for a smaller count of bigger units. Another mistake is thinking a kilobyte is one thousand and twenty-four bytes. In this course, a kilobyte is one thousand bytes. The one thousand and twenty-four unit is the kibibyte.

Now you try. A saved game file is two kibibytes. Construct an expression to give its size in kilobytes. Pause here and work it out.

Kibibytes are binary, so two kibibytes is two times one thousand and twenty-four bytes. Kilobytes are decimal, so divide by one thousand. The expression is two times one thousand and twenty-four, divided by one thousand, which is two point zero four eight kilobytes. Remember the method: spot the decimal and binary units, change to bytes with the first factor, then divide by the second. Now try the practice questions for this type.
