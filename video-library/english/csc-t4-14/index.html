Read the narration

Trainee pilots practise in a flight simulator. They can face an engine failure safely, again and again, without anyone getting hurt. A computer simulation lets us try out situations that would be dangerous, costly or impossible in real life. A model is a set of rules and data that represents a real system. A simulation runs the model, to see what happens over time. Here is a tiny model in Python. The rule is: rabbits double every year. Running it is the simulation. Three years pass in a moment: two hundred, four hundred, then eight hundred. Simulations have big benefits. They are safe. You can change variables to ask what if. They can run faster or slower than real time. And they help to predict outcomes and test ideas. But a simulation is only as good as its data and rules. Real rabbits do not double for ever, so our model is wrong after a few years. Big simulations also need a powerful processor, because they handle lots of data and many calculations.

First, decide what is asked: a benefit, a limit, or a hardware need. State one clear point. Then expand it with a linked effect in the scenario. Never repeat a benefit the question has already given.

Here is a real question from Paper 1 in June 2024. Peter is creating a simulation of rabbits and foxes. One benefit is that it is simpler than watching real animals. Explain one other benefit. It is worth two marks. Simpler is already used, so we choose a different benefit. The simulation can run much faster than real life. Now link it to Peter's scenario. Years of rabbit and fox numbers can be seen in minutes, so he can spot long-term trends quickly. So the answer is: the simulation can run much faster than real life, so Peter can see many generations of rabbits and foxes in a short time, and spot long-term trends. This explanation is by olevels.com, not an official mark scheme.

A common mistake is giving two separate facts instead of one point and its linked effect. Another mistake is saying a simulation is always accurate. Its results depend on its data and rules.

Now you try. A town uses a traffic simulation to plan new traffic lights. Explain one reason why the town should not fully trust its results. Pause here and work it out.

The point is a limit: the simulation is only as good as its data and rules. Then the link: if the traffic data or the assumptions about drivers are wrong, the predicted queues will be wrong too, so the lights could be planned badly. Remember the method: decide what is asked, state one point, then link it to the scenario with so. Now try the practice questions for this type.
