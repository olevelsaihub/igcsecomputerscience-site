Compression: lossy or lossless?

Read the narration

When you pack for a trip, you squash clothes into a smaller bag. Compression does the same to a file. It makes the file smaller, so it takes less storage space and is quicker to send over a network. Here is how big the saving can be. A three-minute song in CD quality is about thirty-two megabytes. As a compressed M P three file it is under three megabytes. There are two kinds. Lossy compression removes some data for ever, so the original can never be rebuilt exactly. Lossless compression loses nothing, so the original comes back exactly.

First, decide what the file is. Is it text or program code, where every character matters? Or is it a picture, music or video that people see or hear? Then choose. Lossless if every bit must be kept. Lossy is often fine for media, because people rarely notice the missing detail. Finally, justify with what would happen to this file. Compression has drawbacks too. It takes time to compress and decompress, and you need compatible software to open the file.

Here is a real question from Paper 1 in June 2024. An instruction manual is compressed before it is sent to a proofreader. Choose lossy or lossless, and justify your choice. It is worth three marks. What is the file? An instruction manual, which is text. The proofreader must see every word exactly as it was written. Lossy compression would delete some data for ever. Letters could be lost or changed, so the proofreader could not check the real text. So choose lossless. It rebuilds the manual exactly. This explanation is by olevels.com, not an official mark scheme.

A common mistake is saying lossless removes less data. It removes no data at all. That is why the file can be rebuilt exactly. Another mistake is giving the same reason twice. Saves space and takes less storage are one point. Give different points, such as less storage and faster to send.

Now you try. A band streams its songs to fans' phones. Should the songs use lossy or lossless compression? Justify your choice. Pause and decide.

Choose lossy. The songs are much smaller, so they stream quickly over mobile data and use less of each fan's data. Listeners rarely notice the missing detail in music. Remember the method: decide what the file is, choose lossless if every bit matters and lossy if people will not notice, then justify for this file. Now try the practice questions for this type.
