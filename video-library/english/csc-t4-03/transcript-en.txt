Idea. Think of a cook with a recipe. The recipe and the ingredients sit on the same shelf. The cook reads one step, works out what it means, does it, then moves to the next step. This is the stored program concept, from von Neumann. Program instructions and data are both kept together in main memory. The CPU fetches each instruction, decodes it and executes it, one at a time. An instruction is one command telling the CPU what to do, such as add two numbers. A memory address is a number that identifies one location in memory, like a house number on a street. Inside the CPU are three main parts. The control unit runs the fetch-decode-execute cycle and sends control signals. The arithmetic logic unit, the ALU, does calculations and comparisons. Registers are tiny, very fast stores.

Method. Five registers have names. The program counter holds the address of the next instruction. The memory address register and memory data register hold the address and data being moved. The current instruction register holds the instruction, and the accumulator holds ALU results. To answer, find the exact term in the question. Give its meaning in one plain sentence. For the stored program concept, say both stored and executed. For labels, the control unit and ALU go inside the CPU.

Worked example. Here is a real question from Paper 1 in June 2022. State what is meant by the term program instruction. It is worth one mark. A program is a list of commands. Each line here is one instruction: load a value, add a value, store the result. So say what it does. A program instruction is a single command that tells the CPU what operation to carry out, for example add two numbers. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is saying only instructions are stored in memory. In the stored program concept, instructions and data are both stored, then the instructions are fetched and executed. Another mistake is mixing up the control unit and the ALU. The control unit controls the cycle. The ALU does the arithmetic and logic.

Your turn. Now you try. A games console adds a bonus to a player's score. Which part of the CPU does the addition? Which part sends the control signals? Name one register. Pause and decide.

Answer. Part a. Adding is arithmetic, so the arithmetic logic unit does the addition. Part b. The control unit sends the control signals. Part c. Any named register, such as the program counter or the accumulator. Remember the method: name the term, give its meaning in one sentence, and know where each part sits.
