Think of a recipe card called make tea. Whenever you want tea, you follow the same card. You never rewrite it. In a program, a subprogram is a named block of code that does one job, and you can call it whenever you need it. A function is a subprogram that sends a value back, using return. Area takes a length and a width, and returns length times width. Rug equals area of three and two, so rug is six. A procedure carries out a task but does not have to send a value back. Show menu just prints two lines. P length and p width are parameters. A parameter is a named input in the subprogram's header. Parameters let one subprogram work with different data each time, so it can be reused: area of five and four gives twenty. Some subprograms come ready-made. Built-in ones, like print and len, are part of Python. A library is a collection of pre-written subprograms that you import, like random. Library code has already been tested, so it is less likely to contain errors.

First decide which idea is being tested. For a difference between a function and a procedure, use the return value: a function returns a value, a procedure does not have to. For a similarity, choose shared features, such as parameters, local variables and reuse. For an explain question, give a point, then so, then its effect.

Here is a real question from Paper 2 in November 2020. Explain one difference between a function and a procedure. It is worth two marks. Think about what happens when each one finishes. A function ends with return and hands a value back, so the value can be stored, like rug equals area of three and two. A procedure just does its job, like showing a menu. So write: a function always sends a value back to the code that called it, whereas a procedure does not have to. One mark for each half. A common mistake is saying a procedure cannot take parameters. It can. Both can take parameters. Only the return value tells them apart. Another mistake is writing libraries are quicker, with no reason. Say why: the code is already written and tested, so it saves time and has fewer errors.
