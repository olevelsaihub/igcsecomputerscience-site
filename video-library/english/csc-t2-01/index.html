Think of a kitchen. Flour goes in a jar, eggs in a box, and milk in a bottle. Each container suits one kind of thing. A computer is the same. Every value is stored with a data type, which says what kind of value it is and what can be done with it. There are five data types to know. An integer is a whole number, like nineteen. A real number has a decimal part, like four point five. A Boolean is only True or False. A char is one single character, like a capital A. A string is a run of characters, like the word Hello. In Python, it looks like this. Hours equals nineteen is an integer. Price equals three five six point two five is a real, which Python calls a float. Member equals True is a Boolean. Grade holds one character, so it is a char, and name holds a string. Text always sits inside quotation marks.

Ask three questions in order. Is it True or False? Then it is a Boolean. Is it a number? A whole number is an integer, and any decimal point makes it real. Is it text? One character is a char. More than one is a string. If you must justify, point to the feature you used. For a real, say it has a decimal part, or that it is made by multiplying by nought point five. Saying it is a number is not enough.

Here is a real question from Paper 2 in June 2024. Complete the table to show the data type for each item: forty-five point eight two, and True. It is worth two marks. The first item is forty-five point eight two. It is a number with a decimal point, so it is a real number. In Python this is a float. The second item is True, with no quotation marks. True is one of only two possible values, so it is a Boolean. You can check this in Python. The type function shows float for forty-five point eight two, and bool, short for Boolean, for True. So write real, then Boolean, for one mark each. This explanation is by olevels.com, not an official mark scheme.

A common mistake is calling True a string. Without quotation marks, True is a Boolean. Another mistake is giving a whole word as an example of a char. A char is one character only.

Now you try. Give the best data type for four values: the letter Q in quotation marks, seventeen, three point nought, and seventeen inside quotation marks. Pause here and work it out.

The letter Q is one character, so it is a char. Seventeen is a whole number, so it is an integer. Three point nought has a decimal point, so it is real, even though its value is whole. Seventeen inside quotation marks is text, so it is a string. You cannot do sums with it. Remember the method: is it True or False, is it a number, or is it text? Then justify with the feature you spotted. Now try the practice questions for this type.
