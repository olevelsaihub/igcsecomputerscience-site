Network topologies: bus, ring, star and mesh

Idea. Think about fairy lights. On some strings, one broken bulb makes the whole string go dark. On others, only that bulb goes out. The way things are wired decides what happens when one part fails. In a network, the layout of the connections is the topology. In a star, every device has its own cable to a central switch. If one cable breaks, only that device is cut off, and the fault is easy to find. But if the switch fails, the whole network stops. In a bus, every device joins one shared main cable, with a terminator at each end. It is cheap. In a ring, devices form a closed loop and data goes one way, so packets do not collide. In a mesh, each device links to several others, so there are many routes. Data can go around a broken link. It is very reliable, but expensive and hard to set up. The internet is a huge partial mesh.

Method. First, recognise the shape. One shared cable is a bus. A closed loop is a ring. Everything joined to one central box is a star. Many cross-links make a mesh. Then recall that topology's strength and weakness. For an explain question, give the feature, then its effect, joined with so or because.

Worked example. Here is a real question from Paper 1 in June 2024. A fault tolerant network gives a reliable service. Explain one reason why the topology in the figure is fault tolerant. It is worth two marks. In the figure, every computer is linked to several others, so it is a mesh. Start with the feature: each computer has two or more links, so there is more than one path between any two devices. Now the effect. If one link breaks or is busy, the packets are sent along another route, and they still reach their destination. Join them with so. Each node has several links, so packets can go around a broken link and still arrive. This explanation is by olevels.com, not an official mark scheme.

Common mistake. Watch for drawbacks from the wrong topology. A star has no main cable. Its weak point is the central switch. Another mistake is saying a mesh is fault tolerant because it is reliable. That repeats the question. Mention the multiple routes.

Your turn. Now you try. A café links six computers. Each one has its own cable to a single switch in the back office. Name the topology. Give one benefit and one drawback. Pause here and work it out.

Answer. Every computer has its own cable to one switch, so it is a star. Benefit: one broken cable only cuts off that computer. Drawback: if the switch fails, every computer loses the network. Remember the method: spot the shape, name it, then explain with feature, so effect. Now try the practice questions for this type.
