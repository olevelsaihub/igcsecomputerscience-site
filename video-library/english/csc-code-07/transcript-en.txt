Think of a toaster. You put bread in, it does one job, and toast comes out. A subprogram is the same: a named block of code that does one job. A function also hands a value back with return. Here, p num is the parameter, the placeholder in the def line. Five is the argument passed in the call. The function returns ten, and answer stores it. A string is a row of characters, and each has an index starting at zero. A slice like zero colon two takes the characters at index zero and one, but stops before index two. So for a b c d it gives a b.

A common mistake is joining the number without str. Python cannot add a whole number to a string, so the program crashes. Another mistake is printing inside the function, or writing return with no value. The calling line then gets nothing back.
