Idea. Think of a toaster. You put bread in, it does one job, and toast comes out. A subprogram is the same: a named block of code that does one job. A function also hands a value back with return. Here, p num is the parameter, the placeholder in the def line. Five is the argument passed in the call. The function returns ten, and answer stores it. A string is a row of characters, and each has an index starting at zero. A slice like zero colon two takes the characters at index zero and one, but stops before index two. So for a b c d it gives a b.

Method. Read the def line and note the parameters. Write the body using only those parameters. End a function with return and the result. Then complete the call with the arguments in the right order, and store what comes back.

Worked example. Here is a real question from Paper 2 in June 2024. The program takes a four-character string and a whole number. The new key is the first two characters, then the number, then the last two. So a b c d and one two three gives a b one two three c d. It is worth six marks. Inside gen new key, p string holds the text and p num the number. Join the first two characters and p num, turned into a string. Then add the last two characters. A function must hand its answer back, so the last line is return new key. The main program is given. Complete the call: my new key equals gen new key, with my string and my number in that order. Run it with a b c d and one two three. The new word is a b one two three c d, just like the example. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is joining the number without str. Python cannot add a whole number to a string, so the program crashes. Another mistake is printing inside the function, or writing return with no value. The calling line then gets nothing back.

Your turn. Now you try. Complete make tag so it returns the last two characters of a four-letter word, followed by the number. Then call it with lion and seven, and print the result. Pause here and work it out.

Answer. Tag equals p word, slice two to four, plus str of p num. Return tag. The call is make tag of lion and seven. Running it prints o n seven. Remember the method: use the parameters, return the result, and call with the arguments in the right order. Now try the practice questions for this type.
