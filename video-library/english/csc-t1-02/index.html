Idea. You cannot see inside a dishwasher. But dirty plates go in, and clean plates come out. So you know its job: washing dishes. To find the purpose of an algorithm, we do the same. Compare what goes in with what comes out. Here is a short algorithm. Do not read it line by line in your answer. Instead, run it with a tiny input and watch what happens. Try the word banana. Count goes up on each letter a, so it ends at three, and three is output. So the purpose is: it counts how many times the letter a appears in a word, and displays that number. Some questions ask about one variable. Here, temp holds a's value during a swap. Without it, setting a to b would overwrite a, and its old value would be lost.

Method. First, pick a small, easy input and dry-run the algorithm. Then compare the input with the output, or with the final state of the data. Write the purpose as one sentence that names the task. For a two-mark describe, add a second linked point, such as what is output.

Worked example. Here is a real question from Paper 2 in June 2025. Describe the purpose of Martha's algorithm, assuming the error has been corrected. It is worth two marks. The error is on line eight: score is reset to zero inside the loop. We assume it is fixed, so score is set to zero only once, on line five. The loop runs ten times. Dry-run two passes with made-up numbers. Twenty-three plus forty-five is shown. The user types sixty-eight, which is correct, so score goes up. Next, ten plus seven: the user types fifteen, which is wrong, so score stays the same. So the purpose is: it is an addition quiz of ten questions using random numbers. It checks each typed answer, adds one to the score for each correct one, and displays the final score. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is retelling each line. That does not say what the algorithm is for. Name the overall job instead. Another mistake is a vague reason for a variable. Saying temp stores a number earns nothing. Say what would be lost without it.

Answer. Big starts as four, the first item. Nine is greater than four, so big becomes nine. Two and seven are not greater than nine, so big stays nine. Nine is output. So the purpose is: it finds the largest number in the array, and displays it.
