Idea. Imagine a rule at home: you can go out to play if your homework is done and it is not raining. Call homework done H, and raining R. The rule becomes H and not R. Use AND when every condition is needed. Use OR when any one of the choices is enough. Use NOT when a condition must be false, like a code that has not been entered. Order matters. NOT is done first, then AND, then OR. So brackets are needed around an OR group that is joined to something else with AND.

Method. Step one. Write each condition next to its letter, and note whether it must be true or false. False conditions need NOT. Step two. Group the either-or choices with OR, inside brackets. Then join every part that must all hold with AND. Step three. Use only the letters and operators you are given. Then test your statement with one case that should give one, and one that should give zero.

Worked example. Here is a real question from Paper 1 in June 2023. A warehouse alarm sounds if a movement sensor, M, or a pressure pad, P, is activated, and the key code, C, has not been entered. Write a logic statement. It is worth three marks. Either sensor is enough to start the alarm, so that is M or P. Put it in brackets, because it will be joined to something else. The key code must not have been entered. That condition must be false, so it is not C. Both parts are needed together, so join them with AND. The statement is: M or P, in brackets, and not C. Test it with a truth table. The alarm sounds only when a sensor is on and no code is entered, and stays silent whenever C is one. One mark each for M or P, not C, and the AND. This explanation is by olevels.com, not an official mark scheme.

Common mistake. The most common mistake is leaving out the brackets. Without them, AND is done first, so the movement sensor alone would sound the alarm, even after the code is entered. Another mistake is forgetting NOT for a condition that must be false. Without NOT, the alarm would only sound once the code is entered.

Your turn. Now you try. A car beeps a warning, W, when the engine is running, E, and either the seat belt, S, is not fastened or a door, D, is open. Write a logic statement for W using E, S and D. Pause here and work it out.

Answer. The engine must be running: E. The belt must not be fastened: not S. Either that or an open door is enough, so not S or D, in brackets. Join with AND: E and, in brackets, not S or D. Test two cases. Engine on, belt fastened, doors shut: one, one, zero gives zero, no beep. Engine on, belt off, doors shut: one, zero, zero gives one, a beep. Both match the story. Remember the method: list each condition, put either-or choices in brackets with OR, use NOT for anything that must be false, and join with AND. Now try the practice questions for this type.
