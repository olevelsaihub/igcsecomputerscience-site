Read the narration

Every house needs its own address, so post arrives at the right door. Every device on a network needs one too. An I P address is a number that identifies a device. An I P version four address is written as four denary numbers, each from zero to two hundred and fifty-five, separated by dots. Each number fits in eight bits. For example, one hundred and ninety-two is one one zero zero, zero zero zero zero. So I P version four uses thirty-two bits, which gives about four point three billion addresses. The number of connected devices grew so much that I P version four was running out. An I P version six address is written as eight groups of four hexadecimal digits, separated by colons. Each hexadecimal digit stands for exactly four bits, because four bits give sixteen values, from zero to F.

Here is the whole picture. I P version four: four parts of eight bits, thirty-two bits. I P version six: eight groups of sixteen bits, one hundred and twenty-eight bits. So the method is: decide the version, count the groups and digits, then multiply. Four digits times four bits is sixteen bits a group. Eight groups times sixteen is one hundred and twenty-eight.

Here is a real question from Paper 1 in June 2024. Marie's phone has this address. Describe the relationship between its structure and the total number of bits needed to store it. It is worth three marks. Count the groups between the colons: there are eight. Each group has four hex digits, so there are thirty-two hex digits in total. Each hex digit needs four bits, so each group is sixteen bits. Eight groups times sixteen bits is one hundred and twenty-eight bits. Check: thirty-two digits times four is also one hundred and twenty-eight. This explanation is by olevels.com, not an official mark scheme.

A common mistake is saying each hex digit is eight bits. One hex digit is four bits. A pair of hex digits makes eight bits. Another mistake is counting the colons. There are seven colons, but eight groups. Count the groups.
