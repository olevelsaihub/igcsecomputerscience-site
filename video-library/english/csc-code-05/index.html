Every program, like a vending machine, has inputs, processing and outputs. You put in a coin and a choice, the machine works out what to do, and out comes a snack. Before you code, list all three from the requirements. Python has the usual arithmetic operators, plus three special ones. Two slashes is whole-number division. The per cent sign gives the remainder. Two stars means to the power of. A price band table becomes an if, elif, else chain. Test the biggest band first. Then each elif only sees the values that failed the tests above it, so there are no gaps or overlaps.

Write each requirement as a comment. Read the inputs with int or float. Write the selection or loop with exact boundaries. Do each calculation once, after the if, then print labelled results and test every boundary.

Here is a real question from Paper 2 in June 2022. Manjit sells textbooks. The program must take the number required, work out the price per book from the table and the total cost, and display both. It is worth six marks. Start with meaningful names. Quantity, price per book and total cost all begin at zero. Next, the input. Quantity equals int of input, so we can compare it with numbers. Now the bands, biggest first. If quantity is at least ten, the price is twelve pounds. Else if it is at least six, fifteen pounds. Else, twenty pounds. After the if, work out the total once: total cost equals quantity times price per book. Then print both with labels and two decimal places. Run it. Six books cost fifteen pounds each, ninety pounds in total. Ten books cost twelve pounds each, one hundred and twenty pounds. This explanation is by olevels.com, not an official mark scheme.

A common mistake is using greater than where the bands need at least. Then an order of exactly ten, or exactly six, lands in the wrong band. Another mistake is repeating the calculation and print inside every branch. Write them once, after the if.

Now you try. A minibus holds twelve people. Write a program that inputs the number of people, then displays how many full minibuses there are and how many people are left over. Pause here and work it out.

Read people with int. Full buses is people, two slashes, twelve. Left over is people, per cent, twelve. Print both with labels. Thirty people gives two full buses and six left over. Remember the method: list inputs, processing and outputs, convert the inputs, use exact boundaries, calculate once and print with labels. Now try the practice questions for this type.
