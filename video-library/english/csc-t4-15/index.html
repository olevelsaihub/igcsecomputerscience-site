High-level and low-level languages

Idea. Imagine giving directions. To a friend you say, go to the park. To a robot you must say, turn left ninety degrees, move ten steps, stop. One is easy for people. The other is exact for the machine. A high-level language, like Python, uses English-like words. People can read and write it easily. Here, total equals a plus b, then print the total. A low-level language is close to the hardware. Assembly language uses short mnemonics like L D A, load, and A D D, add. Machine code is pure binary. Here is the same addition in assembly. Compare them. High-level code is easy to read and portable, so it runs on different computers once translated. Low-level code is written for one processor, but it can control the hardware directly, run fast and use little memory.

Method. Decide which level the question asks about, and whether it wants a benefit, a drawback or a comparison. Pick one feature. To compare, give both sides with whereas. To explain, link the feature to the scenario. Low-level languages are often used for device drivers and embedded systems. High-level languages are used for most general applications, such as games and websites.

Worked example. Here is a real question from Paper 1 in June 2025. A team writes smartwatch software in assembly language. Explain one benefit of writing it in a low-level language. Two marks. Recall the key benefit. Low-level code can directly access the hardware and the registers. So the programmers control exactly what the hardware does. Now link it to the device. A smartwatch has limited hardware: small memory and a small battery. So it must be used as efficiently as possible. So the answer is: programmers can make the best use of the smartwatch's limited hardware, because low-level code gives direct access to its hardware and registers. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is saying high-level languages run faster, or that low-level ones are easier. It is the other way round. Another mistake is a vague word like better. Say how it is better, and in a compare question cover both sides.

Your turn. Now you try. A team is writing a phone app that must run on many different types of phone. Should they use a high-level or a low-level language? Explain one reason. Pause and decide.

Answer. High-level. High-level code is portable. The same source code can be translated to run on each type of phone, whereas low-level code only works on one type of processor. Remember the method: pick the level, pick one feature, and link it to the task. Now try the practice questions for this type.
