Idea. Think of labelled boxes on a shelf. A box called score holds one thing, and you can swap what is inside whenever you like. In a program, that box is a variable: a named place in memory whose value can change while the program runs. Score starts at nought. Score equals score plus five, so it prints five. A constant is a named value that stays fixed while the program runs. In Python we write its name in capitals, like VAT rate. If the rate ever changes, the programmer updates one line, not every place it is used. An array holds many values of the same data type under one name. Each value has an index, starting at zero. Scores index zero is twelve, and scores index two is fifteen. A one-dimensional array is like a single row. A two-dimensional array is like a table, with rows and columns. Every value in it is still the same data type. A record groups related fields about one item, and the fields can be different data types. This record for one product holds a string, a real and an integer.

Method. First, spot the key word: variable, constant, array or record. For a definition, say what is stored and whether it can change. For a difference, describe the first item, write whereas, then describe the second. For array versus record, check the data types. Values of the same type can go in an array. Mixed types about one item need a record.

Worked example. Here is a real question from Paper 2 in June 2025. Describe one difference between a variable and an array. It is worth two marks. Write down what each one stores. A variable holds one value at a time, such as score equals twelve. An array holds many values under one name, such as scores holding twelve, seven and fifteen. Join the two halves with whereas. A variable holds just one value at a time, whereas an array holds many values under one name. One mark for each half. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is describing only one side. A variable holds one value is only half the answer, so it earns only one mark. Another mistake is saying a constant stops the user changing a value. The benefit is for the programmer: the value is set in one place and cannot be changed by accident while the program runs.

Your turn. Now you try. A shop stores the name, the price and the number in stock for one product. Should it use an array or a record? Give a reason. Pause and decide.

Answer. Look at the data types. The name is a string, the price is a real, and the number in stock is an integer. The types are mixed. So use a record, because its fields can be different data types, and they all describe one product. Remember the method: spot the key word, say what is stored and whether it can change, and describe both sides with whereas. Now try the practice questions for this type.
