Read the narration

A school has a head teacher who does not teach every lesson, but makes sure rooms, timetables and staff all work together. The teachers do the actual lessons. A computer has the same split. System software runs and looks after the computer itself. The operating system and utility programs are system software. Application software lets the user do a task, such as writing a letter or editing a photo. The operating system has many jobs. Process management, memory management, file management, peripheral management, security and user management, and providing a user interface. How can one CPU run several programs? The scheduler gives each process a short time slice, in turn, so fast that they all seem to run at once. Processes wait in a queue, and some get higher priority.

Storing a file is a step-by-step process. The OS checks there is enough free space, splits the file into blocks, stores the blocks anywhere on the disc, and records where each block is in the file allocation table. To answer, decide what the question wants. For functions, say management each time. For sharing the CPU, use scheduler, queue and time slices. For system versus application, use whereas.

Here is a real question from Paper 1 in June 2023. A computer with a single CPU is multitasking. Describe how the operating system enables processes to share a single CPU. Two marks. Point one: the scheduler keeps the processes waiting in a queue and picks which one goes next. Point two: each process gets the CPU for a short time slice, then is swapped for the next. So the answer is: the OS scheduler keeps processes in a queue, and gives each a short time slice of the CPU before swapping to the next, so they all appear to run at once. This explanation is by olevels.com, not an official mark scheme.

A common mistake is writing memory or files alone. Say memory management or file management. Another mistake is describing memory management when the question asks how the CPU is shared. Stick to the scheduler, the queue and time slices.

Now you try. Lina uses a photo editor. Is the photo editor system software or application software? Then state the difference between the two kinds. Pause and decide.

Part a. Application software, because it lets Lina do a task, editing photos. Part b. System software runs and looks after the computer itself, whereas application software lets the user do a task. Remember the method: decide what is asked, name OS jobs as management, and give steps in order. Now try the practice questions for this type.
