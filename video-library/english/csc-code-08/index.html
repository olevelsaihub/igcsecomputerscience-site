Read the narration

A text file is like a notebook the program can keep. Variables vanish when the program ends, but a file stays on the disk. To use one, you open it, read or write it line by line, then close it. The mode says what you will do. R opens a file to read. W creates a new file to write, wiping any old one. A adds to the end. Each line read from a file is one string, ending with a hidden newline. Strip removes the newline. Split at commas breaks the line into a list of strings. Then int turns each one into a number. Writing works the other way. Build one string per record, with commas between fields and a newline at the end, then write it.

Open the file with the right mode and the exact name. Loop over the lines. For each line, strip, split and convert. Do the work, such as a running total. Then print the results and close the file.

Here is a real question from Paper 2 in June 2024. Sales dot t x t holds five lines of sales figures. The program must show a subtotal for each line and a grand total. It is worth eight marks. The constants and totals are given. Open the file to read: the file equals open input file, r. For line in the file visits each line. Strip the newline and split at the comma, giving five strings such as two six four. Reset the subtotal to zero for each line. Then, for each sale, add int of sale to the subtotal. Print the subtotal, add it to the grand total, and after the loop print the grand total and close the file. Run it. Line one gives two six four plus one four zero plus one two zero plus two eight four plus one nine two, which is one thousand. The lines give one to five thousand, and a grand total of fifteen thousand. This explanation is by olevels.com, not an official mark scheme.

A common mistake is adding the values without int. They are still text, so Python either crashes or joins the text together instead of adding. Another mistake is forgetting to reset the subtotal for each line, or closing the file inside the loop.

Now you try. Scores dot t x t holds three lines: Ali comma twelve, Bea comma fifteen, Cal comma nine. Write a program that reads the file and displays the total of all the marks. Pause here and work it out.

Set total to zero. Open the file to read. For each line, strip and split at the comma. The mark is at index one, so add int of parts one. Close the file and print the total: thirty-six. Remember the method: open with the right mode, loop over the lines, strip, split and convert, total, then close. Now try the practice questions for this type.
