Idea. The last question on Paper 2 is the big one, worth twenty marks. Eleven marks are for meeting the listed requirements. Up to nine more are for the overall quality of your program. Planning a school trip is easier when you split it into jobs: transport, food, tickets. That is decomposition. In code, each job becomes its own small subprogram. Parallel arrays hold related data at the same index. Index seven is Jersey in the breed array, rating one, seven cows, and eighteen point three litres per cow.

Method. Turn every bullet into a numbered checklist. Study the data: which arrays, and what each index means. Then build and run one requirement at a time, looping with len, never a fixed number. Use a tracker variable to remember the best item found so far. Finish with comments, clear names and labelled output, then re-read every bullet and test.

Worked example. Here is a real question from Paper 2 in June 2023. A college stores data on twelve breeds of dairy cow in parallel arrays. The program must work out each breed's daily milk, show a table, total the herd, and recommend the best breed. It is worth twenty marks. The question goes on. Calculate each breed's daily volume and store it in tbl daily volume. Display a field message, the data for each breed, the herd total, and the recommended breed by name. It must work if the number of breeds changes. Here is Figure 8, the output. A heading, one line for each breed, the total of nine hundred and five point four litres, and the recommended breed: Jersey, rating one, volume eighteen point three. First, daily volume. For each index, multiply volume per cow by the number of cows, round it, and append it to the daily volume array. Red Chittagong gives seven point five times six, which is forty-five litres. Next, the herd total. A running total starts at zero and adds every daily volume. It is rounded to one decimal place. Now the best breed. Best starts at index zero. A breed wins if its rating is better, which means a lower number, or if the rating is the same and it gives more milk. Joining these tests with or and and is the key logic. The main program calls each subprogram in order and prints the results with labels. The full answer also prints a table with headings. Here we show the total and the recommendation. Run it. The herd total is nine hundred and five point four litres. The rating-one breeds give seven point five, fifteen point two, eighteen point three and nine litres per cow, so Jersey is recommended. This explanation is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is hard-coding the number of items, like range twelve. If a breed is added, the program breaks. Use len of the array instead. Another mistake is starting a tracker at zero when looking for the smallest value. Nothing is smaller than zero, so it never changes. Start from the first item instead.

Your turn. Now you try. Two parallel arrays hold four fruits and their prices in pence. Write a function find cheapest that returns the index of the cheapest fruit, then print its name. Pause here and work it out.

Answer. Best starts at index zero. Loop from index one using len. If a price is lower than the best price so far, best becomes that index. Return best, then print the name at that index. Plum, at twenty pence, is cheapest. Remember the method: make a checklist, understand the arrays, build one subprogram at a time with len, use trackers, then add comments and labels.
