Idea. In a school, every pupil has a name, so you can call the right person. In a program, every variable, constant, array and subprogram has a name too. That name is called an identifier. Think of a recipe that says, add the fruit. Fruit is a placeholder. When you cook, you pass in real apples. In code, the placeholder in the def line is the parameter. The value passed in the call is the argument. Where a variable is made decides its scope. One made inside a def block is local. One made in the main program is global. And its first value shows its data type: zero point zero or float gives a real.

Method. First, underline exactly what kind of item is asked for. Then go to the right place. Def headers hold parameters. Call brackets hold arguments. The name left of equals a function call receives the returned value. Finally, copy the identifier exactly as it is spelt, with the same capitals. Do not give a line number when a name is asked for.

Worked example. Here is a real question from Paper 2 in June 2025. Identify the name of a parameter. It is worth one mark. Here is the program, rebuilt by olevels.com. Find the subprogram header. Def get wages, with in sales and in age in the brackets. The names inside the header brackets are the parameters: in sales and in age. Sales and age on the last line are different. They are the arguments passed in the call. So write one parameter, spelt exactly: in sales, with a capital S. Either parameter earns the mark. This explanation is by olevels.com, not an official mark scheme.

Common mistake. The most common mistake is mixing up parameters and arguments. Sales is passed in the call, so it is an argument, not a parameter. Another mistake is naming a global variable when a local one is asked for. Wages is made inside the def block, so it is local. Sales is made in the main program, so it is global.
