Idea. Think about making toast. Bread goes in, the toaster heats it, and toast comes out. Something goes in, work is done, and a result comes out. Computers work the same way. This picture is called the input, process, output model, or I P O. Input is the data that goes in. Process is the work done on it. Output is the result the program produces. There are other models too. Sequential means instructions run one after another. Parallel means a job is split between processors, or cores, working at the same time. Multi-agent means separate systems work together on one goal.

Method. Read the scenario and underline every value. An input is given to the program from outside. It is typed in or sensed. Anything the program works out for itself is not an input. The process is the actual working. Write it with the names from the scenario, such as pay rate times hours. The word calculate on its own does not earn the mark. The output is a result the program produces at the end. It is shown on screen, printed or done. For a parallel question, give each core a separate part that does not need the other. Joining the answers must wait for a later step, because it needs both results.

Worked example. Here is a real question from Paper 2 in June 2025. A payslip shows a pay rate, hours, total pay, tax and income. Give an input, a process and an output used by the program. It is worth three marks. Which values must be typed in? The pay rate, eighteen pounds seventy-five, and the hours, nineteen. Nobody calculates the hours. So hours is an input. How is total pay made? Pay rate times hours. Eighteen seventy-five times nineteen is three hundred and fifty-six pounds twenty-five. That calculation is the process. Check the others. Tax is twenty per cent of the total, seventy-one pounds twenty-five. Income is total minus tax, two hundred and eighty-five pounds. All three are produced, so they are outputs. So the answer is: input, hours. Process, pay rate times hours. Output, total pay. One mark for each box. This explanation is by olevels.com, not an official mark scheme.

Common mistake. The most common mistake is giving a calculated value, such as total pay, as an input. If the program works it out, it is an output. In parallel tables, each core first does an independent part. Adding the parts together must go in a later row, because it needs both answers.

Your turn. Now you try. A fitness app is given the number of steps someone walked today. Each step is zero point seven metres. The app shows the distance walked. Give an input, a process and an output. Pause here and work it out.

Answer. The step count is given, so it is the input. The process is steps times zero point seven. The distance shown is the output. For eight thousand steps, that is five thousand six hundred metres. Remember the method: find what is given, write the actual working, then name the result. Keep the order input, process, output. Now try the practice questions for this type.
