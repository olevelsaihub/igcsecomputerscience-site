One light switch has two states, off or on. Add a second switch, and now there are four different patterns: off off, off on, on off and on on. Every extra bit doubles the number of patterns. One bit gives two, two bits give four, three bits give eight, four bits give sixteen, and eight bits give two hundred and fifty-six. So n bits give two to the power n patterns. Three bits count from zero zero zero up to one one one. That is eight patterns, and the biggest value is seven, one less than eight, because zero is a pattern too. The same rule appears in images and sound. Colour depth is the bits for each pixel. Bit depth is the bits for each sound sample. n bits give two to the power n colours or levels.

First decide which way round the question is. Bits to patterns? Work out two to the power n. Items to bits? Find the fewest bits that give enough patterns. For items to bits, list two, four, eight, sixteen, thirty-two, and stop at the first number that is at least the number of items. If you must write codes, give every item a different pattern with exactly that many bits. Counting up in binary makes sure no code repeats.

Here is a real question from Paper 1 in June 2022. An image has five colours. Give each colour a unique binary pattern, all using the same minimum colour depth. It is worth two marks. We need five patterns. Two bits give only four, which is not enough. Three bits give eight, which is enough. So every code uses three bits. Now count up in three-bit binary. Green zero zero one, black zero one zero, white zero one one, red one zero zero and blue one zero one. Check: every code has three bits, and no two are the same. One mark is for the minimum length, and one for no repeats. This explanation is by olevels.com, not an official mark scheme.

The biggest mistake is multiplying or squaring. Three bits is not three times two, which is six, and not three squared, which is nine. It is two to the power three, which is eight. Another mistake is codes of different lengths, such as zero, one, one zero. Every code must use the same number of bits.

Now you try. A railway uses twelve different signals, each with its own binary code. What is the fewest bits each code needs? How many different signals could that many bits give? Pause here and work it out.

Three bits give eight patterns, which is not enough for twelve. Four bits give sixteen, which is enough. So the fewest is four bits. Four bits give sixteen different patterns, so sixteen signals, with four codes spare. Counting up from zero zero zero zero, the twelfth signal gets one zero one one, which is eleven. Remember the method: decide the direction, use two to the power n, and give every item a code of the same length with no repeats. Now try the practice questions for this type.
