Pearson Edexcel · International GCSE Computer Science · 4CP0

Syllabus

Every official statement and bullet, with the question types that cover it.

Source: Pearson Edexcel International GCSE Computer Science specification, Issue 1 (2016-11). Statement codes and bullet wording are official; internal IDs for unnumbered bullets are not Pearson codes.

1. Problem solving

1.1 Algorithms

1.1.1 Understand what an algorithm is, what algorithms are used for and be able to interpret algorithms (flowcharts, pseudocode, written descriptions, program code).

11 past-paper parts assess this directly (11 main, 0 regional).

Question types: What algorithms are and how we write them down · Say what an algorithm (or one line) does · Turn a flowchart or pseudocode into Python

1.1.2 Understand how to create an algorithm to solve a particular problem, making use of programming constructs (sequence, selection, iteration) and using appropriate conventions (flowchart, pseudocode, written description, draft program code).

6 past-paper parts assess this directly (6 main, 0 regional).

Question types: Write an algorithm on paper: flowcharts and pseudocode

1.1.3 Understand the purpose of a given algorithm and how an algorithm works.

12 past-paper parts assess this directly (12 main, 0 regional).

Question types: Say what an algorithm (or one line) does

1.1.4 Understand how to determine the correct output of an algorithm for a given set of data.

14 past-paper parts assess this directly (14 main, 0 regional).

Question types: Trace tables: run the algorithm by hand

1.1.5 Understand how to identify and correct errors in algorithms, including using trace tables.

20 past-paper parts assess this directly (20 main, 0 regional).

Question types: What algorithms are and how we write them down · Trace tables: run the algorithm by hand · Find and fix errors in an algorithm

1.1.6 Understand how to code an algorithm in a high-level language.

14 past-paper parts assess this directly (14 main, 0 regional).

Question types: Turn a flowchart or pseudocode into Python · The final 20-mark program

1.1.7 Understand how the choice of algorithm is influenced by the data structures and data values that need to be manipulated.

6 past-paper parts assess this directly (6 main, 0 regional).

Question types: Compare sorts and searches · Make an algorithm faster or work for any amount of data

1.1.8 Understand how standard algorithms work (bubble sort, merge sort, linear search, binary search).

20 past-paper parts assess this directly (20 main, 0 regional).

Question types: Bubble sort, one pass at a time · Merge sort: split, then merge · Compare sorts and searches · Binary search step by step

1.1.9 Be able to evaluate the fitness for purpose of algorithms in meeting specified requirements efficiently, using logical reasoning and test data.

3 past-paper parts assess this directly (3 main, 0 regional).

Question types: Compare sorts and searches · Make an algorithm faster or work for any amount of data
